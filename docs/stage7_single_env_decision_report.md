# 阶段七：单环境预训练后的决策适应

## 设置

认知网络和分离式决策网络只在同一个环境上预训练。部署时切换到两个未见环境，认知状态通过单步转移在线更新。决策网络使用认知模型的 5 步短视 MPC 目标进行评估；物理接收分支分别采用零样本和在线小学习率更新。

## 结果

下表为真实环境 MPC 教师的动作 MSE，参数为预训练 100 步、决策预训练 100 步、部署 64 步、在线学习率 `1e-4`。

## 解释

认知网络的在线适应已经稳定，但决策物理分支的在线更新没有一致优于零样本，甚至在部分条件下略有退化。原因是决策网络只在单一环境上看到过物理算子，尚未学会如何把“新算子响应”转换成正确的动作变化；用认知模型自身的 MPC 标签更新还存在模型—真实环境偏差。

因此当前瓶颈已经从“认知网络是否能适应”转移到“决策解码器如何在没有隐藏因子标签的情况下适应新物理响应”。下一步需要设计基于真实转移代价/奖励的物理分支更新，或使用受约束的低秩决策适配器，避免直接改动整个决策网络。
