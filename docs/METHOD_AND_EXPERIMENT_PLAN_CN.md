# 任务可控效果接口：方法与实验计划

## 1. 当前唯一研究问题

给定固定源动力学 \(F_s\)、任务奖励 \(r\) 和高维连续控制任务，自动学习
一个决策网络与认知网络共同使用的效果空间。该空间不能依赖人工选择的
速度、高度或关节索引，并且必须足以支持闭环任务完成。

物理参数泛化、在线恢复和抗遗忘暂不进入本阶段实验。

## 2. 数学接口

认知网络：

\[
\hat s_{t+1}=F_\theta(s_t,a_t).
\]

效果编码器：

\[
z_t=\psi_\eta(s_t),\qquad z_t\in\mathbb R^{d_z}.
\]

任务 Router：

\[
\delta z_t=R_\phi(s_t,g).
\]

无参数隐式执行器：

\[
a_t^\star=
\arg\min_a
\left\|\psi_\eta(F_\theta(s_t,a))-(z_t+\delta z_t)\right\|^2
+\lambda\|a\|^2.
\]

任务梯度不得更新认知网络：

\[
\nabla_\theta\mathcal L_{\rm task}=0.
\]

## 3. 效果表示的四个条件

1. **任务充分**：\(V(s)\approx\bar V(\psi(s))\)。
2. **动力学闭合**：\(\psi(s')\approx h(\psi(s),a)\)。
3. **动作可控**：
   \(G=\partial\psi(F_\theta(s,a))/\partial a\) 满秩且条件数不过大。
4. **短时域一致**：效果改善应与真实未来价值提高同向。

单步局部逆问题要求 \(d_z\le d_a\)。若采用 \(H\) 步动作序列，则可放宽为
\(d_z\le H d_a\)。

## 4. 三道实验门

### Gate A：任务与规划器

- 普通 SAC 能稳定完成 Pusher。
- 真实 MuJoCo 状态克隆的 Oracle-CEM 达到 SAC 至少 90% 的性能。

若 Oracle-CEM 失败，问题位于奖励、规划时域、候选优化或终端价值，
不得归因于 ProtoKAN。

### Gate B：自动效果空间

在完全相同的 Router 和执行器下比较：

- 完整状态；
- PCA；
- 随机固定投影；
- 人工任务投影（仅作为上界，不作为最终方法）；
- 任务充分但无可控性约束；
- 完整任务可控效果空间。

通过标准：

- 自动方法达到 SAC 80%--90%；
- 显著优于 PCA 和随机投影；
- Jacobian 的最小奇异值与条件数稳定；
- 打乱效果空间或去掉可控性约束后性能明显下降。

### Gate C：认知模型

使用完全相同数据和预算比较 MLP 与 ProtoKAN：

- 单步状态 MSE；
- 动作 Jacobian 方向；
- 候选动作排序相关性；
- 短时域效果误差；
- 最终闭环成功率。

ProtoKAN 至少应保留 Oracle 80%--85% 的性能，并明显优于错误或打乱的
动力学模型。

## 5. 防止人工泄漏

- 方法读取完整环境观测，不手工挑状态坐标。
- 目标与奖励只用于源任务学习和评估。
- 物理参数从不作为网络输入。
- 效果维数只按动作维数和验证集确定，不按物理语义指定。
- 目标物理阶段不使用人工选择的变化类型路由。

## 6. 本分支第一轮

当前只实现 Gate A：

1. 环境、动作范围、状态克隆确定性检查；
2. zero/random 基线；
3. 真实模拟器 Oracle-CEM；
4. GPU SAC 训练入口；
5. 每步奖励分解、物体距离、动作幅值、候选回报和规划时间日志。

Gate A 通过前，不实现大规模效果表示或物理变化实验。
