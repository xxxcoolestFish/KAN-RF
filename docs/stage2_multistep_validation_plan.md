# 阶段二：认知表示充分性验证

## 假设

如果物理 token 是动力学的充分表示，那么使用该表示训练的认知网络应当在未见动力学组合上保持多步预测能力，而不是只在单步监督下拟合。

## 比较

1. 只使用单步预测损失；
2. 使用 4 步递归预测损失；
3. 两者都使用相同的 token 一致性约束和稀疏约束。

## 指标

- 未见组合的 1 步预测误差；
- 未见组合的 4 步预测误差；
- 同一因素下的 pooled token 一致性；
- 不同因素之间的 pooled token 区分度；
- 有效 token 数。

只有当多步训练确实降低长时域误差，同时保持不同动力学可区分，才进入决策网络 oracle 接收实验。
