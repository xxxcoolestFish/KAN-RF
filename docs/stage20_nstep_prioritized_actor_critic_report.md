# Stage 20：改进实时损失的无教师实验

## 1. 改动

本实验完全不使用实时 MPC 教师，只使用真实环境反馈。相对 Stage 19，损失和回放改为：

- 8-step return，缩短成功信号传回早期动作的路径；
- 势函数奖励塑形 `gamma * height(next) - height(current)`；
- 成功 episode 和 TD-error 优先回放；
- 双 Critic、目标策略平滑和较小的 Actor 学习率；
- 终端高度达到 `1.0` 时给予成功奖励并结束 episode。

认知网络仍只用于预训练和一次性生成固定算子；在线阶段不再查询教师动作。

## 2. 结果

配置：全决策参数可训练，`n_step=8`，100 个 episode，固定测试集 20 个初始状态。

| 指标 | 结果 |
|---|---:|
| 学习前固定测试集 | 14/20 = 70% |
| 在线训练成功率 | 67% |
| 学习后固定测试集 | 14/20 = 70% |
| 在线训练平均回报 | 6.48 |

相比 Stage 19，训练回报从负值变为正值，Critic 后期损失大致稳定在 `0.2–0.5` 范围，但确定性固定测试成功率没有提升。失败状态主要仍然集中在原先的困难初始状态，说明优先回放并没有自动找到这些状态对应的成功动作序列。

## 3. 结论

这次实验说明：

1. 原来的自我动作回放损失确实不够好；
2. n-step、势函数塑形和优先回放改善了训练信号和 Critic 稳定性；
3. 但“损失函数改正确”仍然不能保证 20/20，当前主要瓶颈还包括困难状态的探索覆盖、固定物理算子初始化以及 Actor 的状态—动作表示；
4. 当前结果不能再简单归因于“没有使用教师”。在线阶段已经完全无教师，仍然无法解决困难状态。

## 4. 下一步

下一步应检查困难状态是否在真实在线数据中获得过成功轨迹，并加入基于 Critic 不确定性的探索或课程式状态覆盖。同时应比较固定 `q_const` 与实时更新 `q_t`，确认一次性算子是否丢失了决策所需的状态上下文。
