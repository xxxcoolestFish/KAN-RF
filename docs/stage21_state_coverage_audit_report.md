# Stage 21：困难状态覆盖与物理算子稳定性审计

## 1. 实验目的

在继续改 Actor–Critic 损失之前，检查两个问题：

1. 当前探索机制是否能够为固定测试状态找到成功轨迹；
2. 认知网络输出的 operator 是否真的是同一物理环境下稳定的物理编码。

本实验不更新决策网络，在线探测阶段不使用动作教师。认知网络只用于预训练和一次性初始化 `q_const`。

## 2. 困难状态探索结果

固定测试集仍为 `test_seed=20260718` 的 20 个初始状态。对每个状态分别进行 16 次、64 步 rollout，动作噪声分别为 `0.10`、`0.20`、`0.40`。

有 5 个状态在所有三种噪声强度下均为 0/16 成功：

| 状态索引 | 噪声 0.10 | 噪声 0.20 | 噪声 0.40 |
|---:|---:|---:|---:|
| 0 | 0/16 | 0/16 | 0/16 |
| 2 | 0/16 | 0/16 | 0/16 |
| 4 | 0/16 | 0/16 | 0/16 |
| 15 | 0/16 | 0/16 | 0/16 |
| 17 | 0/16 | 0/16 | 0/16 |

状态 10 对探索强度敏感：噪声 `0.10` 时为 4/16，噪声 `0.20` 时为 9/16，但噪声 `0.40` 时又降为 1/16。

这说明当前回放学习存在一个前置问题：对于这些困难状态，探索策略根本没有产生成功样本，优先回放自然无法学习出成功动作序列。

## 3. operator 稳定性结果

在同一预训练物理环境中采样 256 个不同状态/历史上下文，得到：

- operator 维度：54；
- 平均坐标标准差：`0.171`；
- 最大坐标标准差：`0.237`；
- operator 与均值编码的平均余弦相似度：`0.230`；
- 余弦相似度标准差：`0.444`。

如果 operator 主要表示同一环境的不变物理规律，来自同一环境的编码应该高度对齐。平均余弦相似度只有 `0.23`，说明当前 operator 明显包含状态或历史上下文，而不是纯粹的环境物理参数。

因此，当前使用

```text
q_const = mean(q(state, history))
```

会把不同上下文中的信息混合并抵消，导致决策网络接收到一个既不稳定、又不对应当前状态的物理接口。

## 4. 结论

当前性能差的主要原因可以重新排序为：

1. **探索覆盖不足：** 困难状态没有成功轨迹，损失函数没有正向样本可学习；
2. **物理接口不稳定：** operator 不是环境不变量，`q_const` 平均会丢失有效上下文；
3. **决策网络与 operator 的实时耦合不足：** 当前 operator 只在初始化和 residual 分支中发挥作用；
4. **损失函数问题：** n-step 和优先回放只能改善已有数据的利用，不能弥补没有成功数据的问题。

所以，继续单纯修改 Critic 损失不会解决这 5 个状态。下一步应优先重新设计 operator，使其区分“环境不变量”和“当前状态上下文”，并让决策网络在实时决策中接收状态相关的 operator；同时需要设计能够主动覆盖困难状态的探索机制。
