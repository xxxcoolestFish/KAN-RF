# Stage 22：嵌合式认知—决策网络首轮验证

## 1. 实验目的

本实验验证一条尽量简洁、数学路径明确的结构：认知网络只负责单步预测，决策网络在认知网络之上增加一个标量能量网络；动作不是由旁路策略头直接输出，而是通过最小化

\[
E_\psi(F_\phi(s,a),g)
\]

得到。因此每次动作求解都必须经过认知预测器 `F_φ`。

本轮不使用动作教师、MPC、GRU、latent 分割或固定物理参数接口。

## 2. 网络结构

- 认知网络：`ProtoKAN([state, action] -> next_state)`，输入维度 7，隐层宽度 32，输出维度 6。
- 决策新增参数：`ProtoKAN([predicted_next_state, goal] -> scalar energy)`，输入维度 12，隐层宽度 32，输出维度 1。
- 动作生成：从零动作开始，对能量关于动作做 3 次可微梯度下降，并将动作限制在 `[-1, 1]`。
- 决策训练：冻结认知网络，仅更新能量网络；在认知网络内部进行 4 步模型滚动，以任务代价反向更新能量参数。

## 3. 实验设置

- 环境：Acrobot 预训练物理参数（同一环境）。
- 认知预训练：300 步，批大小 64，Smooth-L1 单步状态预测损失。
- 能量表面初始化：100 步。监督目标是认知模型预测状态的任务代价，不是动作标签，因此不属于动作教师。
- 决策训练：100 步，批大小 16，模型滚动长度 4。
- 测试：固定随机种子 `20260718`，20 个初始状态，真实环境滚动 64 步；成功定义为末端高度达到 1.0。

## 5. 结论

这轮实验验证了结构上的关键事实：

1. 单一 ProtoKAN 可以在预训练环境中学到较高精度的单步动力学预测。
2. 能量网络可以通过认知网络的预测结果获得初始化，并进一步使用任务损失更新。
3. 动作生成路径确实是 `动作 -> 认知预测 -> 能量 -> 动作梯度`，没有独立的策略旁路，也没有动作教师。
4. 该结构在固定环境和固定测试集上已经得到 70% 成功率，但还没有达到 20/20。因此本轮证明的是“嵌合结构能够工作”，不是“最终决策性能已经解决”。

当前主要瓶颈是：单步认知模型被用于多步滚动时会产生误差累积；能量表面虽能拟合一步任务代价，但还没有形成足够平滑、可供动作梯度稳定下降的长时域势能。下一步应优先检查多步滚动误差、动作梯度的有效性和能量函数的长时域训练，而不是重新引入复杂 latent 分支。
