# Stage 16：认知网络一次性初始化后的决策网络单独持续学习

## 1. 实验目的

本实验隔离验证一个问题：认知网络完成预训练并向决策网络传递一次初始化信息后，部署阶段完全停止调用认知网络，只让决策网络在认知网络原本的训练环境中通过真实环境反馈持续学习，当前的决策损失和回放机制能否把成功率提升到较高水平。

这不是完整的在线认知—决策双网络实验，而是对决策网络持续学习能力的单独检查。

## 2. 实验设置

- 物理环境：预训练环境 `PRETRAIN_FACTOR=(7.35, 0, 0.8, 0.8)`。
- 认知网络：使用原子转移 `(s, a, s')` 预训练；随后只计算一次固定算子 `q_const`。
- 参数传递：使用已有的认知算子到决策网络的初始化映射；部署期间 `q_const` 保持不变。
- 部署期间：不再调用认知网络，不更新认知网络；决策网络的基础物理分支冻结，只更新 runtime residual 分支。
- 持续学习：收集真实环境轨迹，将折扣回报作为权重进行动作回放（AWR-like 加权动作回归），每回合更新 4 次，并限制 residual 相对初始参数的漂移半径为 `0.05`。
- 探索：训练阶段加入幅度为 `0.10` 的高斯动作噪声；评估阶段关闭探索。
- 每个阶段：20 个 episode，每个 episode 最多 64 步。
- 成功判据：轨迹中摆杆尖端高度达到 `1.0` 以上。
- 随机种子：42。

## 3. 结果

| 阶段 | 探索 | 成功率 |
|---|---:|---:|
| 在线学习前确定性评估 | 关闭 | 7/20 = 35% |
| 在线训练过程 | 开启 | 13/20 = 65% |
| 在线学习后确定性评估 | 关闭 | 10/20 = 50% |

因此，从同一批随机初始状态分布下的确定性表现看，在线学习使成功率由 **35% 提升到 50%**，提升 15 个百分点。但它仍没有达到我们希望的高成功率，更没有达到 20/20。

训练阶段的 65% 不能直接视为策略已经达到 65% 的确定性能力，因为其中包含了探索噪声；真正用于判断已学会策略的是训练后的无探索评估。

## 4. 结论

1. **决策网络持续学习确实在起作用。** 在认知网络被移除后，决策网络仍能利用真实回报更新 residual，并改善确定性成功率。
2. **当前损失并不足以稳定学习成功动作序列。** 逐步动作回放只使用局部动作回归，虽然用折扣回报加权，但没有显式解决长时域信用分配；成功轨迹中的关键早期动作仍可能被大量普通步覆盖。
3. **一次性物理初始化不是充分条件。** 固定 `q_const` 提供了可用起点，但初始化后的决策表示仍需要更强的任务级学习机制才能达到高成功率。
4. **本实验支持下一步改进方向。** 应优先加入成功轨迹/动作序列级别的目标，或引入价值函数/优势函数，把最终成功信号传递到早期动作；同时保留当前真实环境回放和 trust-region 约束。
