# 认知可达管道的局部闭环验证

## 验证目标

在进入完整 Acrobot 任务前，验证粗规划图中的宏边能否被一个不接收动作教师的共享反馈策略稳定执行。实验使用 Oracle 动力学，抽取 96 条通向成功集合的图边，其中包括下垂初态最短路线上的三条边。

每条点边通过 64 组动作扰动转化为经验可达椭球。构造完成后动作全部丢弃；决策网络只接收当前状态、区域中心和可达尺度。每条边允许 24 个真实环境步，测试 16 个扰动初态。

预设通过条件为总体边完成率不低于 95%，且打乱区域参考后明显下降。

## 正式结果

| 指标 | 结果 |
|---|---:|
| 正确可达区域完成率 | 33.01% |
| 随机常值动作完成率 | 23.57% |
| 打乱可达区域完成率 | 20.57% |
| 下垂初态三条路线边完成率 | 66.67% |
| 中位单边完成率 | 25.00% |
| 最差单边完成率 | 0.00% |
| 达到 95% 的边 | 4/96 |
| 规划打乱后的平均动作变化 | 0.5945 |
| 源状态已落在目标区域内 | 0% |
| 名义终点误差（平均/最大） | 0.0051 / 0.0292 |

Critic 损失从 1.22 稳定下降到约 0.25，排除了价值目标数值爆炸。正确规划比随机和打乱规划分别高约 9.4 和 12.4 个百分点，动作敏感性也很高，因此规划信息确实进入了策略，而不是被 Actor 忽略。

但是 33.01% 远低于 95% 闸门，局部闭环命题不成立，不能进入完整任务验证。

## 问题定位

### 1. 当前椭球描述的是前向终点散布，不是反馈可达集合

动作扰动协方差只能说明某条名义动作附近的终点怎样变化。它没有证明：从任意扰动初态出发，存在一个状态反馈律能把系统送入该区域。

数学上，当前近似的是前向像：

\[
\{F^H(s_i,a_{0:H-1}+\delta a)\},
\]

真正需要的是反馈可达集或吸引域：

\[
\mathcal B_{ij}
=\{s:\exists\pi,\;F_\pi^{\le H}(s)\in\mathcal R_{ij}\}.
\]

二者不是同一个对象。

### 2. 对角尺度丢失了耦合方向

Acrobot 的角度以正余弦表示，并且角度、速度之间存在强耦合。六个独立尺度无法表达“某个角度误差必须配合某个速度方向”这类倾斜流形。区域在数值上包含了不应等价的状态。

### 3. 宏边可能只能由狭窄的相位动作实现

名义终点误差很小，说明图边确实开环可达；但多数边的闭环完成率很低，说明可行动作序列缺少反馈余量。低层策略还没有剩余时间或宏相位输入，同一个状态目标在不同剩余时域下可能需要不同动作。

### 4. 图搜索尚未使用闭环成功概率

当前图仍然可能选择只有 0%–25% 完成率的边。只要边的代价不包含低层闭环成功率，最短路就不等于最可靠路线。

## 结论

本实验确认了两个不同事实：

1. 粗规划信息能够被决策网络使用；
2. 当前由开环终点扰动构造的区域不足以成为可靠的认知—决策接口。

因此下一步若继续，应该估计反馈可达集或局部吸引域，而不是继续调大椭球、增加 PPO 轮数或直接运行完整任务。规划边必须先由闭环完成概率认证，再允许进入全局图搜索。
