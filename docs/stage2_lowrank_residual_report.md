# 阶段二：低秩物理基—系数残差实验

## 动机

有界残差降低了 V2 物理分支的过度响应，但没有消除跨随机种子的校准差异。为使“认知编码—物理解码”更明确，本实验将自由的状态残差替换为

\[
R_\psi(h,s,a)=B_\phi(s,a)c_\psi(h),
\qquad B_\phi^\top B_\phi\approx I.
\]

其中认知分支只从历史产生系数 `c`，当前状态和动作只用于生成应用基 `B`。`rank` 是过完备容量，不对应预先知道的物理参数数量。

## 实验设置

- 多因素隐藏 Acrobot：重力、阻尼、驱动强度、惯量尺度；
- `M=8`，历史长度 8，训练 300 步；
- rank 分别为 2、4、6；
- 残差尺度 0.1；
- 损失包含普通预测、反事实绝对误差、反事实差分误差、token 一致性、基正交正则和残差能量正则；
- seed 42、43。

## 结论

当前低秩算子没有实现物理差异传递，而是出现了比 V2 更严重的“物理分支坍缩”：反事实预测差异接近 0，模型主要依赖不含历史的 base 分支。增加 rank 没有改善这一点，说明问题不是简单的容量不足。

这暴露了两个需要分开的因素：

1. 低秩 `B c` 的参数化存在系数—基的不辨识性，正交正则只约束了基，却没有保证系数具有跨动力学条件的语义；
2. 当前差分损失相对于普通预测和残差能量的梯度可能不足，模型通过令 `c` 近似常数获得了较低的平均误差。

因此暂不把该结构接入决策网络。下一步先做损失权重与可辨识性消融：直接测量同状态不同因素下的系数差异，并比较差分损失权重、残差能量权重和固定基/可变基三种设置。只有当物理系数能稳定区分反事实动力学后，才进入决策网络的物理接收器实验。
