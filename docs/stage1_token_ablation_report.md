# 阶段一：自适应物理 token 消融报告

## 实验设置

- 环境：修正后的连续动作 Acrobot；
- 训练重力：`7.35, 12.25, 14.7`；
- 未见重力：`9.8, 11.0, 13.475`；
- 历史长度：8；
- 训练步数：300；
- 容量和一致性实验使用随机种子 `42, 43, 44`；
- 一致性只比较相同重力下的两条独立轨迹，避免把不同动力学错误拉近。

## 评价指标

- `heldout_prediction_loss`：未见重力上的下一状态预测误差；
- `same_dynamics_consistency`：相同动力学下两组轨迹的 token 集合距离；
- `different_dynamics_distance`：不同动力学下 pooled 表示的距离；
- `mean_effective_slots`：门控值大于 0.5 的平均 token 数。

## 容量比较

固定 `lambda_sparse=1e-3`、`lambda_consistency=0.1`，结果如下（预测误差为三 seed 平均）：

| 最大 token 数 M | 未见预测误差 | 同动力学一致性 | 不同动力学距离 |
|---:|---:|---:|---:|
| 4 | 0.001362 | 0.001892 | 0.007921 |
| 8 | **0.001296** | 0.001791 | **0.009357** |
| 16 | 0.001749 | **0.001743** | 0.005270 |

当前重力变化任务中，`M=8` 是较好的折中；`M=16` 没有带来收益，反而出现更弱的动力学区分度。这个结果只说明当前任务的表示容量，不代表真实物理因素数量。

## 稀疏系数比较

固定 `M=8`、`lambda_consistency=0.1`，seed 42 的结果：

| `lambda_sparse` | 未见预测误差 | 有效 token 数 |
|---:|---:|---:|
| 0 | 0.001010 | 8.00 |
| 1e-4 | 0.000999 | 8.00 |
| **1e-3** | **0.000966** | **6.45** |
| 1e-2 | 0.001612 | 0.00 |

`1e-3` 能减少冗余 token 而不明显损害预测；`1e-2` 会导致门控全部关闭，说明当前简单的平均门控惩罚不能无限增大。

## 一致性系数比较

固定 `M=8`、`lambda_sparse=1e-3`，三 seed 平均结果：

| `lambda_consistency` | 未见预测误差 | 同动力学一致性 | 不同动力学距离 |
|---:|---:|---:|---:|
| 0 | 0.001419 | 0.05956 | **0.04347** |
| **0.01** | 0.001373 | 0.01699 | 0.02676 |
| 0.1 | **0.001296** | 0.001791 | 0.00936 |
| 1.0 | 0.001153 | **0.000132** | 0.00209 |

一致性越强，同一动力学的表示越稳定，但不同动力学之间的距离也会被压缩。`lambda_consistency=1` 已出现明显表示塌缩；`0.01` 是当前更保守的折中，`0.1` 更重视预测和轨迹稳定性，但动力学区分度较弱。

## 当前决定

阶段一暂定配置：

```text
最大 token 数：8
token 维度：8
lambda_sparse：1e-3
lambda_consistency：0.01（保守接口）
```

在进入决策网络之前，还需要加入摩擦/质量等隐藏变化，验证容量和 token 机制是否真的能够随动力学复杂度扩展。当前结果不能被解释为 token 与真实物理参数一一对应。
