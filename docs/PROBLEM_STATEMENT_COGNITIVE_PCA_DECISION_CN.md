# 认知 PCA → 决策网络外推：问题陈述

> 2026-07-26 | 分支 feature/cognitive-pca-decision | 供内部讨论

---

## 1. 项目背景（一句话）

单一物理环境训练 RL 策略 + 认知世界模型，部署后在线适应未知物理变化，不访问目标环境奖励。

---

## 2. 当前框架

```
┌─────────────────────────────────────────────────┐
│  认知网络（KAN，控制仿射结构）                       │
│                                                 │
│  f(s, a) = b(s) + G(s)·a                       │
│                                                 │
│  源环境训练后冻结。目标环境仅用 (s,a,s') 在线拟合     │
│  新系数 W_t，使 KAN 适配当前物理。                   │
│                                                 │
│  PCA(W_t - W_source) → z ∈ ℝᵏ                  │
│  前 4 个主成分捕获 93.6% 方差。                     │
│  z 的物理含义已验证：不同物理变化在 PC 空间自然分离。   │
└────────────────────────┬────────────────────────┘
                         │ z（紧凑物理表征，~4 维）
                         ▼
┌─────────────────────────────────────────────────┐
│  决策网络 π(s, z) → a                            │
│                                                 │
│  训练：仅在源物理环境（此时 z ≡ z₀ = 常数）          │
│  部署：z 由认知网络在线提供，可能是任意值             │
└─────────────────────────────────────────────────┘
```

**核心直觉**：认知提取物理规律（z），决策利用规律做动作（a）。两层分工明确，认知不参与动作生成，只提供上下文。

---

## 3. 当前卡点

### 3.1 核心矛盾

```
训练时：z 永远是常数 z₀
  → 强化学习的梯度告诉策略："z 变不变无所谓"
  → π(s, z) 退化成了 π(s)，忽略 z

部署时：z 可以是 PCA 空间任意位置
  → 质量变大、摩擦变小、组合变化……
  → 网络从未见过这些输入，不知道该怎么做
```

**这不是架构问题，是训练信号问题。** 用 RL 在单一环境中训练，z 没有变化，网络就学不到 z→动作的映射。改架构（残差、FiLM、Lipschitz 约束）不解决这个问题——架构再好，输入不变，就学不到映射。

### 3.2 已排除的方向

| 方向 | 为什么不行 |
|:---|:---|
| KAN 做策略网络 | 软最大值局部化 → 梯度饥饿，有效容量远低于 MLP，不适合 RL |
| 域随机化（多个物理环境训练） | 放弃"单源训练"的独特竞争力 |
| 残差锚定 π = π_source + Δπ | Δπ 训练时 z 还是常数 |
| FiLM 调制 z→(γ,β) 注入 MLP | z 为常数时退化回普通 MLP |

### 3.3 KAN 策略为何失败

ProtoKAN 的软最大值插值结构（高斯核 + softmax → 局部原型激活）与 SGD 优化不兼容：
- 每个输入只激活 2-3 个原型 → 大量参数梯度为零
- RL 状态分布随训练漂移 → 原型饥饿 / 灾难性遗忘
- 软最大值梯度指数衰减 → PPO 噪声梯度无法有效传播

KAN 适合认知网络（IID 数据 + 闭式求解），不适合 RL 策略（在线数据 + SGD）。

## 4. 请求帮助

**核心问题**：如何让 π(s, z) 在只有源物理环境的条件下，获得 z 变化的有效训练信号？

---

## 5. 关键约束

- **必须保持单源训练范式**（这是和域随机化方法的本质区分）
- **认知网络不再参与动作生成**（只提供 z）
- **π(s,z) 最终必须能在外推的 z 上稳定工作**
