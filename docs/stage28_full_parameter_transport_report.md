# Stage 28：全维度参数运输验证

## 1. 目的

验证不压缩认知参数的参数运输方式：

\[
\theta_c\in\mathbb R^{7090}
\xrightarrow{\mathcal T}
\omega_p\in\mathbb R^{7090}
\]

运输维度与认知网络参数维度完全相同，压缩比例为 1.0。

## 2. 实现

- `FullParameterTransport` 使用同维度的缩放恒等映射；
- 所有认知 ProtoKAN 参数均被读取，没有低维代码瓶颈；
- 决策网络通过状态相关查询向量读取完整物理参数向量；
- 对照组使用相同决策主干，但关闭完整物理参数通道；
- 认知网络只使用预测损失，决策网络只使用任务滚动损失；
- 在线阶段只更新认知预测网络，然后重新读取完整参数。

代码：

- `physics_transfer/full_parameter_transport.py`
- `scripts/stage28_full_parameter_transport.py`

## 3. 结果

快速实验使用 120 步认知预训练、80 步决策训练和 60 步在线认知更新。

### 参数完整性

- 认知参数量：7090；
- 运输维度：7090；
- 压缩比例：1.0；
- 在线目标环境上的运输参数变化 L2：`6.27`。

相比 Stage 27 压缩运输版本的运输代码变化约 `0.00105`，全维运输没有丢弃认知参数变化。

### 决策结果

| 环境 | 全维运输 | 无物理通道基线 |
|---|---:|---:|
| source | 75% | 75% |
| factor_1 | 65% | 65% |
| factor_2 | 65% | 65% |
| factor_3 | 70% | 70% |
| factor_4 | 60% | 60% |
| heldout_1 | 70% | 70% |
| heldout_2 | 55% | 55% |

在线认知更新后：

- 认知 MSE：`0.0191 → 0.0161`；
- 运输参数变化：`6.27`；
- 平均动作变化：约 `1.1×10^{-5}`；
- heldout_1 成功率：`70% → 70%`。

## 4. 结论

全维运输验证了：

> 不压缩地保留认知网络参数是可行的，认知参数变化可以完整地传递到决策网络的物理参数空间。

但实验也显示：

> 参数完整传递并不会自动带来决策性能提升。

当前决策网络仍然可以通过自身主干和输出饱和区弱化物理参数的影响。因此问题已经从“参数是否丢失”转移为“决策前向如何强制使用这些参数”。

## 5. 下一步

1. 去掉决策网络绕过物理通道的加性捷径；
2. 使用乘性门控或参数生成层，使完整认知参数必然影响每一层；
3. 测量 \(\partial a/\partial\theta_c\) 和逐块参数干预敏感性；
4. 再比较全维运输与低秩运输的在线恢复速度。
