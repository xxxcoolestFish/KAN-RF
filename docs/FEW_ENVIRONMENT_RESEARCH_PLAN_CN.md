# Few-Environment ProtoKAN 动力学适应研究路线

## 1. 当前研究问题

我们不再要求从一个固定物理环境中凭空推断所有未见物理规律。新的问题是：

> 能否只从极少数源物理环境中学习“动力学如何变化”的低维结构，并在未知
> 目标环境中，仅使用少量无奖励状态转移，快速识别当前动力学并恢复控制性能？

必须同时报告两个独立的数据预算：

1. **源环境预算 \(K\)**：预训练使用多少种不同物理环境；
2. **目标转移预算 \(N\)**：切换环境后允许使用多少条
   \((s_t,a_t,s_{t+1})\) 转移。

本文中的 `few-environment` 指 \(K\) 很小，`few-transition adaptation`
指 \(N\) 很小。两者不能混称为一个模糊的 `few-shot`。

## 2. 硬约束

正式方法和主要实验不得使用：

- 真实质量、摩擦、执行器强度等物理参数；
- 人工提供的环境 ID 或物理变化类型标签；
- 目标环境奖励来训练认知模型或选择适配结果；
- 根据测试环境类型手工切换专用适配器；
- 只对最终成功率有利、但无法由观测和转移自动得到的人工状态投影。

允许使用：

- 源环境中的任务奖励训练源 Actor/Critic；
- 源与目标环境中的无奖励转移训练或更新认知模型；
- 由源 Critic、源 Actor 和认知动力学自动计算的控制相关量；
- 决策网络在目标环境中持续学习，但必须单独报告其奖励和交互预算。

## 3. 数学模型

设环境动力学为

\[
s_{t+1}=f_{\theta(z)}(s_t,a_t),
\]

其中 \(z\) 是未知环境坐标。我们不要求 \(z\) 对应某个具名物理参数，只要求
它能够解释转移规律的变化。

第一版假设 ProtoKAN 参数位于一个低维变化子空间：

\[
\theta(z)=\bar{\theta}+Uz.
\]

- \(\bar{\theta}\)：跨环境共享的动力学规律；
- \(U\)：动力学参数变化基；
- \(z\)：某个环境在变化基中的坐标。

训练时共同优化共享参数、变化基和每个源环境的自由坐标：

\[
\min_{\bar{\theta},U,\{z_i\}}
\sum_{i=1}^{K}
\sum_{(s,a,s')\in D_i}
\left\|
s'-f_{\bar{\theta}+Uz_i}(s,a)
\right\|^2
+\mathcal{R}.
\]

进入未知目标环境后，冻结 \(\bar{\theta}\) 与 \(U\)，只利用少量无奖励转移
识别 \(z_\star\)：

\[
z_\star=
\arg\min_z
\sum_{(s,a,s')\in D_\star}
\left\|
s'-f_{\bar{\theta}+Uz}(s,a)
\right\|^2
+\lambda\|z\|^2.
\]

后续可允许共享模型进行慢速更新，但必须与“只更新环境坐标”的快速环分离，
并配合回放或结构保护验证抗遗忘。

## 4. 一个不能回避的维数限制

如果只有 \(K\) 个离散源环境，仅根据环境间参数差异，通常最多可靠识别
\(K-1\) 维变化子空间：

\[
\operatorname{rank}(U)\le K-1.
\]

因此：

- 两个源环境首先只验证一个物理变化轴；
- 三到四个经过独立干预的源环境才适合验证二维复合变化；
- 不能用两个源环境宣称解决任意质量、摩擦和执行器变化。

这个限制应成为实验设计和理论分析的一部分，而不是通过增加网络容量回避。

## 5. 系统结构

### 5.1 认知模型

认知模型是条件 ProtoKAN 动力学：

\[
\hat{s}_{t+1}=f_{\bar{\theta}+Uz}(s_t,a_t).
\]

它负责：

- 从少数源环境中学习共享规律与变化方向；
- 从目标环境少量转移中识别当前 \(z\)；
- 持续更新预测并输出不确定性；
- 保留旧环境能力。

第一阶段不强迫 \(z\) 的每一维对应人工物理语义。

### 5.2 决策模型

长期任务仍由成熟 Actor–Critic 学习。认知模型不能只是附加输入，也不能被
Actor 绕过。当前保留的候选接口是控制等价算子：

\[
a_\star=
\arg\min_a
\left\|
F_{\theta(z_\star)}(s,a)-d_{\text{desired}}
\right\|_M^2.
\]

已有 Oracle 实验表明局部效果匹配可解，但还没有证明它能够稳定恢复长期闭环
性能。因此它是保留的候选组件，不是已确定的最终方案。

正式接入 ProtoKAN 前，必须先在 Oracle 动力学条件下证明有限时域闭环控制
等价能够改善连续任务指标。

### 5.3 双时间尺度在线适应

- 快速环：每获得少量目标转移就更新 \(z_\star\)；
- 慢速环：证据充分时才更新共享 ProtoKAN 参数；
- 决策环：允许 Actor/Critic 持续学习，但单独统计带奖励交互数量；
- 记忆环：保留少量源环境锚点或函数约束，测试切回旧环境后的遗忘。

## 6. 分阶段实验

### Gate A：一维变化是否可辨识

- 环境：先使用 Pusher 执行器强度单轴变化；
- 源环境数：\(K=1\) 与 \(K=2\)；
- 两个源锚点示例：0.9、1.0；
- 插值测试：0.95；
- 外推测试：0.6、0.75、1.15、1.3；
- 目标转移预算：\(N\in\{0,5,10,25,50,100\}\)；
- 暂不训练目标策略，只测动力学识别与 Oracle 控制接口。

通过标准：

1. \(K=2\) 在外推点明显优于单源 ProtoKAN；
2. 少量转移更新主要改变 \(z\)，不会破坏源环境预测；
3. ProtoKAN 在预测误差、导数误差或样本效率上稳定优于同容量 MLP；
4. 不使用真实执行器参数或环境 ID。

### Gate B：认知更新能否改善控制

固定同一个高成功率源 Actor，比较：

- 源 Actor 直接迁移；
- Actor/Critic 直接在线微调；
- MLP 条件动力学；
- ProtoKAN 条件动力学；
- Oracle 目标动力学；
- 大规模 domain randomization 上限。

主要指标：

- 切换后即时性能下降；
- 恢复曲线 AUC；
- 恢复到源性能 90% 所需转移数；
- 最小目标距离和平均回报；
- 目标奖励交互预算；
- 切回源环境后的遗忘。

只有连续指标改善时才算通过，不能只依赖 0.05 阈值附近的成功率变化。

### Gate C：二维复合变化

- 使用至少 3–4 个源环境；
- 独立改变执行器和质量；
- 测试未出现过的组合以及训练范围外的强度；
- 检查变化基能否组合，而不是记住环境 ID；
- 比较 rank-1、rank-2 与过高秩模型。

### Gate D：迁移到更复杂系统

Pusher 通过后，再进入一个高维连续控制环境。必须同时包含：

- 单一物理变化；
- 复合物理变化；
- 非平稳连续漂移；
- 多随机种子。

## 7. 关键消融

- \(K=1,2,3,4\)；
- \(N=0,5,10,25,50,100\)；
- MLP 与 ProtoKAN；
- 只更新 \(z\)、更新全部认知参数、双时间尺度更新；
- 无记忆、转移回放、函数保持约束；
- 控制等价接口与简单 context 拼接；
- 插值与外推；
- 已知物理参数 Oracle 与完全无标签设置。

## 8. 创新边界

已有研究已经覆盖“上下文动力学模型”“上下文条件策略”“少量训练 context
泛化”和“世界模型参考轨迹控制”。因此不能宣称首次进行少环境动力学适应。

当前可能形成的独特组合是：

1. 在 ProtoKAN **系数空间**学习少环境动力学变化基；
2. 不需要真实物理参数、环境 ID 和目标奖励；
3. 用少量转移进行快速环境坐标识别；
4. 将识别结果通过不可绕过的闭环控制等价接口作用于策略；
5. 同时研究快速恢复与持续学习遗忘。

这些只是待验证的研究假设。只有关键消融和多环境实验成立后才能作为论文贡献。

## 10. 下一项实现

实现最小 `FewEnvironmentDynamics` 原型：

1. 共享 ProtoKAN 动力学；
2. rank-1 系数变化方向；
3. 两个匿名源环境自由 latent；
4. 目标环境仅优化 latent；
5. 与同容量 MLP 和单源 ProtoKAN 做预测及外推比较。

在 Gate A 得到明确结果前，不重新加入 Router、长程规划器或复杂在线 Actor。
