# 阶段二：认知表示充分性验证

## 实验设置

- 多因素隐藏 Acrobot；
- 最大 token 数 `M=8`；
- 训练因素和未见因素与阶段一相同；
- 训练步数 300；
- 对比两个 seed：`42, 43`；
- 单步训练和四步递归训练使用相同的一致性与稀疏约束。

## 结果

| 训练方式 | 1 步误差 | 4 步误差 | 同因素一致性 | 不同因素距离 | 有效 token |
|---|---:|---:|---:|---:|---:|
| 单步训练 | **0.001209** | 0.005223 | **0.01813** | 0.02331 | 3.72 |
| 多步训练 | 0.002567 | **0.004114** | 0.03513 | **0.04021** | 7.60 |

## 结论

多步训练确实降低了未见动力学组合上的长时域误差，但产生三个代价：

1. 单步预测精度下降；
2. 同一动力学下的 token 表示更不稳定；
3. 几乎所有 token 都被激活，稀疏结构被削弱。

因此，多步损失不能简单替换单步损失。它更适合作为辅助项：

\[
\mathcal L=\mathcal L_{1}+\lambda_4\mathcal L_{1:4}
\]

下一步应比较不同的 `lambda_4`，寻找局部预测、长时域预测和表示稳定性之间的折中。
