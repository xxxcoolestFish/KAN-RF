# Stage 58：多动作 Oracle 与单点 Oracle 对照

## 1. 实验目的

Stage 56 表明，单个准确动力学预测可以支持约 32.8% 的在线恢复，但仍不能达到高成功率。本阶段让决策网络在每次前向时读取目标动力学对 9 个虚拟候选动作的真实下一状态，再由 DeepONet 式结构统一评分。

虚拟动作不会执行到环境中，因此没有额外探索成本。

## 2. 结果（seed=0，完整协议）

| 方法 | 源环境 | 目标零样本 | 在线适应后 |
|---|---:|---:|---:|
| 单动作真实 Oracle（Stage 56） | 78.13% | 9.38% | **32.81%** |
| 多动作真实 Oracle（Stage 58） | 85.94% | 7.81% | 18.75% |

## 3. 结论

1. 多动作单步后果确实被成功传入决策网络，但没有提高目标环境恢复率；
2. 当前瓶颈不是“只查询一个动作”这么简单；
3. 单步后果集合仍然没有提供长期动作序列的价值结构；
4. DeepONet 动作评分 trunk 在新动力学下不能稳定把单步效果转换为长程策略；
5. 这进一步支持重新设计为“动力学模型 + 长程价值/可达性算子”，而不是继续扩大单步 token 或动作基数量。

## 4. 研究方向变化

下一步应重点测试：

- 多步真实 Oracle rollout；
- 目标函数/可达性函数作为决策接口；
- 动力学条件的 value operator，而不是单步动作评分；
- 直接学习动作序列或短期轨迹分布。
