# 阶段三：功能分离决策网络验证

## 结构

新决策网络显式分为：

\[
a=\tanh\left(
\pi_{task}(s)+
\sum_{k=1}^{K}z_k B_k h_{task}(s)
\right).
\]

task trunk 只接收当前状态；物理潜变量只能进入 `physics_basis` 调制分支。训练中加入物理 basis 正交和 task/physics 重叠正则。

## 结论

功能分离解决了决策网络 task 分支绕过物理分支的结构问题，但冻结的认知系数仍然无法驱动决策。当前瓶颈进一步收敛为：认知表示必须在联合训练中被塑造成“决策物理分支可用”的功能潜空间。

下一步在该分离结构上进行联合训练：保持 task trunk 独立，只让反事实决策损失更新认知编码器和物理 basis，并比较冻结、交替更新和完全联合更新三种策略。
