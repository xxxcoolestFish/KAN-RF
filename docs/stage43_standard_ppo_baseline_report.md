# Stage 43：普通 PPO 决策基线上限

## 实验目的

在完全移除认知网络、物理参数传递和 ProtoKAN 的情况下，测试当前连续动作 Acrobot 任务能否被标准策略—价值强化学习框架解决。

## 训练设置

* actor：目标条件 Gaussian MLP；
* critic：目标条件 MLP value network；
* 算法：PPO + GAE；
* 初始状态：悬垂状态附近的小扰动，而非随机全状态；
* 训练物理参数：`(7.35, 0.0, 0.8, 0.8)`；
* 动作：连续一维，范围 `[-1, 1]`；
* rollout horizon：256；
* 评估时域：500 步；
* 训练奖励：基于末端高度的平滑任务奖励和成功奖励，不使用认知模型或能量教师；
* 随机种子：0、1、2；
* 每个种子测试状态数：64。

## 结果

| seed | 最终成功率 | 平均最大高度 |
|---:|---:|---:|
| 0 | 87.5% | 1.516 |
| 1 | 89.1% | 1.429 |
| 2 | 92.2% | 1.574 |
| **平均** | **89.6%** | — |

seed=0 在中间评估阶段曾达到 93.75%，说明继续增加训练量仍可能进一步提升。

训练曲线显示，seed=0 的成功率从第 1 轮的 0%，提升到第 30 轮约 84%，最终稳定在 87.5% 左右；seed=1、2 也出现相似的持续提升趋势。

## 结论

1. 当前任务确实可以被标准强化学习策略解决；
2. 之前固定悬垂状态下 PPO 为 0% 的结果主要来自训练时域、探索强度和训练量不足，而不是任务本身不可学；
3. 普通 MLP actor 已经达到约 90% 的源环境成功率，因此它现在是合格的决策上限基线；
4. 下一步可以把完整 ProtoKAN 嵌合 actor 接入完全相同的 PPO 训练协议，比较其是否在相同样本量下达到相近成功率，以及是否在物理参数变化后恢复更快；
5. 只有当嵌合 actor 在源环境至少接近这个基线后，才有意义讨论认知参数对泛化能力的贡献。
