## 1. 当前框架（改进后）

### 认知网络

```
Φ(s): 固定 B-spline KAN 字典（源阶段训练，目标阶段冻结）
W_t: 在线 RLS / 批量最小二乘拟合
T_t: 全局控制增益变换（3×3 或对角）

目标认知: f̂_t(s, δa) = b₀(s) + Φ(s)·W_t + G₀(s)·T_t·δa
控制等价反解: δa★ = argmin ||f̂_t(s, δa) - e₀(s)||²
最终动作: a = clip(π₀(s) + δa★)
```

### 认知改进

| 改进 | 状态 | 效果 |
|:---|:---|:---|
| 谱正则化（η=0.2 mode=mean） | ✅ | combo_medium 三种子不回归，friction_070 小幅改善 |
| 平滑正则化（λ=10） | ✅ | friction_070 +9.7（净正！），combo_medium −1.2（可接受） |
| 对角线 T_t | ✅ | 与全 T_t 无显著差异——G_t 不是瓶颈 |
| 物理 PCA 提取 | ✅ | W_t 前 4 PC 捕获 93% 方差，质量/摩擦/执行器分离，种子一致 |

### 核心诊断发现

```
G₀(s) vs 真实 G_t(s) 余弦: 0.962  ← G₀ 在目标状态上方向很准
估计 G_t vs 真实 G_t 余弦: 0.611  ← T_t 拟合引入旋转
修正改善比例:            25%    ← 每 4 次修正仅 1 次有用
闭环回报恢复:           341→406 ← 有改善但绝对值很低
```

## 2. 决策网络探索

### 问题

决策网络 π(s, z) 需要：
1. 在源物理（z=[1,1,1]）下训练后，能外推到未见的 z
2. z 来自认知 PCA 提取的紧凑物理表示

### 尝试的方案

| 方案 | 架构 | 步数 | 源物理回报 | 结论 |
|:---|:---|:---|:---|:---|
| MLP PPO (对照) | π(s) MLP[256,256] | 500K | **3503** | 标准基准 |
| B-spline KAN 直连 | B-spline(298)→Linear→a | 200K | 231 | ❌ |
| B-spline KAN + MLP | B-spline(298)→MLP[256,256]→a | 500K | 129 | ❌ 加 MLP 反而更差 |
| ProtoKAN 直连 | ProtoKAN(256)→Linear→a | 500K | 549 | ❌ 最好但仍仅 16% |
| ProtoKAN + L2 | 同上 + L2 正则化 | 150K | 244 | ❌ L2 有害 |
| ProtoKAN + z | 同上 + z=[1,1,1] 输入 | 150K | 216 | ❌ 加 z 有害 |

### 根本原因

KAN 特征（B-spline 或 ProtoKAN）→ 单层 Linear Actor 表达能力远不及 MLP PPO 的 2 层 ReLU + 共享特征表示。KAN 适合认知网络（结构化函数逼近），不适合梯度驱动的 RL 策略优化。

## 3. 当前卡点和下一步

### 已解决的问题

1. ✅ 谱正则化保住了 combo_medium 主结果
2. ✅ 平滑正则化首次给出 friction_070 净正 (+9.7)
3. ✅ W_t PCA 验证了物理特征可提取、可分离、种子稳定
4. ✅ G₀ 方向泛化验证（余弦 0.962）——源认知泛化没问题

### 未解决的问题

1. ❌ 决策网络架构：KAN 策略不可行，需要新方案
2. ❌ 外推机制：单一源训练后如何泛化到新 z
3. ❌ friction_070 残存漂移：2048 处仍未完全修复
4. ❌ payload_125 负迁移：可达性判定未实现

### 待探索的外推方案

| 方案 | 思路 | 风险 |
|:---|:---|:---|
| 残差锚定 | π = π_source + Δπ(s,z)，Δπ 小网络 + L2 | Δπ 可能学不到有用信号 |
| FiLM 调制 | z → (γ,β) 调制 MLP 隐层 | z 为常数时可能退化回 MLP |
| Lipschitz 约束 | 谱范数归一化保证平滑 | 实现复杂，可能限制容量 |
| 认知修正 + 门控 | δa_cog + 学习 α | 门户耦合，调参困难 |

## 4. 核心洞察

```
认知网络（KAN / B-spline）:
  ✅ 结构化、可解释、从数据拟合物理规律
  ✅ 平滑正则化后系数自然分离物理变化
  ✅ PCA 提取到紧凑物理表示

决策网络（MLP PPO）:
  ✅ 梯度驱动的 RL 优化 → 高维非线性策略
  ❌ 外推能力差 → 训练时没见过新 z

两者需要互补而非替代:
  认知管物理 → 提取 z
  决策管任务 → 用 z 调节行为
  关键：z 的外推机制（当前最大开放问题）
```
