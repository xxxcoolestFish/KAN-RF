# Stage 59：认知网络与决策网络联合在线适应

## 实验目的

验证完整框架在物理参数改变后是否能够通过以下两个同步过程恢复性能：

1. 认知网络使用目标环境中的真实转移持续更新预测参数；
2. 决策网络自身的策略参数继续通过任务损失更新，同时直接读取更新后的认知网络。

因此，本实验不是冻结决策网络的单独认知更新实验，而是完整的联合在线适应实验。

## 更新流程

源环境预训练完成后，在目标环境中重复执行：

```text
s_t -> 决策网络 -> a_t -> 真实环境 -> s_{t+1}
                                      |
                       +--------------+--------------+
                       |                             |
                 认知预测更新                    决策 PPO 更新
                 phi <- phi'                 theta_policy <- theta'
                       |
                 认知参数实时进入决策网络
```

认知更新目标为真实状态转移预测损失；决策更新目标为环境任务奖励和价值估计。决策网络中的认知部分与认知对象共享，因此认知参数更新后会直接影响下一次决策前向传播。

## 设置

- 源物理参数：`(7.35, 0.0, 0.8, 0.8)`
- 目标物理参数：`(13.475, 0.06, 0.90, 1.10)`
- ProtoKAN 认知网络，8 维历史上下文
- 源环境 PPO 训练：30 轮
- 目标环境联合适应：30 轮
- 目标环境数据：真实环境转移
- 随机种子：0（首轮完整运行）

## 结果

| 阶段 | 成功率 | 平均最大高度 |
|---|---:|---:|
| 源环境训练结束 | 89.06% | 1.487 |
| 目标环境零样本 | 10.94% | 0.382 |
| 目标环境联合适应结束 | 31.25% | 0.800 |

目标环境适应过程中的认知预测损失和成功率如下：

| 适应轮次 | 认知更新损失 | 成功率 |
|---:|---:|---:|
| 1 | 1.284e-3 | 0.00% |
| 5 | 2.123e-2 | 25.00% |
| 10 | 1.084e-2 | 18.75% |
| 15 | 5.302e-3 | 18.75% |
| 20 | 1.782e-3 | 18.75% |
| 25 | 3.935e-4 | 25.00% |
| 30 | 1.788e-4 | 37.50% |

## 初步结论

1. 认知网络确实在学习目标环境的动力学：预测损失总体下降约一个数量级。
2. 更新后的认知网络被决策网络继续使用，联合训练后成功率从 10.94% 恢复到 31.25%。
3. 目前恢复幅度仍然有限，说明“认知规律已经被学到”并不等于“决策网络已经能够充分利用这些规律”。
4. 当前结果同时包含认知参数更新和决策策略参数更新的贡献，不能将 31.25% 单独归因于其中某一个网络。
