# 阶段五：单步转移数据与流式认知网络

## 接口修正

当前框架改为把

\[
    (s_t,a_t,s_{t+1})
\]

作为唯一的基础数据单元。训练集可以包含任意多条转移；序列只用于模拟系统在线连续收到这些单步数据的过程，不再把固定长度历史窗口定义为认知网络接口。

认知网络维护在线状态：

\[
z_{t+1}=U_\theta(z_t,s_t,a_t,s_{t+1}),\qquad
\hat s_{t+1}=F_\theta(s_t,a_t,z_t).
\]

预测时先使用旧的 (z_t) 预测，观测到真实 (s_{t+1}) 后再更新到 (z_{t+1})，避免目标泄漏。

## 解释

流式更新明显降低了序列后段的动力学预测误差，说明认知状态正在利用新收到的转移数据。但同环境与异环境的潜状态距离没有分离，表明“能预测”与“形成跨轨迹稳定的物理接口”仍是两个问题。

下一步应在不规定每个维度语义的前提下增加功能等价约束，或直接让决策接收器使用认知状态诱导的算子响应，并继续进行多随机种子验证。
