# Stage 23：多步认知训练与终端价值能量控制验证

## 1. 目的

本实验验证两项从传统模型式强化学习借鉴的机制：

1. 认知网络采用 1、2、4、8 步自由滚动的 horizon curriculum，减少多步预测误差累积；
2. 决策网络只做 4 步短时域能量优化，并加入 TD 训练的终端价值网络，而不是直接对 64 步轨迹反向传播。

动作仍然由认知网络内部的可微梯度路径生成，没有动作教师或 MPC 动作标签。

## 2. 训练设置

- 认知网络：`ProtoKAN([state, action] -> next_state)`。
- 认知训练：300 步，序列批大小 32，滚动 horizon 从 1 逐步增加到 8。
- 能量网络：先用一步任务代价拟合 100 步。
- 终端价值网络：使用真实转移的 TD 目标更新 150 步，折扣因子 `γ=0.95`。
- 决策训练：4 步短时域模型滚动，更新能量网络 150 步。
- 测试：固定种子 `20260718` 的 20 个初始状态，在预训练 Acrobot 环境中真实滚动 64 步。

## 3. 结果

### 3.1 认知网络

| 指标 | 结果 |
|---|---:|
| 训练损失首步 | 0.2205 |
| 训练损失末步 | 0.01183 |
| 一步模型误差 | 0.00189 |
| 两步模型误差 | 0.00378 |
| 四步模型误差 | 0.00937 |
| 八步模型误差 | 0.02408 |

多步误差仍然随 horizon 增加，但相比只优化单步预测，认知网络已经具备了更明确的自由滚动训练目标。

### 3.2 决策网络

| 阶段 | 成功率 | 平均最大高度 |
|---|---:|---:|
| 一步能量拟合后 | 14/20 = 70% | 1.4194 |
| 终端价值 TD 更新后 | 15/20 = 75% | 1.4056 |
| 短时域能量训练后 | 15/20 = 75% | 1.4056 |

终端价值 TD 更新带来 1 个测试状态的提升；短时域能量训练没有继续提升成功率，而且训练损失从 13.52 上升到 21.69。

## 4. 结论

本实验验证了两个判断：

1. 多步认知训练是有效的训练方向，但单纯降低模型滚动误差还不足以解决决策问题；
2. 终端价值比直接展开长轨迹更稳定，至少带来了 70% 到 75% 的提升；
3. 当前短时域能量目标仍然不稳定，能量函数没有形成适合动作梯度下降的长时域势能表面。

因此，下一步不应继续盲目增加模型 rollout 长度，而应优先把能量网络改成真正的任务条件化 cost-to-go，并使用目标网络、TD3/SAC 式双价值约束或动作优化信赖域来稳定能量更新。
