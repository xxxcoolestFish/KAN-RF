# ProtoKAN 可达图路由：第一阶段快速验证

## 1. 验证目标

本阶段不测试物理泛化，也不引入 ProtoKAN 预测误差。首先使用精确 MuJoCo
动力学回答：

> 如果认知模型能够准确给出状态转移，带动作标签的局部状态可达图能否通过路由
> 产生可直接执行的底层动作序列，并在固定 Pusher 环境中完成任务？

只有该问题成立，才值得将精确动力学替换为可在线更新的 ProtoKAN。

## 2. 最小架构

每个真实控制时刻从当前状态建立一张局部有向图：

1. 节点保存完整模拟器状态；
2. 边保存一个可直接传给环境的 7 维底层动作；
3. 使用精确 MuJoCo 动力学展开后继节点；
4. 对近似重复的完整观测状态自动标准化、量化并合并；
5. 每层保留固定宽度的最优节点；
6. 找到最优路径后只执行第一条边，再根据真实反馈重新构图。

第一版配置为深度 6、每个节点 24 个候选动作、束宽 48。每条边严格对应一个
真实环境步，因此预测与执行没有动作重复造成的时间尺度差异。

## 3. 首轮失败及定位

只使用 6 步累计环境奖励时，25 个真实步骤全部选择零动作：

- 物体到目标距离始终为 0.2577；
- 每层最优路线也无法改变物体位置；
- 模型预测与真实执行的观测误差约为 \(10^{-8}\)；
- 图节点合并率约为 11%。

因此失败不是动力学误差、状态恢复错误或过度合并，而是短时域奖励中的动作代价
立即生效，机械臂接近物体的收益却存在延迟，零动作在短图中占优。

## 4. 一次原则性修正

图路由必须具有指向任务目标的启发，而不能只有短期累计奖励。修正版使用环境奖励
中原本已经定义的状态部分：

\[
r_{\mathrm{state}}
=
r_{\mathrm{dist}}+r_{\mathrm{near}},
\]

并以有限剩余时域的保持状态回报作为终端估计。该信息来自任务定义，不包含质量、
摩擦、阻尼等人工物理参数。

修正后前 25 步中，规划路线的机械臂—物体距离从约 0.49 降至 0.12，证明图路由
已经能够完成朝物体接近的阶段。

## 5. 完整 100 步结果

同一随机种子下运行完整回合：

| 指标 | 结果 |
|---|---:|
| 初始物体—目标距离 | 0.2577 |
| 最终物体—目标距离 | 0.2573 |
| 推进距离 | 0.0004 |
| 最小机械臂—物体距离 | 约 0.075 |
| 成功率 | 0% |
| 平均单步规划时间 | 548.9 ms |
| 模型—真实观测误差 | 约 \(10^{-8}\) |

路由器在约 30 步内接近物体，随后稳定选择零动作。逐层日志显示，即使是保留节点中
接触距离最小的路线也停留在约 0.077，无法形成有效接触，更无法推动物体。

## 6. 当前结论

实验验证了三点：

1. 带动作标签的图路径可以直接转换成底层动作，不需要额外执行网络；
2. 精确状态转移可以稳定构图，预测和真实执行接口正确；
3. **状态转移模型本身不足以产生有效的连续控制图。**

当前结构性瓶颈是图的边如何产生。单关节动作基元与少量随机动作可以完成接近，
但无法稳定发现接触和推动所需的多关节协调动作。如果只通过增加动作数量、图深度和
束宽解决，计算量会快速增长，并逐渐退化为比 CEM 更昂贵的动作序列采样。

因此第一阶段尚未通过，不能接入 ProtoKAN 或宣称泛化能力。下一步若继续该方向，
研究重点不应是扩大图，而应是：

> 如何从 KAN 动力学的局部结构中直接生成少量、具有控制意义的动作条件边，使可达图
> 在连续高维动作空间中仍能覆盖接触和推动等关键状态变化？

这也是该方向能否形成方法创新的真正分界点。
