# ProtoKAN 可达图路由：第一阶段快速验证

## 1. 验证目标

本阶段不测试物理泛化，也不引入 ProtoKAN 预测误差。首先使用精确 MuJoCo
动力学回答：

> 如果认知模型能够准确给出状态转移，带动作标签的局部状态可达图能否通过路由
> 产生可直接执行的底层动作序列，并在固定 Pusher 环境中完成任务？

只有该问题成立，才值得将精确动力学替换为可在线更新的 ProtoKAN。

## 2. 最小架构

每个真实控制时刻从当前状态建立一张局部有向图：

1. 节点保存完整模拟器状态；
2. 边保存一个可直接传给环境的 7 维底层动作；
3. 使用精确 MuJoCo 动力学展开后继节点；
4. 对近似重复的完整观测状态自动标准化、量化并合并；
5. 每层保留固定宽度的最优节点；
6. 找到最优路径后只执行第一条边，再根据真实反馈重新构图。

第一版配置为深度 6、每个节点 24 个候选动作、束宽 48。每条边严格对应一个
真实环境步，因此预测与执行没有动作重复造成的时间尺度差异。

## 3. 首轮失败及定位

只使用 6 步累计环境奖励时，25 个真实步骤全部选择零动作：

- 物体到目标距离始终为 0.2577；
- 每层最优路线也无法改变物体位置；
- 模型预测与真实执行的观测误差约为 \(10^{-8}\)；
- 图节点合并率约为 11%。

因此失败不是动力学误差、状态恢复错误或过度合并，而是短时域奖励中的动作代价
立即生效，机械臂接近物体的收益却存在延迟，零动作在短图中占优。

## 4. 一次原则性修正

图路由必须具有指向任务目标的启发，而不能只有短期累计奖励。修正版使用环境奖励
中原本已经定义的状态部分：

\[
r_{\mathrm{state}}
=
r_{\mathrm{dist}}+r_{\mathrm{near}},
\]

并以有限剩余时域的保持状态回报作为终端估计。该信息来自任务定义，不包含质量、
摩擦、阻尼等人工物理参数。

修正后前 25 步中，规划路线的机械臂—物体距离从约 0.49 降至 0.12，证明图路由
已经能够完成朝物体接近的阶段。

## 5. 完整 100 步结果

同一随机种子下运行完整回合：

| 指标 | 结果 |
|---|---:|
| 初始物体—目标距离 | 0.2577 |
| 最终物体—目标距离 | 0.2573 |
| 推进距离 | 0.0004 |
| 最小机械臂—物体距离 | 约 0.075 |
| 成功率 | 0% |
| 平均单步规划时间 | 548.9 ms |
| 模型—真实观测误差 | 约 \(10^{-8}\) |

路由器在约 30 步内接近物体，随后稳定选择零动作。逐层日志显示，即使是保留节点中
接触距离最小的路线也停留在约 0.077，无法形成有效接触，更无法推动物体。

## 6. 当前结论

实验验证了三点：

1. 带动作标签的图路径可以直接转换成底层动作，不需要额外执行网络；
2. 精确状态转移可以稳定构图，预测和真实执行接口正确；
3. **状态转移模型本身不足以产生有效的连续控制图。**

当前结构性瓶颈是图的边如何产生。单关节动作基元与少量随机动作可以完成接近，
但无法稳定发现接触和推动所需的多关节协调动作。如果只通过增加动作数量、图深度和
束宽解决，计算量会快速增长，并逐渐退化为比 CEM 更昂贵的动作序列采样。

因此第一阶段尚未通过，不能接入 ProtoKAN 或宣称泛化能力。下一步若继续该方向，
研究重点不应是扩大图，而应是：

> 如何从 KAN 动力学的局部结构中直接生成少量、具有控制意义的动作条件边，使可达图
> 在连续高维动作空间中仍能覆盖接触和推动等关键状态变化？

这也是该方向能否形成方法创新的真正分界点。

## 7. 局部控制敏感性边的快速验证

随后保持图深度 6、每节点 24 个动作、束宽 48 和任务评分完全不变，只替换动作边的
生成方式。使用精确动力学有限差分估计

\[
B(s)=\frac{\partial F^{3}(s,a)}{\partial a},
\]

再从其右奇异向量生成多关节协同动作，并额外加入使原任务状态奖励增长最快的动作
方向。未来替换为 ProtoKAN 时，同一敏感性可以直接通过自动微分获得。

同一初态的 40 步快速对照结果：

| 指标 | 原始动作边 | 局部敏感性动作边 |
|---|---:|---:|
| 物体—目标距离 | 约 0.2575 | 0.2572 |
| 最小机械臂—物体距离 | 约 0.075 | 约 0.073 |
| 是否形成有效推动 | 否 | 否 |
| 40 步末机械臂—物体距离 | 约 0.075 | 0.0883 |

敏感性矩阵在整个过程中保持满秩 7，初始奇异值约为
\([3.081,3.004,2.677,1.543,1.027,0.212,0.146]\)，说明数值估计和控制方向
并未退化。动作也确实由多个关节共同组成。但在机械臂接近物体后，任务动作梯度范数
从约 \(5.3\times10^{-3}\) 降至 \(1.9\times10^{-3}\)，路线无法跨过接触边界，
随后机械臂反而退开。

这揭示了更根本的原因：Pusher 是混合接触系统。接触发生前，局部光滑模型看到的
主要是“动作改变机械臂”，而“动作改变物体”的一阶导数接近零；只有跨过有限距离并
进入接触模式后，动作才会影响物体。因而即使局部 Jacobian 满秩，它也不能单独生成
跨模式的有效推动边。

本实验否决“仅靠单点局部微分生成动作边”的最小形式。若继续，应研究有限幅度、
多步、能够跨越接触模式的可达算子，而不是继续放大局部图或只提高 Jacobian 精度。

## 8. SAC 已知有效边诊断：评分同样是瓶颈

为区分“图中缺少有效动作边”和“有效边进入图后仍被错误评分”，在每个图节点额外
加入训练好 SAC Actor 的确定性动作。SAC 只提供一条候选边，图路由器仍自主决定
是否保留和执行；其余图配置完全不变。

同一初态、同样 60 个真实步骤的结果：

| 方法 | 物体推进距离 | 最终物体—目标距离 | SAC 边选择率 |
|---|---:|---:|---:|
| 图路由 + SAC 候选边 | 0.00003 | 0.2576 | 0% |
| 直接执行 SAC | 0.0957 | 0.1620 | 100% |

图最终动作与 SAC 建议动作的平均欧氏距离为 2.636。SAC 的第一步动作范数为 1.736，
会立即产生较大的控制代价，但后续能够建立接触并持续推动；图的短时域评分则系统性
拒绝了这些“当前昂贵、长期有效”的动作。

因此当前失败不再能够只归因于动作边生成。即使一条已知有效的局部策略边明确进入
图中，当前终端启发和逐层束剪枝仍会在长期收益出现之前将其删除。状态转移模型只能
回答“执行后会发生什么”，不能单独回答“暂时付出代价是否值得”。

若继续 routing 方向，至少需要同时具备：

1. 能跨接触模式的有限时域边或闭环 option；
2. 能估计长期任务结果的 cost-to-go / Critic；
3. 不在延迟收益出现前删除必要路径的可达性剪枝。

这与 RL-RRT 使用 RL 局部控制器和学习可达性估计器的设计一致，也说明“只有
ProtoKAN 状态转移图”不足以承担完整决策。
