# 时变反馈可达通道：三条代表性宏边验证

## 本检查点要解决的问题

上一版把一条宏边表示成“经过动作扰动得到的终点椭球”。实验已经证明，这种集合只描述开环前向像，并不能保证存在反馈策略把受扰动状态送到终点。更严重的是，旧图的三条最短路边之间存在约 0.14--0.22 的状态跳跃，而经验通道尺度只有约 0.06；它们不是一条可以连续执行的轨迹。

本检查点因此不再扩大旧椭球，而是验证一个更严格的中间命题：

> 如果认知网络给决策网络的不是孤立终点，而是一条由局部动力学构造的时变反馈通道，那么一个不接收动作教师的共享决策网络，能否直接输出动作并稳定走完这条通道？

实验只验证三类代表性局部阶段，达到预设门槛后停止，没有继续运行完整 Acrobot 任务。

## 连续名义路线

当前使用精确 Acrobot 动力学作为 Oracle 认知模型。CEM 仅在通道构造阶段搜索 20 个分段常值动作，每段持续 24 步，得到一条连续 480 步的状态路线。路线在第 474 步进入成功集合，最大末端高度为 1.2698。

从路线中选择三个差异较大的连续片段：

1. 第 0 段：初始蓄能；
2. 第 8 段：高速运动；
3. 第 19 段：末端摆起。

这里的构造动作在通道生成后被设为私有信息。Actor 的输入中没有 CEM 动作，也没有后述 LQR 增益。

## 数学结构

### 1. 局部切空间

六维 Acrobot 状态中的两对正余弦是冗余坐标。代码先把状态映射为四维局部坐标

\[
x=(\theta_1,\theta_2,\bar\omega_1,\bar\omega_2),
\]

角度误差通过圆周最短差计算，从而避免 \(-\pi/\pi\) 分支处的不连续。

### 2. 时变局部动力学

对名义轨迹 \((\bar x_t,\bar a_t)\) 上的每个截面，通过认知动力学的自动微分得到

\[
\delta x_{t+1}\approx A_t\delta x_t+B_t\delta a_t.
\]

有限时域 Riccati 递推给出只用于构造和认证的反馈律

\[
\delta a_t=K_t\delta x_t.
\]

这一步回答“该片段在局部是否存在反馈余量”，而不是把 LQR 动作交给决策网络模仿。

### 3. 全矩阵时变通道

从每条边起点采样角度和速度扰动，用构造反馈律滚动 1024 条闭环轨迹。在每个时刻估计误差协方差 \(\Sigma_t\)，得到带角度—速度耦合方向的椭球截面

\[
\mathcal T_t=\{x:\delta x_t^\top P_t\delta x_t\le r_t\},
\qquad P_t=(\Sigma_t+\epsilon I)^{-1}.
\]

半径 \(r_t\) 取经验 Mahalanobis 距离的 99% 分位数。与旧版逐维尺度不同，\(P_t\) 是完整的 \(4\times4\) 矩阵，因此保留角度与速度之间的耦合方向。

### 4. 决策接口

共享 Actor 接收 15 维输入：

\[
[s_t,\ L_t\delta x_t,\ \Delta x_{t\to t+1},\ t/H],
\]

分别对应当前六维状态、通道截面白化误差、下一截面的四维局部方向和归一化相位。Actor 直接输出一维动作。Critic 使用同一接口估值，PPO 根据真实动力学反馈训练。

训练奖励只衡量通道距离进展、是否位于截面内、末端是否完成以及动作幅度；没有名义动作回归损失，也没有 LQR 动作教师。

## 正式结果

正式配置为 150 轮、256 个并行环境、每条边 64 个独立测试扰动，随机种子为 0；最佳共享策略出现在第 50 轮。

| 指标 | 结果 |
|---|---:|
| 构造样本 LQR 末端完成率（三边） | 98.93% / 98.93% / 98.93% |
| 隐藏 LQR 认证器末端完成率（三边） | 100% / 95.31% / 100% |
| 随机常值动作完成率（三边） | 3.13% / 12.50% / 34.38% |
| 学习策略末端完成率（三边） | 100% / 98.44% / 100% |
| 学习策略总体完成率 | 99.48% |
| 学习策略全程留在通道内 | 98.96% |
| 打乱通道描述后的完成率 | 0% / 0% / 0% |
| 正确与错误通道描述的平均动作差 | 0.8257 |

预设通过条件是三条边各自不低于 95%。最低完成率为 98.44%，因此本检查点通过。

## 这次结果说明了什么

1. **旧方法的主要错误不是 Actor 天生学不会，而是认知接口给错了数学对象。** 孤立终点集合换成连续、时变、带耦合方向的反馈通道后，同样是直接动作策略，局部完成率从上一版三条路径边的 66.67% 提高到最低 98.44%。
2. **策略确实依赖认知描述。** 打乱三条通道描述后完成率归零，动作平均变化 0.8257；这排除了“Actor 忽略认知输入、只记固定控制律”的解释。
3. **通道本身具有反馈可执行性。** 独立扰动下隐藏 LQR 认证器的最低完成率为 95.31%，证明高成功率不是通过放大一个不可执行集合得到的。
4. **动作教师不是必要接口。** 构造动作和 LQR 增益都没有进入 Actor，Actor 只根据认知网络提供的几何通道和真实反馈学习直接动作。

## 尚未证明的部分

这个结果是结构可行性检查，不是项目最终结果：

- 动力学目前仍是 Oracle，还没有换回持续学习的 ProtoKAN；
- 只测试了源物理环境、三个局部片段和一个训练种子；
- 三个片段被独立重置测试，尚未串成完整 480 步闭环任务；
- 通道是离线构造的，还没有验证物理参数变化后由认知网络在线更新、重估通道并触发重规划；
- LQR 虽不作为动作教师，但参与了通道的构造，因此后续需要比较其他反馈可达集估计器。

因此当前严谨结论是：**“认知动力学 → 时变反馈可达通道 → 直接动作策略”这一信息传递接口在三个代表性连续片段上成立。** 下一阶段才应研究把通道构造算子接到持续学习的 ProtoKAN 上，并验证参数改变后的恢复曲线。
