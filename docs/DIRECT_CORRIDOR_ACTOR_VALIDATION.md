# 直接状态走廊 Actor 验证

## 1. 这一步验证什么

此前的反馈走廊实验仍然在运行时使用了隐藏的 CEM/LQR 控制器，只能证明走廊存在、在线认知更新能够改善走廊，不能证明一个神经网络能直接把走廊解码为动作。

本实验把问题严格拆成两层：

1. 构造器只生成一条按时间排列的**状态参考走廊**；
2. Actor 只能读取当前真实状态和未来状态走廊，使用环境奖励通过 PPO 学习直接输出动作。

CEM 的动作序列在状态参考构造完成后被丢弃；Actor 既看不到 CEM 动作，也看不到 LQR 增益或动作教师。因此，这一步验证的是“状态可达性信息能否被神经网络直接解码为反馈动作”，而不是动作模仿。

## 2. 网络结构

设当前状态为 \(x_t\)，未来 \(H=12\) 个走廊状态为 \(\bar x_{t+1:t+H}\)。第 \(k\) 个输入 token 是

\[
z_{t,k}=
\left[
\bar x_{t+k},\;
e(x_t,\bar x_{t+k}),\;
k/H
\right],
\]

其中 \(e\) 是考虑角度周期性的四维切空间误差。序列由一个 GRU 编码：

\[
h_t=\operatorname{GRU}(z_{t,1},\ldots,z_{t,H}),
\qquad
\mu_t=\operatorname{MLP}(h_t),
\qquad
a_t=\tanh(\mu_t+\sigma\epsilon).
\]

Actor 没有从当前状态直接通向动作头的旁路。当前状态只通过每个走廊 token 中的误差进入网络，所以 Actor 的前向传播必须经过走廊编码器。Critic 使用独立的同构 GRU 编码器，估计该“状态—走廊”条件下的价值。

Actor 共 19,010 个参数，实现在 `cpbn/corridor_policy.py`。

## 3. 训练目标

训练转移全部来自源环境的真实 Oracle 动力学，而不是认知模型滚动。即时奖励为

\[
r_t=
\operatorname{clip}(d_t-d_{t+1})
+0.08\mathbf 1[d_{t+1}\le 0.12]
+3\mathbf 1[\text{task success}]
-0.002a_t^2,
\]

其中 \(d_t\) 是当前真实状态到当前走廊截面的切空间距离。Actor 和 Critic 通过 PPO/GAE 更新；不存在动作回归损失。

训练从随机走廊相位及其扰动邻域启动，避免网络只会从固定初态复现一条轨迹。整程测试则从路线起点的小扰动分布出发，连续闭环执行 500 步。

## 4. 实验结果

强配置在第 40 轮取得最佳检查点。单次 32 条整程测试成功 28 条，即 87.5%；将走廊相位打乱后为 0/32。正确与错误走廊下的平均动作绝对差为 1.0615。这说明 Actor 的动作强烈依赖走廊，而不是绕过认知输入记住固定策略。

随后使用 5 个独立测试随机种子、每个种子 64 个初态做严格复测：

| 指标 | 结果 |
|---|---:|
| 正确走廊整程成功率 | 271/320 = 84.69% |
| 乱序走廊整程成功率 | 2/320 = 0.63% |
| 各种子成功率范围 | 71.88%--93.75% |
| 平均局部段末跟随率 | 72.72% |
| 最弱局部段末跟随率 | 1.88% |

末段的“段末跟随率”会低估任务表现：参考路线在第 474 步已经成功，而该指标仍要求控制器在成功后继续跟到第 480 步。把“任务成功或到达段末”作为完成条件后，末段由 1.88% 变为 95.31%。不过第 14、16 段的对应完成率仍只有 25.00% 和 28.75%，这是真实的中途控制薄弱点。

一次针对困难相位加权采样的继续训练没有改善结果：最佳点仍是继续训练前的第 0 轮，独立整程复测反而为 78.13%。这说明简单增加困难片段的采样会改变 PPO 的状态分布并破坏已经学到的其他阶段，不能当作可靠修复。

## 5. 当前结论

这一步得到的是一个明确的正结果：**不提供任何动作教师时，直接 Actor 能够从有序状态走廊中解码出具有长时域任务能力的动作，而且打乱走廊会使能力基本消失。** 因而“认知动力学 → 状态可达走廊 → 直接策略”的接口是可学习的。

但它还没有达到进入目标环境泛化实验所需的可靠性。主要问题不是认知参数干扰 Actor，因为本实验使用了正确的源状态走廊；问题出在走廊解码器自身：

1. 训练 rollout 长度为 96，而完整路线长 480，局部误差在整程执行中形成分布偏移；
2. 走廊相位按时钟强制前进。Actor 一旦落后，未来走廊仍继续前移，参考目标可能越走越远，缺少基于真实反馈的相位重定位；
3. 单一 GRU 隐状态需要同时压缩路线方向、局部反馈误差和不同动力学阶段，困难阶段存在表示与优化冲突；
4. 直接 PPO 对困难阶段加权会遗忘其他阶段，说明需要保持全路线分布的课程学习或约束更新，而不是单纯重采样。

因此本检查点先停在源环境解码能力验证。下一步应首先把“固定时钟相位”改成可微或离散的反馈相位估计，使控制器在偏离后能够重新定位到走廊中的可达截面；待源环境多种子成功率稳定通过门槛后，再接入在线 ProtoKAN 生成的动态走廊，测量物理参数变化后的恢复曲线。
