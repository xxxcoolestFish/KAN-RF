# Stage 45：多种子、多参数变化对照

## 统一设置

两类 actor 都只在源参数 `(7.35, 0.0, 0.8, 0.8)` 上训练 30 轮，使用 3 个随机种子、64 个并行环境、256 步 rollout、2 个 PPO epoch。测试使用同一批悬垂向下小扰动状态，确定性动作，500 步。

## 参数变化 A：`(9.8, 0.04, 1.1, 0.9)`

| seed | 普通 PPO | ProtoKAN 嵌合 PPO |
|---:|---:|---:|
| 0 | 78.1% | 68.8% |
| 1 | 89.1% | 85.9% |
| 2 | 78.1% | 75.0% |
| **均值** | **81.8%** | **76.6%** |

这个变化方向比源任务容易，不能单独当作泛化优势证据。

## 参数变化 B：`(13.475, 0.06, 0.90, 1.10)`

| seed | 源环境 | 普通 PPO 变化后 | ProtoKAN 嵌合变化后 |
|---:|---:|---:|---:|
| 0 | 84.4% | 4.7% | 1.6% |
| 1 | 70.3% | 6.3% | 1.6% |
| 2 | 78.1% | 4.7% | 15.6% |
| **均值** | **77.6%** | **5.2%** | **6.3%** |

在这个更难的参数变化上，嵌合 actor 的均值仅比普通 PPO 高 1.0 个百分点，且标准差显著更大（约 8.1 vs 0.9 个百分点），目前不能认为存在可靠泛化优势。

## 阶段结论

当前认知参数嵌入机制已经能在源环境完成任务，但在零样本物理变化上尚未显示稳定优势。下一步不能直接宣称“认知网络带来泛化”，而应先检查：

1. 嵌合 actor 的源环境训练是否达到与普通 PPO 相同的成功率；
2. ProtoKAN 的单步预测误差在变化参数上是否足够小；
3. 决策头是否能将预测状态中的物理变化转换为动作修正；
4. 再加入在线认知更新，画出真实环境反馈下的恢复曲线。
