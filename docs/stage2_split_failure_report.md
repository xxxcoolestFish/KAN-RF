# 阶段二：物理分支与轨迹分支分离实验

## V1：仅结构分离

V1 将完整历史输入轨迹记忆分支，将状态差分和动作输入物理 token 分支。动力学预测同时使用两者。

结果（300 步）：

| seed | 结构 | 1 步误差 | 4 步误差 | 有效物理 token |
|---:|---|---:|---:|---:|
| 42 | single | 0.001159 | 0.003758 | 5.82 |
| 42 | split V1 | 0.001878 | 0.008968 | 0 |
| 43 | single | 0.001582 | 0.006005 | 4.12 |
| 43 | split V1 | 0.001730 | 0.007745 | 0 |

V1 的轨迹分支直接解释了动力学，物理 token 被门控关闭。因此，结构隔离本身不能防止信息旁路。

## V2：当前状态分支 + 反事实约束

V2 让快速分支只接收当前状态，并使用相同状态/动作、不同隐藏动力学的反事实样本训练。理论上，只有物理分支能够解释两种不同的下一状态。

结果：

| seed | 1 步误差 | 4 步误差 | 反事实预测差异 | 真实差异 | 有效 token |
|---:|---:|---:|---:|---:|---:|
| 42 | 0.001151 | 0.008631 | 0.06464 | 0.01326 | 0 |
| 43 | 0.001284 | 0.009787 | 0.05456 | 0.01281 | 0 |

V2 防止了完全的旁路，但物理残差分支过度响应，预测差异约是真实差异的 4–5 倍；门控值低于 0.5，说明当前门控标定也不可靠。

在加入反事实差分损失和残差能量正则的快速试验中，预测差异降至 `0.02179`，真实差异为 `0.01292`，但仍未达到稳定匹配。

## 当前结论

物理/轨迹分离是必要的，但还不充分。下一步必须把物理分支设计成有界、可校准的参数传递算子：

\[
\hat{s}'=F_{base}(s,a)+\alpha\tanh(R_\psi(s,a,z_{phys}))
\]

并同时使用反事实绝对损失、反事实差分损失和残差幅度约束。当前尚未进入决策网络接收实验。
