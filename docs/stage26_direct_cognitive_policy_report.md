# Stage 26：直接认知解码策略初步验证

## 1. 目的

本实验验证更接近最终目标的结构：认知网络只负责预测，决策网络将认知网络作为冻结子模块，通过认知网络对固定动作探针的响应直接输出动作。部署时不使用能量函数、Cost-to-Go 或动作梯度下降。

## 2. 结构

认知网络：

```text
ProtoKAN([state, action] -> next_state)
```

决策网络首先用三个固定动作探针 `[-1, 0, +1]` 查询认知网络：

```text
state + goal + Cφ(state,-1) + Cφ(state,0) + Cφ(state,+1)
       + 相对零动作的响应差分
```

然后通过一个 ProtoKAN 策略头直接输出：

```text
ProtoKAN([48, 32, 1]) -> tanh -> action
```

认知网络和策略头的损失完全分开：认知网络使用预测损失，策略头使用多步模型任务损失；认知参数在决策训练中冻结。

## 3. 结果

训练只使用源物理环境，测试使用相同的 20 个初始状态。

| 环境 | 直接策略成功率 |
|---|---:|
| source | 16/20 = 80% |
| factor_1 | 17/20 = 85% |
| factor_2 | 15/20 = 75% |
| factor_3 | 11/20 = 55% |
| factor_4 | 11/20 = 55% |
| heldout_1 | 16/20 = 80% |
| heldout_2 | 14/20 = 70% |

认知网络在目标环境上的单步 MSE 约为 `0.0062–0.0068`，仍然保持较小；但直接决策成功率在部分物理参数下下降到 55%。

## 4. 结论

这轮实验验证了三个结构事实：

1. 决策网络可以不依赖运行时动作梯度下降，而由一次前向传播直接给出动作；
2. 认知网络可以作为决策网络的物理响应编码器，两个损失可以完全分开；
3. 直接策略头目前能够在源环境工作，但对部分动力学参数的泛化还不稳定。

因此，当前最主要的问题不是“是否必须使用能量梯度求动作”，而是直接策略头如何把认知网络的物理响应解码为长程有效动作。下一步应使用更稳定的长程策略训练目标和在线认知更新，而不是重新引入运行时动作优化。
