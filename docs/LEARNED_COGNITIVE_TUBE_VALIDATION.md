# 学得认知动力学的通道构造验证

## 目的

Oracle 实验已经证明“时变反馈可达通道”可以成为认知网络与直接动作策略之间的有效接口。本轮把精确动力学替换为只在单一源环境转移上训练的 ProtoKAN，回答两个不同问题：

1. ProtoKAN 的局部动力学和 Jacobian 是否足以构造反馈通道？
2. ProtoKAN 是否足以进行 480 步开环模型滚动并规划完整路线？

这两个问题必须分开。局部通道只依赖短时域动力学；完整路线规划会把每一步微小误差反复复合。

## 认知模型

认知网络是一个未做物理语义分割的单体 ProtoKAN：

\[
[s_t,a_t]\xrightarrow{\mathrm{ProtoKAN}[7,32,4]}\Delta x_t,
\qquad
\hat s_{t+1}=s_t\oplus\Delta x_t.
\]

其中 \(\oplus\) 只负责 Acrobot 状态表示的几何约束：两对角度正余弦保持在单位圆上，归一化速度保持在有效范围内。网络共有 6002 个参数，不接收物理参数标签，也没有预先划分重力、阻尼、驱动力或惯性语义。

训练数据全部来自源参数 `(7.35, 0.0, 0.8, 0.8)` 下的 `(s_t,a_t,s_{t+1})` 转移。

## 尝试一：单步预测训练

1200 次 Adam 更新后：

| 指标 | 结果 |
|---|---:|
| 单步原始状态 MSE | 2.68e-5 |
| 单步切空间 RMSE | 0.01269 |
| 24 步最终切空间 RMSE | 0.58256 |
| 状态 Jacobian 平均余弦 | 0.99908 |
| 动作 Jacobian 平均余弦 | 0.96587 |

这些局部指标看起来较好，但模型规划器出现了明显的模型利用：

| 路线指标 | 模型内 | 真实源环境重放 |
|---|---:|---:|
| 最大末端高度 | 1.9995 | -0.8565 |
| 是否成功 | 是 | 否 |

在模型内部，三条通道的隐藏反馈认证为 100%；把相同控制器放回真实源环境后，三条边完成率为 `0% / 95.31% / 0%`。说明单步误差足以在 480 次复合后产生完全虚假的成功路线。

## 尝试二：多步预测与局部割线一致性

第二种训练仍然只有预测目标，但加入两项数据约束：

1. 自由滚动预测课程，训练时域依次为 1、2、4、8、16 步；
2. 从邻近状态—动作转移对构造局部割线响应，使网络不仅拟合函数值，也拟合局部变化方向。

局部割线项为

\[
\mathcal L_{\mathrm{sec}}
=\left\|
[F_\theta(s+\delta s,a+\delta a)-F_\theta(s,a)]
-[s'_{\delta}-s']
\right\|^2,
\]

其中两个真实下一状态都来自同一个源环境，不使用物理公式或物理参数标签。

结果：

| 指标 | 单步训练 | 多步+割线 |
|---|---:|---:|
| 单步切空间 RMSE | 0.01269 | 0.01421 |
| 24 步平均误差 | 0.18224 | 0.09346 |
| 24 步最终 RMSE | 0.58256 | 0.26871 |
| 动作 Jacobian 平均余弦 | 0.96587 | 0.90645 |
| 真实三边总体完成率 | 31.77% | 63.02% |

多步稳定性和局部通道执行明显改善，但完整路线仍然是假的：模型预测最大高度 1.3669，真实重放只有 -1.3643；真实三边完成率为 `0% / 92.19% / 96.88%`。初始蓄能边仍完全失败。

这也揭示了一个训练张力：增加长时域自由滚动损失改善了轨迹误差，却降低了动作 Jacobian 的准确度。通道规划同时需要函数值和局部导数，不能只优化其中之一。

## 定位实验：正确路线与学得局部动力学

为了区分“路线错误”和“局部动力学错误”，最后固定一条由真实动力学生成的连续路线，但仍让 ProtoKAN 提供局部导数、Riccati 增益和通道几何。

| 路线/局部动力学组合 | 三边完成率 | 最低单边 |
|---|---:|---:|
| 真实路线 + 真实局部动力学 | 100% / 100% / 100% | 100% |
| 真实路线 + ProtoKAN 局部动力学，在模型内 | 100% / 95.31% / 100% | 95.31% |
| 真实路线 + ProtoKAN 局部动力学，在真实环境执行 | 100% / 100% / 92.19% | 92.19% |

预设的局部诊断门槛是最低单边不低于 90%，该门槛通过。因此当前主要问题已经定位：

> ProtoKAN 的局部动力学已经基本能够支撑短时域反馈通道；失败主要来自把近似认知模型当作精确模拟器进行 480 步开环路线规划。

## 对架构的影响

这意味着下一步不应该继续强迫一个单步认知模型做超长开环预测，也不应该直接进入目标参数恢复实验。合理的完整架构应把长路线改成反馈规划过程：

1. 全局层只保存经过局部反馈认证的可达关系或粗价值，不保存一条 480 步精确轨迹；
2. 认知模型只生成短时域通道，例如 24--48 步；
3. 决策网络执行少量步数后，使用真实状态重新定位；
4. 每个真实转移继续训练 ProtoKAN；
5. 当预测创新或通道距离超过阈值时，重新线性化、重建通道并重新路由。

设真实创新为

\[
e_t=d(F_\theta(s_t,a_t),s_{t+1}),
\]

重规划触发器可以写为

\[
e_t>\tau_e
\quad\lor\quad
d_{\mathcal T_{t+1}}(s_{t+1})>\tau_T.
\]

这样，认知网络持续学习、决策网络实时反馈和必要时重新规划会成为同一个闭环，而不是依赖一次性开环模型幻觉。

## 当前结论

本轮没有进入目标物理参数在线恢复，因为源环境上的学得全局规划尚未通过。直接进入目标环境会重新混合认知误差、规划误差和决策误差。

当前得到的积极结果是：**单一、未做语义分割的 ProtoKAN 所提供的局部动力学，已经足以在正确连续路线附近构造最低 92.19% 完成率的真实反馈通道。** 下一难点已经从“认知信息能否进入决策网络”收缩为“如何把局部认证通道组合成不会被模型长程误差欺骗的反馈路线”。
