# Stage 54：ProtoKAN 公式图决策算子

## 1. 目标

本阶段首次不使用“决策网络生成一个动作，再让认知网络预测这个动作后果”的单点探针接口，而是把 ProtoKAN 的完整边函数转换成公式图 token，供决策网络直接读取。

认知网络仍然只优化状态转移预测损失；决策网络通过公式图注意力模块直接输出动作。

## 2. 实现

### 2.1 公式图接口

对 ProtoKAN 的每条边函数在固定解析基点上计算：

\[
\phi_{ij}(u_m),\qquad u_m\in[-1,1]
\]

其中边函数同时包含：

- 原型位置 `proto_pos`；
- 原型值 `proto_val`；
- 原型导数 `proto_der`；
- 核宽 `log_sigma`；
- SiLU 基础权重 `base_weight`。

逐边编码后，对边集合进行池化，得到每个 ProtoKAN 层的公式 token。该表示不是把参数向量直接展平，而是把参数转换为函数响应。

### 2.2 决策网络

决策网络对各层公式 token 做多头注意力，然后通过门控融合当前状态、历史上下文和目标，直接输出动作。

没有使用用于产生最终动作的认知 query；认知网络只作为函数图提供者。

## 3. 接口验证

- 公式图包装器的数值预测与原 ProtoKAN 输出最大误差：`0.0`；
- 所有认知参数均存在到公式 token 的梯度路径，包括 `proto_pos`、`proto_val`、`proto_der`、`log_sigma` 和 `base_weight`；
- 逐边编码后 actor 参数量约 4.27 万，明显低于直接展平全部边函数的约 41 万。

相关代码：

- `kanrf/formula_graph.py`：完整公式图导出原型；
- `kanrf/formula_graph_operator.py`：可导公式图接口；
- `kanrf/formula_graph_operator_fast.py`：逐边编码和缓存的高效版本；
- `scripts/stage54b_formula_graph_ppo_fast.py`：公式图决策实验。

## 4. 正式实验（seed=0，完整 rollout）

| 阶段 | 成功率 |
|---|---:|
| 源环境训练后 | 76.56% |
| 参数组 B 零样本 | 14.06% |
| 参数组 B 在线适应后 | 9.38% |

认知网络在线预测损失从切换后的较高值下降到 `1.32e-4`，但决策成功率没有同步恢复。

## 5. 结论

本实验验证了：

1. 可以在不使用最终动作探针的情况下，让决策前向传播访问 ProtoKAN 的完整边函数；
2. 公式级函数表示可以承载认知网络的全部主要参数；
3. “信息已经正确传递”与“决策网络能够稳定解释这些信息”是两个不同问题。

当前失败的主要原因是公式 token 的表示不稳定：认知网络在线更新后，即使预测损失下降，公式 token 的坐标也可能发生较大漂移，导致源环境训练得到的决策解码器无法继续解释它。

因此，下一阶段不应继续增加 token 数量，而应先解决：

- 函数图 token 的尺度和坐标规范化；
- 网络参数微小变化下的 token 一致性；
- 公式图变化与真实动力学变化之间的区分；
- 决策解码器对公式图的稳定利用。
