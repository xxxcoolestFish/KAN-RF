# Stage 29：强制全参数耦合验证

## 实验目的

验证去掉决策网络任务捷径后，动作是否会真正依赖完整认知参数。

决策路径为：

\[
(s,g)\rightarrow q(s,g)\rightarrow
\langle q,\omega_p\rangle\rightarrow a
\]

其中 \(\omega_p\in\mathbb R^{7090}\)，动作前向没有独立的任务分支。

## 结果

- 认知参数量：7090；
- 运输维度：7090；
- 无参数压缩；
- `decision_has_bypass = false`；
- source 成功率：75%；
- heldout_1 成功率：70%；
- heldout_2 成功率：55%。

在线更新到 `heldout_1` 后：

- 认知 MSE：`0.0229 → 0.0178`；
- 运输参数变化 L2：`6.14`；
- 动作平均变化：`1.7×10^{-5}`；
- 成功率：`70% → 70%`。

## 结论

实验说明：

1. 去除结构上的决策捷径是可行的；
2. 全部认知参数确实位于动作的前向路径中；
3. 但“前向路径经过参数”不等于“动作对参数变化敏感”。

当前查询网络和动作输出的饱和性仍然会把参数变化削弱。因此下一步需要加入显式参数敏感性约束，例如：

\[
\mathcal L_{\mathrm{sens}}
=-
\frac{
\|a(\theta_c+\epsilon)-a(\theta_c)\|_2
}{\|\epsilon\|_2+\varepsilon}
\]

或者使用参数调制的乘性门控，并同时限制动作输出不进入饱和区。
