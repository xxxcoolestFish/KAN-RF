# 阶段一：多因素隐藏动力学验证

## 目的

验证 token 容量不是物理参数数量的硬编码。环境同时隐藏改变重力、阻尼、执行器强度和惯量尺度，认知网络只接收交互历史。

## 设置

训练因素组合：

```text
(g, damping, actuation, inertia)
(7.35, 0.00, 0.80, 0.80)
(7.35, 0.08, 1.20, 1.20)
(12.25, 0.00, 1.20, 1.20)
(12.25, 0.08, 0.80, 0.80)
(14.70, 0.04, 1.00, 1.00)
```

未见组合：

```text
(9.80, 0.04, 1.10, 0.90)
(13.475, 0.06, 0.90, 1.10)
```

所有配置训练 300 步，使用 seed `42, 43, 44`。

## 结果

| 最大 token 数 | 未见组合预测误差 | 同因素一致性 | 不同因素距离 | 平均有效 token |
|---:|---:|---:|---:|---:|
| 4 | **0.001292** | 0.02316 | **0.03484** | 3.55 |
| 8 | 0.001398 | 0.01849 | 0.02184 | 4.14 |
| 16 | 0.001608 | **0.01159** | 0.02059 | 7.59 |

这里的结果说明：

1. 当前多因素任务并不需要 16 个 token；
2. 更大的最大容量不会自动带来更好的预测；
3. `M=8` 的门控机制只激活约 4 个 token，实际有效复杂度小于最大容量；
4. token 数与物理因素数量没有一一对应关系；
5. `M=4` 的预测最好，但 `M=8` 为未来更复杂动力学保留了余量。

## 当前决定

后续暂用：

```text
最大 token 数：8
token 维度：8
lambda_sparse：1e-3
lambda_consistency：0.01
```

该配置不是最终超参数，而是进入决策网络接收实验的保守接口。若后续加入更复杂的非线性或接触动力学，仍需重新测量有效 token 数。
