# 固定目标走廊下的闭环 Bellman 认知迁移验证

## 1. 实验问题

Oracle 闭环宏步 Bellman Actor 已在源环境达到正确认知 `95/96 = 98.96%`、错误认知 `2/96 = 2.08%`。本轮进一步验证：

> 在真实物理环境切换后，如果 Actor 参数完全冻结，并给所有条件同一条可行目标状态走廊，正确目标动力学是否能让同一个 Actor 产生更合适的动作？

该实验只隔离局部认知—决策接口，不让不同路线质量、Actor 在线学习或 ProtoKAN 预测误差混入结论。

## 2. 匹配实验设计

真实执行环境固定为重惯性 Acrobot：

\[
(g,d,u,I)=(7.35,0,0.80,1.20).
\]

目标 Oracle-CEM 走廊包含 `721` 个状态，最大高度 `1.85687`，首次在第 `708` 步进入成功集合。走廊只包含状态，不向 Actor 暴露 CEM 动作。

Actor 使用源环境正式验证的第 `35` 轮检查点。所有决策参数完全冻结，评估前后的参数向量逐位相同。

三种条件共享：

- 同一个真实重惯性环境；
- 同一条目标 Oracle 走廊；
- 同一个 Actor 参数；
- 同一批随机初态和评估种子；
- 同一个750步反馈相位执行协议。

唯一改变的是 Actor 内部闭环 Bellman 树所调用的认知动力学：

| 条件 | Actor 内部认知因子 |
|---|---|
| 正确目标认知 | `(7.35, 0, 0.80, 1.20)` |
| 冻结源认知 | `(7.35, 0, 0.80, 0.80)` |
| 错误强重力认知 | `(9.00, 0, 0.80, 0.80)` |

## 3. 正式协议

- `3` 个评估种子；
- 每个种子 `32` 个随机初态；
- 每个条件共 `96` 次；
- 三个条件使用匹配随机数；
- 正确认知门槛：成功率至少同时高于另外两种认知 `2` 个百分点；
- Actor 无梯度、无优化器、无在线参数更新。

## 4. 正式结果

| 内部认知 | 成功数 | 成功率 | 平均最高高度 | 平均最终相位 |
|---|---:|---:|---:|---:|
| 正确重惯性认知 | **94/96** | **97.92%** | 0.98449 | 699.10 |
| 冻结源认知 | 85/96 | 88.54% | 0.98118 | 676.35 |
| 错误强重力认知 | 5/96 | 5.21% | -0.31111 | 462.58 |

正确认知、冻结源认知和错误认知在三个种子上的成功数分别为：

\[
\text{correct}: 31/32,\ 31/32,\ 32/32,
\]

\[
\text{frozen source}: 29/32,\ 28/32,\ 28/32,
\]

\[
\text{wrong}: 2/32,\ 2/32,\ 1/32.
\]

因此：

\[
\text{correct} - \text{frozen source}=+9.375\text{ pp},
\]

\[
\text{correct} - \text{wrong}=+92.708\text{ pp}.
\]

正确认知在三个种子上分别比冻结源认知多成功 `2/3/4` 条，方向逐种子一致。正确目标认知相对冻结源认知的平均绝对动作变化为 `0.55664`，相对错误认知为 `0.66895`；两者最大动作变化均为 `2.0`。

## 5. 能够成立的结论

本轮给出直接的因果隔离证据：

1. 源环境训练好的决策参数无需更新，就能在新的重惯性环境和新目标走廊上工作；
2. 仅把闭环 Bellman 树内部的认知动力学从源模型替换为正确目标模型，成功率从 `88.54%` 提高到 `97.92%`；
3. 换成物理语义错误的强重力模型后，成功率下降到 `5.21%`；
4. 因为真实环境、走廊、Actor 参数、初态和随机种子全部匹配，差异只能来自内部认知模型改变了 Bellman 动作评分。

这说明当前接口不是把认知模型当作无意义的相位编码或动作缩放器，而是能够利用与真实环境一致的动力学后果改善动作决策。

## 6. 为什么冻结源认知仍有 88.54%

目标 Oracle 走廊已经提供了一条适合重惯性环境的可行高层路线，反馈相位还会根据真实状态纠正进度。宏步 Bellman Actor 本身也具有较强反馈鲁棒性，因此即使内部模型仍是源动力学，也能完成大部分轨迹。

正确目标认知的价值体现在剩余困难初态：它把三个种子中的成功数分别从 `29/28/28` 提高到 `31/31/32`，同时平均最终相位提高约 `22.75` 步。当前认知更新表现为提高可靠性，而不是从完全失败恢复到成功。

## 7. 尚不能成立的结论

本实验不能称为完整泛化，因为：

- 目标走廊由 Oracle 动力学预先构造；
- 正确目标认知也是直接提供的 Oracle，而不是 ProtoKAN 在线学习得到；
- 只有一个 Actor 训练种子；
- 尚未让认知网络在环境切换后自己更新并重新生成走廊；
- 动作仍是五点离散网格。

因此当前结论是“正确目标动力学能够被已训练 Actor 立即利用”，不是“完整系统已经能够自主发现并适应未知环境”。

## 8. 下一检查点

下一步应把 Oracle 目标认知替换为从目标真实转移持续更新的 ProtoKAN，同时暂时仍固定同一条目标走廊，记录：

\[
\text{认知预测误差}(episode),
\quad
\text{动作与 Oracle 动作差异}(episode),
\quad
\text{成功率恢复}(episode).
\]

只有学得认知逐步接近 Oracle 效果后，再取消固定目标走廊，让更新后的认知模型负责重新规划，以避免同时引入认知误差和路线规划误差。
