# 新框架：认知网络—物理参数接口—决策网络

## 目标

将系统收敛为一个认知预测网络和一个决策网络。认知网络从交互历史中识别具有稳定语义的动力学表征，决策网络通过专门隔离的物理参数子空间接收该表征。

## 核心形式

\[
\eta_t=E_\phi(H_t),\qquad
\hat s_{t+1}=F_\phi(s_t,a_t;\eta_t)
\]

\[
\Theta_D=\Theta_{task}\oplus\Theta_{phys},\qquad
\theta_{phys}(\eta_t)=\theta_{phys}^0+\mathcal T_\psi(\eta_t)
\]

\[
a_t=\pi_\theta(s_t;\theta_{task},\theta_{phys}(\eta_t))
\]

其中 `PhysicsTransport` 是认知网络与决策网络之间的显式参数接口。第一版采用可解释的线性传递，后续再比较低秩算子、KAN 基函数系数调制和更一般的参数传输算子。

## 设计原则

1. 物理信息不能依赖手工重力编码；
2. 决策网络的任务参数与物理接收参数必须结构隔离；
3. 同一物理系统的不同轨迹应产生一致的物理表征；
4. 物理表征变化应通过接收子空间改变策略，而不是被策略网络绕过；
5. 先验证物理表征和接口，再进行联合控制训练。

当前分支的 `physics_transfer` 包是新框架的最小实现，不再依赖旧的 V19–V33 实验脚本。
