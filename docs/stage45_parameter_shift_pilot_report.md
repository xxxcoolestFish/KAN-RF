# Stage 45：物理参数变化适应的第一轮对照

## 设置

本轮使用与 Stage 44 完全相同的 PPO 协议，训练 60 轮、seed=0。训练只在源参数 `(7.35, 0.0, 0.8, 0.8)` 上进行，随后不更新网络，直接将环境替换为 held-out 参数 `(9.8, 0.04, 1.1, 0.9)`，以测量零样本参数变化适应。

## 结果

| actor | 源环境 | 变化后环境 |
|---|---:|---:|
| 普通 PPO | 89.1% | 96.9% |
| ProtoKAN 嵌合 PPO | 84.4% | 92.2% |

评估均为 64 个悬垂向下小扰动初始状态、确定性动作、500 步，成功定义为末端高度曾达到 `1.0`。

## 解释

这是单种子试验，不能证明泛化优势。当前两种策略在参数变化后的成功率都没有下降，甚至高于源环境，说明这个 held-out 参数组合对任务可能更容易，不能单独作为“泛化恢复”证据。公平结论仍需：

1. 多随机种子；
2. 多个更难的参数变化方向；
3. 源环境训练成功率匹配后再比较；
4. 后续加入在线认知更新，记录 episode 级恢复曲线。

脚本：`scripts/stage45_direct_ppo_fixed_heldout.py`；嵌合结果来自 `results/stage44_ppo_embedded_fixed_seed0_60iter.json`。
