# 样条参数耦合外推快速门

## 1. 验证问题

本轮只验证一个受控上限问题：

> 当环境物理坐标已知时，让局部样条参数更新沿有序样条位置传播，能否提高
> 从两个源物理环境到第三、第四个物理环境的动力学预测外推能力？

这不是最终的无标签适应实验。执行器尺度 \(\alpha\) 被显式输入模型，仅用于
隔离样条耦合机制。如果该上限门不能稳定改善，就不应立即加入环境 latent、
在线控制和持续学习。

## 2. 被测试的机制

对同一 KAN 边上的有序参数梯度 \(g\)，构造路径图拉普拉斯 \(L\)，使用

\[
\tilde g=(I+\tau L)^{-1}g
\]

进行隐式扩散，再由 SGD 更新参数。该算子满足：

- \(\tau=0\) 时退化为普通训练；
- 常量梯度保持不变；
- 局部脉冲按样条索引距离衰减；
- 扩散矩阵对称正定；
- 只扩散第一层的环境 context 输入维度，状态和动作梯度保持不变。

同时实现了 ProtoKAN 的 Hermite 一致性：

\[
\mathcal L_H=
\sum_j
\left[
\frac{v_{j+1}-v_j}{x_{j+1}-x_j}
-\frac{d_j+d_{j+1}}{2}
\right]^2.
\]

主实验使用 SGD。Adam 会逐坐标归一化扩散后的微小远端梯度，第一步就可能
把距离衰减变成近似等幅更新，因此不适合直接验证该机制。

## 3. 严格实验设置

### 3.1 状态和目标

不使用 Pusher 的 23 维公开 observation。该 observation 缺少物体速度，
不是当前预测任务所需的完整 Markov 状态。

输入：

\[
x=[qpos[:9],qvel[:9],a,\alpha]\in\mathbb R^{26}.
\]

目标：

\[
y=\Delta[qpos[:9],qvel[:9]]\in\mathbb R^{18}.
\]

只预测 delta，排除固定 goal 自由度，避免恒等状态和静态维度稀释物理变化。

### 3.2 物理环境

- 源环境：执行器尺度 \(\alpha=\{0.80,1.00\}\)；
- 插值环境：\(\alpha=0.90\)；
- 外推环境：\(\alpha=\{0.65,1.15\}\)。

每个尺度使用独立 MuJoCo 环境，只修改一次
`actuator_gear[:, 0]`，不调用 `mj_setConst`。

### 3.3 配对反事实数据

先生成固定的完整状态和动作库，再从完全相同的
\((qpos,qvel,a)\) 分别查询所有执行器尺度。

训练、验证和测试在状态动作库层面独立生成，之后才扩展物理尺度。因此不存在
同一根状态跨 split 的泄露，也不会把状态分布变化误认为函数外推。

### 3.4 模型与控制变量

- 普通 MLP；
- KAN；
- KAN + P-spline 二阶差分；
- KAN + context 梯度扩散；
- ProtoKAN；
- ProtoKAN + context 梯度扩散；
- ProtoKAN + context 梯度扩散 + Hermite。

KAN 使用 `grid_size=13, order=3`，每条边 16 个样条系数；ProtoKAN 使用
8 个 prototype，每条边有 8 个 value 和 8 个 derivative，局部参数容量接近。

主机制门将所有 KAN/ProtoKAN 的 SiLU base path 置零并冻结。ProtoKAN
位置和带宽也固定，保证“相邻参数”始终对应相邻输入位置。

所有同族对照使用相同初始化、相同 minibatch 顺序、相同 SGD 设置。

## 4. 关键度量修正

最初只报告整体 delta RMSE 时，所有模型几乎可以忽略 \(\alpha\)，因为执行器
尺度引起的差异远小于状态本身的一步变化。

因此增加配对反事实训练损失：

\[
\mathcal L_{\rm cf}
=
\left\|
[\hat y(1.0)-\hat y(0.8)]
-[y(1.0)-y(0.8)]
\right\|^2,
\]

并把外推反事实效果误差作为主要机制指标：

\[
E_{\rm cf}(\alpha)
=
\left\|
[\hat y(\alpha)-\hat y(0.9)]
-[y(\alpha)-y(0.9)]
\right\|.
\]

它直接检测模型是否学到了物理尺度对同一状态动作的影响，而不是平均动力学。

## 5. 实验结果

### 5.1 直接把所有网络参数都扩散

第一版对所有层、所有输入维度扩散：

- KAN 外推反事实误差恶化约 0.49%；
- ProtoKAN 几乎完全不变。

原因是充分观测的状态和动作样条也被过度平滑。该实现被否定。

### 5.2 只扩散第一层 context

没有反事实损失时，耦合与普通模型几乎完全相同。模型通过忽略 context 就能
降低普通预测损失，说明普通 MSE 不是有效机制指标。

### 5.3 加入反事实训练后的扩散强度扫描

固定 seed 8128，主要结果如下。正值表示相对普通同族模型改善：

| 扩散强度 \(\tau\) | KAN | ProtoKAN |
|---:|---:|---:|
| 0.05 | -1.85% | +1.08% |
| 0.10 | -3.82% | +1.60% |
| 0.20 | +4.56% | +2.05% |
| 0.40 | -19.17% | +1.40% |

没有稳定、单调的有效区间，也没有达到预注册的 10% 改善门槛。

### 5.4 三个随机种子，\(\tau=0.20\)

| Seed | KAN 扩散改善 | ProtoKAN 扩散改善 |
|---:|---:|---:|
| 8128 | +4.56% | +2.05% |
| 8129 | -3.17% | +1.27% |
| 8130 | +1.28% | -0.09% |
| 平均 | **+0.89%** | **+1.08%** |

改善幅度很小，并且两种模型都出现随机种子变号。完整动力学 RMSE 也没有同步
稳定改善。

### 5.5 Hermite 与 P-spline

- ProtoKAN 训练 700 步时，\(\tau=0.1\) 的扩散使反事实外推恶化约 3.69%；
- Hermite 权重 0.01 和 0.1 与扩散版本几乎完全相同，没有补回损失；
- P-spline 权重 0.01 在单 seed 上改善约 2.73%；
- P-spline 权重 0.1 开始恶化，说明更强平滑并不等于更正确的外推。

### 5.6 普通 MLP

在同一 seed、同一反事实训练下：

- MLP 外推反事实 RMSE：约 0.0692；
- ProtoKAN：约 0.0828；
- KAN：约 0.1063。

当前 KAN 系列还没有超过普通 MLP。执行器尺度主要通过
`effective_action = alpha * action` 产生影响，MLP 更容易学习该跨输入交互。

## 6. 客观结论

当前结论是：

> **“按样条索引扩散原始梯度”这一具体实现没有通过外推门。**

它在数值上正确实现了“一个局部样条更新波及其他样条”，但传播的是平滑梯度，
不是物理变化方向。未激活区域虽然获得了更新，却没有证据保证更新方向对应
真实的动作—效果变化。

这不否定“利用 KAN 参数结构传播物理趋势”的上层思想，只否定当前的均匀图
扩散实现。

## 7. 根因

物理变化并不是 context 输入边上的一个独立加法函数，而是 context 与动作的
交互：

\[
\Delta s \approx F(s,\alpha a).
\]

当前扩散只在第一层 context 样条系数之间传播，无法直接告诉网络：

- 哪个动作维度应被增强或减弱；
- context 变化如何改写动作响应曲线；
- 哪些状态区域共享相同变化趋势。

因此它主要提供低频平滑偏置，而没有提供控制相关的参数运输规律。

## 8. 更合理的后续结构

下一版不应继续调扩散强度，而应让环境坐标直接调制动力学 KAN 的动作边函数：

\[
c_a(z)=c_{a,0}+Uz,
\]

或者更一般地：

\[
\theta(z)=\bar\theta+Uz.
\]

两个源环境学习的不是“把一个 knot 的梯度复制给另一个 knot”，而是：

\[
U\approx
\frac{\theta(z_2)-\theta(z_1)}{z_2-z_1},
\]

即完整动力学函数随环境变化的系数方向。目标环境再用少量转移识别 \(z\)。

这仍然充分利用 KAN 系数的结构，但传播对象从“原始局部梯度”升级为
“跨环境动力学函数的参数切向量”，更符合 few-environment 研究问题。
