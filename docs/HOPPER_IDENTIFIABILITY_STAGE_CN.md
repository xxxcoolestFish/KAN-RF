# Hopper 高维认知传递：可辨识性阶段报告

## 1. 本阶段研究问题

Two-Link 上的效果空间 Actor 已证明：把策略更新约束在认知模型定义的控制等价坐标中，
可以明显快于普通动作残差。但将同一思想迁移到 Hopper 后，在线 ProtoKAN pullback
没有带来稳定恢复。本阶段不再直接优化回报，而是逐层检验以下链条：

\[
\text{源控制知识}
\rightarrow
\text{目标控制变化识别}
\rightarrow
\text{目标漂移变化识别}
\rightarrow
\text{真实效果补偿}
\rightarrow
\text{Actor--Critic 恢复}.
\]

所有学习实验只使用一个源物理环境和目标环境的在线转移；质量、摩擦、重力等真实参数
均不向学习器开放。目标模拟器的状态克隆和有限差分只用于诊断，不参与训练。

## 2. 残差阈值不能区分模型偏差与物理变化

对源环境和 `combo_mild` 目标环境分别采集 512 条同协议转移，使用源 Sobolev
ProtoKAN 计算归一化残差。结果如下：

| 分数 | 区分 AUC | 目标样本超过源 95% 阈值 |
|---|---:|---:|
| 完整状态残差 | 0.566 | 14.6% |
| 可控子空间投影残差 | 0.635 | 8.2% |

增加源基线数据后，AUC 仅变为 0.596 和 0.666，超过阈值比例仍为 14.3% 和
8.2%。因此，基于残差幅值的 uncertainty gate 会漏掉绝大多数真实变化，不能作为
主要机制。

根本混淆为

\[
s'-\hat f_0(s,a)
=
\underbrace{f_t(s,a)-f_0(s,a)}_{\text{真实物理变化}}
+
\underbrace{f_0(s,a)-\hat f_0(s,a)}_{\text{源模型偏差}}.
\]

## 3. 源控制 Sobolev 认知

在唯一源环境中，对同一状态执行
\(\pi_0(s)\pm\epsilon e_i\) 黑盒探针，以有限差分监督控制 Jacobian。
1024 个源训练状态上的固定 KAN 字典取得：

- 验证 Jacobian 相对误差约 9.0%；
- Jacobian 余弦约 0.9946；
- 正方向比例 100%。

这证明控制相关物理基底可以从单一黑盒源环境学习，不需要物理公式或参数标签。

但是窄源策略分布上的高精度不等于目标轨迹上的高精度。使用源环境内的随机行为扰动
扩展状态覆盖后：

- 宽分布验证 Jacobian 相对误差约 12.7%，余弦 0.989；
- 学得源 Jacobian 在目标状态上的误差由 35.7% 降至约 26.3%；
- 允许 Oracle 选择最佳全局控制变换时，误差下界由 31.9% 降至约 18.3%。

覆盖扩展有效，但不能单独完成目标识别。

## 4. 严格正交的目标控制变换

旧实验使用高斯动作噪声后再裁剪。源 Actor 接近动作边界时，实际扰动不再满足
\(E[\delta u\mid s]=0\)，漂移项会污染控制交叉矩。

修正后的探索采用严格对称 Rademacher 扰动：

\[
\delta u_i\in\{-\epsilon_i,+\epsilon_i\},
\qquad
\epsilon_i\le 1-|\pi_{0,i}(s)|.
\]

由此构造

\[
G_t(s)\approx G_0(s)M_t
\]

的正交矩估计。`combo_mild` 上，2048 条目标转移得到：

- 源 Jacobian 直接用于目标：相对误差 22.68%；
- 正交更新后：相对误差 19.99%；
- 更新后目标 Jacobian 余弦 0.979；
- 同状态真实源/目标 Jacobian 的 Oracle 全局变换误差仅约 3.7%。

这是本阶段最明确的正结果：低维控制变换假设在真实动力学上基本成立，严格对称探索
能够从在线转移中恢复一部分目标控制变化。

## 5. 为什么回报仍未改善

策略中心化模型写为

\[
\Delta s=b_t(s)+G_t(s)\delta u.
\]

只更新 \(G_t\) 不会改变源 Actor 的名义动作，因为名义动作对应
\(\delta u=0\)。它只改变后续残差 Actor 的动作解码。公平的 2k 在线 PPO 对照中：

| 方法 | 初始平均回报 | 2k 决策转移后 |
|---|---:|---:|
| 效果空间残差 | 539.72 | 530.00 |
| 动作空间残差 | 539.72 | 530.06 |

两者几乎相同，而且都轻微退化。当前控制变换只是一个条件良好的线性重参数化，普通
Actor 能够吸收，尚未产生可观测的迁移优势。真正缺失的是名义动作所需的漂移补偿。

## 6. 三种漂移恢复均失败

在已识别 \(G_t\) 后，本阶段依次测试：

1. 完整 11 维 KAN 漂移残差；
2. 3 维全局可控等价动作偏置；
3. 状态相关、输出秩 1 的加性 KAN 可控偏置。

真实反事实效果诊断如下：

| 漂移更新 | 基线效果误差 | 修正后误差 | 改善状态比例 |
|---|---:|---:|---:|
| 完整 KAN，ridge=100 | 0.341 | 0.375 | 44.5% |
| 完整 KAN，ridge=1000 | 0.341 | 0.359 | 36.7% |
| 常量可控坐标 | 0.341 | 0.360 | 38.3% |
| 源零点校准后的常量坐标 | 0.341 | 0.358 | 35.9% |
| 秩 1 状态相关坐标 | 0.341 | 0.376 | 25.0% |

提高正则只会把结果收缩回“不更新”，不能产生正确补偿。

## 7. 新的结构性发现

评估专用 Oracle 显示，目标环境中真实需要的等价动作补偿具有很强的低秩性：

\[
\text{PCA variance ratio}
=
(91.99\%,\,6.76\%,\,1.24\%).
\]

因此“小型状态相关适配器”在表达能力上是足够的。失败发生在标签辨识，而不是补偿函数
复杂度：由普通单步残差投影得到的补偿与真实补偿平均余弦接近 0，甚至为负。

当前可以较有把握地写成：

\[
\boxed{
\text{控制 Jacobian 变化可由外生对称扰动辨识；}
\quad
\text{漂移变化不能由未校准的单步目标残差辨识。}
}
\]

## 8. 下一阶段的正确研究问题

不应继续调整漂移网络容量、ridge 或手工门控。下一阶段必须改变信息来源，使
\(b_t-b_0\) 可辨识。优先研究：

1. **源残差条件分布的交叉拟合校准**：保存状态相关的源误差函数与置信区间，而不是
   一个全局均值；
2. **时序差分矩**：在相邻或闭环匹配状态上构造差分，使慢变漂移与模型偏差被消去；
3. **主动成对扰动的可实现近似**：不克隆环境，通过短时对称实验和局部回归获得漂移
   变化信号；
4. **联合多步闭环可辨识性**：使用短轨迹效果而不是单步状态残差，直接监督可控低秩
   补偿；
5. **策略持续学习保底**：决策网络允许继续训练，但必须用动作空间对照证明认知更新
   提供额外恢复速度，而非仅由 PPO 学习产生。

只有漂移补偿的真实方向余弦显著为正、反事实效果改善比例显著超过 50%，才应重新启动
正式 Hopper 恢复曲线和多随机种子实验。

## 9. 源反事实数字孪生上界

为了判断“一步控制等价结构本身无效”还是“源认知模型不够准确”，增加了诊断上界：
目标参数仍完全隐藏，但保留源环境模拟器；在目标访问到的同一状态、同一动作上查询源
转移，从而得到

\[
\Delta f(s,a)
=
f_t(s,a)-f_0(s,a).
\]

这个差分严格消除了源模型基线误差。它不是最终可部署方法，而是检验源认知充分性的
Oracle。

在 `combo_medium`、2048 条目标认知转移上：

- 单步真实效果误差由 0.4660 降至 0.4114，降低约 11.7%；
- 69.5% 的状态得到改善；
- 预测变化与真实变化的方向余弦为 0.635；
- 87.5% 状态的变化方向余弦为正；
- 目标 Jacobian 误差由直接源模型的 44.0% 降至 21.2%。

在不训练残差 Actor 的十回合闭环评估中，源策略回报由约 340.0 提升到
393.34，提升约 15.7%，平均回合长度由 130.7 提升到 141.6。随后加入 2048 条
决策转移和残差 Actor--Critic，最终回报约 392.46，没有继续提升，也没有明显破坏
认知修正。

因此当前结论更新为：

\[
\boxed{
\text{一步控制等价结构在 Hopper 上能够改善闭环控制；}
\quad
\text{实际瓶颈是 ProtoKAN 尚不能提供准确的源反事实数字孪生。}
}
\]

下一阶段的核心任务不是继续调整目标 PPO，而是将源模拟器的反事实查询能力蒸馏到认知
网络中。蒸馏模型必须同时满足：

1. 在宽源可达状态域上学习 \(f_0(s,a)\)，而不只覆盖源 Actor 的窄轨迹；
2. 使用控制 Sobolev 监督保持准确的 \(G_0(s)\)；
3. 使用多步一致性约束降低闭环外推误差；
4. 使用交叉拟合或模型集成校准源反事实不确定性；
5. 目标阶段只在源置信域内使用
   \(\hat f_t(s,a)-\hat f_0(s,a)\) 做漂移传递；
6. 与保留源模拟器 Oracle 的 15.7% 闭环增益比较，量化蒸馏认知回收了多少上界。

## 10. 高容量源数字孪生蒸馏仍受联合分布外推限制

首先训练控制仿射神经数字孪生：

\[
\hat f_0(s,\pi_0(s)+\delta u)
=
\hat b_0(s)+\hat G_0(s)\delta u.
\]

它使用 30,000 条源宽探索转移、4096 个源 Sobolev 探针，并在 GPU 上训练。
不含状态云扰动的版本取得：

- 独立源转移归一化 RMSE 0.196；
- 源名义效果 RMSE 0.188；
- Jacobian 相对误差 13.1%，余弦 0.989。

但该模型在 `combo_medium` 目标访问状态上的源反事实误差为 0.840，pullback 将
真实效果误差由 0.466 放大到 0.571。

随后在源轨迹状态周围加入多维随机状态云，并直接查询源模拟器标签。状态云版本在独立
源状态云验证集上进一步达到：

- 名义效果 RMSE 0.122；
- Jacobian 相对误差 14.3%，余弦 0.987。

然而它在目标访问状态上的源反事实误差仍为 0.851；pullback 后效果误差为
0.529，仅 38.3% 状态改善。

因此高维失败不是由以下因素单独造成：

1. 训练转移数量不足；
2. 普通网络容量不足；
3. Jacobian 监督不足；
4. 单变量坐标越过训练范围；
5. 简单的源状态邻域扩增不足。

目标物理变化诱导的是新的多变量联合状态组合。源验证集与目标状态的每个单独坐标范围
可以高度重叠，但联合分布仍然不同。普通 MLP 和固定全交互 KAN 都会把源联合相关性
写入函数，因而不能可靠地重组到新的状态组合。

下一版 ProtoKAN 的结构目标应改为**稀疏可组合机制图**：

\[
\hat f_{0,j}(s,a)
=
\sum_{C\in\mathcal G_j}
\phi_{j,C}(s_C,a_C),
\qquad |C|\ll \dim(s).
\]

其中 \(\mathcal G_j\) 是从源数据和控制 Sobolev 导数中学习的稀疏父集，每个局部 KAN
只描述少量状态变量之间的机制关系。新的联合状态出现时，认知网络重组已学得的局部
机制，而不是对完整 11 维联合分布做黑盒外推。

下一阶段门槛应直接使用目标状态上的源反事实误差，而不是源留出集 RMSE：

1. 源留出误差只是训练质量指标；
2. 目标状态源反事实误差是机制重组指标；
3. 只有该误差显著低于当前 0.84，才重新测试目标 pullback；
4. 最终以源模拟器 Oracle 的 0.411 单步误差和 393.34 闭环回报为上界。

## 11. 成对可组合 KAN 仍不足，以及不可辨识边界

第一版可组合 KAN 使用：

- 每个状态变量上的局部 B-spline 机制；
- 所有二元状态交互的低维余弦投影；
- 控制仿射输出头；
- Sobolev Jacobian 监督；
- 软组稀疏惩罚；
- 扩展到源尺度 1.5 倍的样条支持。

正式源训练后：

- 源状态云名义效果 RMSE 0.191；
- Jacobian 相对误差 15.4%，余弦 0.983；
- 软组稀疏没有真正关闭机制组，活跃比例仍为 100%。

在 `combo_medium` 目标状态上：

- 源反事实误差为 1.832，明显差于神经数字孪生的约 0.85；
- pullback 将效果误差从 0.466 放大到 0.572；
- 仅 35.2% 状态改善；
- 估计动作补偿与真实补偿余弦为负。

因此单变量和成对 ANOVA 机制不能充分表示 Hopper 的接触切换与多体耦合。更关键的
理论边界是：给定有限源分布 \(\rho_0\) 上的数据，若目标访问状态
\(s\notin\operatorname{supp}(\rho_0)\)，则存在多个源动力学函数在所有源数据点上
完全一致，却在该状态上给出不同反事实：

\[
f_0^{(1)}(s,a)\ne f_0^{(2)}(s,a).
\]

所以在不加入额外假设或信息的条件下，

\[
\boxed{
\text{单一源环境有限数据}
\not\Rightarrow
\text{任意高维目标状态上的准确源反事实}.
}
\]

网络更大、更多样条或更强稀疏正则不能消除这个不可辨识性。可成立的研究边界必须明确
选择至少一种附加条件：

1. 目标状态处于源认知模型经过验证的支持域；
2. 部署时保留可查询的源生成模型或模拟器；
3. 已知足够强的机械结构，使源动力学可以从局部关系唯一外推；
4. 允许决策网络通过真实奖励学习支持域外补偿，而认知传递只在支持域内启用。

当前最诚实且可实现的框架是“支持感知的认知传递”：

\[
a_t
=
\pi_0(s_t)
+
g(s_t)\,\operatorname{Pullback}_{\hat f_t,\hat f_0}(s_t)
+
\operatorname{Decode}_{\hat G_t}r_\psi(s_t),
\]

其中 \(g(s)\) 由源认知覆盖和交叉拟合误差决定。在可靠支持域内使用完整源反事实传递；
在支持域外关闭漂移传递，只保留可辨识的控制 Jacobian，并由残差 Actor--Critic 通过
真实反馈学习。论文不能再主张“任意未知高维状态上的零假设泛化”，而应主张：

> 在经过验证的机制支持域内快速传递；在支持域外安全退化为持续决策学习，并随在线
> 认知支持扩张逐步开放传递。
