# 阶段二：低秩物理接口的混合单步/多步训练

## 目标

闭环验证表明，单步反事实校准模型的误差会随递归步数累积。这里在低秩基—系数接口和差异幅值校准的基础上，加入 4 步闭环损失：

\[
\mathcal L=\mathcal L_{1}+50\mathcal L_{gap}
 +\lambda_4\mathcal L_{1:4}+\text{consistency}+\text{regularization}.
\]

`lambda_4` 只作为长期预测辅助项，不替代单步和反事实目标。

## 结果（300 步）

### Seed 42

| `lambda_4` | 单步损失 | 四步损失 |
|---:|---:|---:|
| 0.00 | 0.001316 | 0.010136 |
| 0.10 | 0.001243 | 0.009094 |
| 0.25 | **0.001149** | **0.008125** |

### Seed 43

| `lambda_4` | 单步损失 | 四步损失 |
|---:|---:|---:|
| 0.00 | 0.001669 | 0.011912 |
| 0.10 | 0.001325 | 0.009115 |
| 0.25 | **0.001097** | **0.007144** |

## 结论

1. 两个 seed 都显示混合目标优于纯单步目标，且 `lambda_4=0.25` 同时改善单步和四步误差。
2. 这说明长期漂移不是低秩接口的必然属性，至少可以通过训练目标显著缓解。
3. `0.25` 目前只是 Acrobot 多因素基准上的候选值，不应被当作普适超参数；后续环境和动作分布需要重新校准。

## 认知侧候选版本

当前进入决策网络实验的认知输出为：

- 历史编码的自适应物理 token；
- 低维物理系数 `c(h)`；
- 状态—动作基 `B(s,a)` 和 `B c` 物理残差；
- 反事实差异幅值校准；
- `lambda_4=0.25` 的辅助四步训练。

下一阶段将冻结或半冻结该认知侧，先训练只接收 `c` 的 oracle 决策接收器，验证决策网络是否真的能利用传递的物理信息，而不是再次从历史旁路学习动力学。
