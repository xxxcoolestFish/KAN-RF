# 阶段三：认知—决策接口与可辨识性审查

## 结论

当前分离式决策结构本身是可用的，但认知编码器尚未从观测历史中提取出足以驱动决策的环境信息。继续单独调大决策网络或增加潜变量维度，不能解决这个信息瓶颈。

## 已验证的事实

1. **物理分支的结构分离有效。** 决策网络拆成状态任务分支和物理接收分支后，输入 oracle 环境码时，测试动作 MSE 约为 `0.040–0.046`，打乱环境码会显著恶化，反事实动作差异约为真实差异的 `0.64–0.70`。因此接收器确实能够使用物理信息。

2. **认知码和算子约束都未形成稳定环境等价类。** 对潜变量坐标、归一化潜变量和诱导残差算子分别施加同环境一致性/异环境间隔约束，在 100 步和 300 步实验中，异环境距离与同环境距离几乎相等，分离裕度接近 0。

3. **历史可辨识性不足。** 在 5 个训练环境、8 步历史上训练一个独立的 ProtoKAN 因子分类器，seed=42、500 步得到准确率约 `0.214`，随机基线为 `0.200`。这表明当前历史观测几乎不能恢复人为定义的隐藏因子。

4. **当前决策教师读取了不可见标签。** `conditional_teacher(state, factors)` 直接使用隐藏因子生成动作；而认知网络只接收 history/state/action。于是 oracle 接收器和认知接收器面对的不是同一个信息条件，认知接收器不可能稳定复现 oracle 动作差异。

## 数学解释

设隐藏环境上下文为 \(\psi\)，观测历史为 \(h_{0:T}\)。当前实验实际要求认知网络实现

\[
    h_{0:T}\mapsto c(h_{0:T})\mapsto a(s,c)\approx a(s,\psi),
\]

但若 \(I(h_{0:T};\psi)\) 很低，则不存在稳定的确定性映射可以从 history 恢复 \(\psi\)。潜变量坐标的旋转不变性、算子等价类约束和接收器容量都无法创造缺失的信息。

## 对总体框架的影响

这不是推翻“认知编码器—决策解码器”方向，而是说明接口实验必须满足**信息闭合**：决策目标只能依赖认知网络在其输入中可以辨识的物理响应。当前 oracle 成功证明了决策解码器的结构可行；认知失败主要暴露了评测任务的信息不一致。

## 下一步

1. 将决策教师改为基于认知网络预测动力学的短视模型控制（或 MPC）目标，而不是直接读取隐藏因子。
2. 若仍要研究隐藏环境识别，则增加历史长度、主动激励动作和在线更新，并报告 \(I(h;\psi)\) 的代理指标。
3. 保留分离式决策结构；认知—决策接口优先采用算子查询/行为等价约束，不预先规定每个潜变量维度的语义或物理参数个数。
4. 在修正信息条件后，再进行多随机种子、跨环境和持续适应实验。
