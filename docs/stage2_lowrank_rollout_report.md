# 阶段二：低秩物理接口的闭环多步验证

## 验证方式

使用反事实差异校准后的低秩模型（rank=4、gap 权重 50）进行闭环滚动。每一步都把模型预测的状态写回历史窗口，并使用新的动作继续预测；真实轨迹使用相同动作和隐藏动力学推进。测试在两个未见因素组合上进行，滚动 4 步。

## 结论

反事实差异接口在一步预测上已经能传递隐藏动力学差异，但闭环误差随步数明显累积。当前认知网络还不能被描述为稳定的长期物理世界模型，尤其不能直接作为决策网络的长期规划依据。

下一步应在低秩接口上加入混合多步目标：保留单步精度和反事实 gap 校准，同时以较小权重训练 4 步闭环误差。只有多步误差和系数一致性同时受控，才进入决策网络接收器实验。
