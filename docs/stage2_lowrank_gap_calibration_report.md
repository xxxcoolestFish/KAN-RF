# 阶段二：低秩物理系数的反事实差异幅值校准

## 问题

低秩基—系数结构在初始损失下出现物理系数坍缩：不同隐藏动力学条件的系数几乎相同，模型退化为只使用不含历史的 base 分支。逐维 SmoothL1 差分项即使提高权重也没有改变这一点。

## 方法

保留普通预测和反事实绝对误差，新增直接的反事实差异幅值损失：

\[
\mathcal L_{gap}=\operatorname{MSE}\left(
\lVert \hat{s}'_a-\hat{s}'_b\rVert_2,
\lVert s'_a-s'_b\rVert_2
\right).
\]

该损失不需要知道物理公式或物理参数个数，只要求同一当前状态—动作下的两个反事实轨迹具有正确的下一状态差异幅度。残差能量权重降为 0.01，低秩 rank 固定为 4，训练 300 步。

## 结论

1. 低秩基—系数结构并非必然坍缩；使用直接的反事实差异幅值监督后，物理系数可以恢复跨隐藏动力学条件的区分能力。
2. 需要较大的 gap 权重才能压制平均预测解。`gap=10` 与 `gap=50` 都有效，但最佳值依赖 seed，不能直接宣称 50 是通用常数。
3. 差异幅值校准会牺牲 token 一致性：从约 `3e-5` 增至约 `1e-3`。这意味着当前表示仍处于“可区分但不够稳定”的状态，不能跳过多 seed、多因素和长时域验证。

## 当前候选接口

当前可作为下一阶段候选的认知接口是

\[
c_\psi(h)\rightarrow B_\phi(s,a)c_\psi(h),
\]

配合普通预测、反事实绝对误差、差异幅值校准和较弱残差能量正则。进入决策网络前，还需补充：

- gap 权重的系统扫描和多随机种子统计；
- 同因素一致性与不同因素分离的联合 Pareto 曲线；
- 四步滚动预测和跨未见因素组合；
- 决策网络只接收 `c`，不接收历史的 oracle 接收器对照。
