# 阶段二补充：物理系数的轨迹不变性约束

## 动机

前一版低秽物理系数可以校准反事实下一状态差异，但决策接入实验显示 `c(h)` 对不同轨迹仍不够稳定。新增同因素系数一致性项：

\[
\mathcal L_c=\|c(h_a)-c(h_b)\|_2^2,
\]

其中 `h_a,h_b` 来自同一个隐藏动力学条件的独立轨迹。反事实 gap 项继续负责不同动力学条件的分离，四步项权重固定为 0.25。

## 300 步结果

## 结论

权重 0.1 在两个 seed 上都改善了同因素稳定性，同时比强约束保留更多不同因素距离。权重 1.0 虽然同因素 MSE 最低，但不同因素距离明显收缩，存在表示坍缩风险。因此后续认知接口暂采用 0.1 作为候选，而不是追求单一一致性指标最小化。
