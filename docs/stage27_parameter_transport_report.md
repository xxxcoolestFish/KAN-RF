# Stage 27：全参数运输算子初步验证

## 1. 实验目的

验证以下结构是否能够运行：

\[
\theta_c
\xrightarrow{\mathcal T_\psi}
\omega_{\mathrm{phys}}
\xrightarrow{\text{决策解码器}}
a_t
\]

其中认知 ProtoKAN 的全部参数进入参数运输算子，运输算子生成决策 MLP 的低秩权重更新。运行时不使用 `[-1,0,+1]` 等动作探针，也不通过动作梯度搜索动作。

## 2. 实现

- 认知网络：`SimpleCognitiveKAN`，输入为 `(state, action)`，输出下一状态；
- 认知参数量：7090；
- 参数运输：完整参数向量输入运输网络，输出两个决策层的 rank-4 权重更新；
- 决策网络：两层直接动作策略；
- 运输校准：冻结认知网络，用认知网络的预测作为教师，单独训练辅助重构头；
- 决策训练：冻结认知网络和运输算子，只使用任务滚动损失训练决策参数；
- 在线更新：认知网络在目标物理环境上继续使用状态转移预测损失更新，决策网络重新读取更新后的认知参数。

主要代码：

- `physics_transfer/parameter_transport_v3.py`
- `scripts/stage27_parameter_transport_v3.py`

## 3. 主要结果

快速实验使用源环境 `(7.35, 0.0, 0.8, 0.8)`，150 步认知训练、120 步运输校准、60 步决策训练，并将调制幅度提高到 `0.5` 进行敏感性测试。

### 运输校准

运输重构损失：

- 初始：约 `0.262`
- 最终：约 `0.0046`

这说明运输网络能够从完整认知参数中提取出足以重构认知预测的信息，参数级运输在数值上是可训练的。

### 决策性能

| 环境 | 运输策略成功率 | 无运输基线 | 最大高度差异 |
|---|---:|---:|---:|
| source | 75% | 75% | -0.001 |
| factor_1 | 75% | 75% | +0.014 |
| factor_2 | 65% | 65% | +0.015 |
| factor_3 | 70% | 70% | +0.004 |
| factor_4 | 60% | 60% | +0.007 |
| heldout_1 | 75% | 75% | +0.004 |
| heldout_2 | 65% | 65% | +0.007 |

运输策略与无运输基线的成功率暂时没有明显差异，但在大多数改变物理参数的环境中平均最大高度略高。

### 在线参数刷新

在 `heldout_1` 上进行 60 步认知在线更新：

- 认知单步 MSE：`0.0167 → 0.0135`；
- 运输代码变化的 L2 范数：约 `0.00105`；
- 决策动作平均变化量：约 `3.5e-5`；
- 决策成功率：`75% → 75%`。

认知预测确实改善了，但当前运输后的决策参数变化过小，尚未形成明显的实时策略适应。

## 4. 当前结论

这次实验验证了第一层假设：

> 认知网络的完整参数可以通过一个参数运输算子重新组织，并用于生成决策网络的物理权重调制。

但尚未验证第二层假设：

> 认知参数的变化能够充分改变决策行为。

当前主要瓶颈是信息瓶颈：7090 个认知参数被压缩为 32 维代码，再生成 rank-4 更新，导致在线参数变化被严重削弱。

## 5. 下一步

1. 将单一 32 维代码改为分块运输，分别为每个认知 ProtoKAN 层生成物理调制参数；
2. 增加恒等残差或单射通道，避免运输算子丢失认知参数信息；
3. 直接测量每个认知参数块对决策输出的 Jacobian 和干预敏感性；
4. 比较 `rank=1/4/16` 和不同代码容量；
5. 再进行多随机种子和在线持续适应实验。
