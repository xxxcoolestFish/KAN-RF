# Oracle 闭环宏步 Bellman Actor：正式源环境验证

## 1. 研究问题

此前一步 Bellman 伴随 Actor 在源环境达到 `83%--88%`，但正确认知不稳定优于错误认知；反事实 Bellman/Sobolev 监督进一步下降到正确认知 `47.92%`、错误认知 `64.58%`。这些结果暴露了两个结构问题：

1. 动作由零动作点的局部价值梯度决定，无法可靠表达 Acrobot 的大幅、近饱和施力；
2. 单步内不同动作造成的状态差异太小，策略必须从病态的小尺度变化中恢复长程动作语义。

本轮只使用 Oracle 动力学，验证一个更小的结构命题：

> 如果决策网络在完整动作范围上进行闭环 Bellman 备份，并先让动作效果在短宏步内积累到可辨认尺度，正确动力学是否能同时带来高源环境成功率和稳定的正确/错误认知排序？

本轮不接入 ProtoKAN，不进行物理参数切换，也不声称已经得到最终两网络架构。

## 2. 网络结构

### 2.1 完整动作范围

Oracle 门控使用固定动作集合

\[
\mathcal A=\{-1,-0.5,0,0.5,1\}.
\]

该离散化只用于验证结构，不是最终连续动作实现。与旧伴随 Actor 不同，当前动作不再由

\[
\left.\partial_a V(F_\theta(s,a))\right|_{a=0}
\]

唯一决定。

### 2.2 四步内部宏转移

对每个候选动作，认知动力学内部连续滚动 `L=4` 步：

\[
\hat s_{j+1}=F_\theta(\hat s_j,a),
\qquad j=0,\ldots,L-1.
\]

宏步收益为

\[
u_L(s,a)=\sum_{j=0}^{L-1}\gamma^j
r_g(\hat s_j,a,\hat s_{j+1}),
\]

其中 `r_g` 只使用走廊进度、走廊内奖励、成功奖励和动作代价，不使用参考动作。

真实执行时只实施当前选出的第一个动作；下一真实时间步重新读取状态和反馈相位并重新规划。因此四步保持只存在于内部认知推演，不是开环执行承诺。

### 2.3 两层闭环 Bellman 备份

在每个宏节点重新比较全部动作，而不是预先固定一条动作序列。终端势函数为 `Uψ`，两层软 Bellman 递推为

\[
Q_d(s,a)=u_L(s,a)+\gamma^L V_{d-1}(F_\theta^L(s,a)),
\]

\[
V_d(s)=\tau\left[
\log\sum_{a\in\mathcal A}
\exp\left(\frac{Q_d(s,a)}{\tau}\right)
-\log|\mathcal A|
\right],
\]

\[
V_0(s)=U_\psi(s,\text{corridor}).
\]

根节点动作分布由 `softmax(Q₂/τ)` 给出。每个候选下一状态都有独立的下一层动作最大化，因此这是深度有限的反馈 Bellman 树，而不是一个固定开环序列。

### 2.4 损失与参数隔离

认知动力学为冻结的 Oracle 模型，不接收 PPO 梯度。决策部分使用：

\[
\mathcal L_{\mathrm{actor}}
=\mathcal L_{\mathrm{PPO}}
+0.25\,\operatorname{Huber}(U_\psi(s),\hat G),
\]

并使用独立 Critic 计算 GAE/return。参考路线只提供状态走廊，CEM 动作不暴露给 Actor。

为降低计算成本，每次 PPO 更新先缓存冻结认知产生的叶状态和中间收益；PPO epoch 只重新计算可学习势函数。缓存前后的动作 logits 在单元测试中以 `1e-6` 精度一致，算法和梯度没有变化。

## 3. 为什么需要宏步

在 512 个走廊扰动状态上，用 Oracle 动力学比较持续 `+1` 与持续 `-1` 的状态分离度：

| 内部步数 | 正负动作平均状态间距 | `+1` 相对零动作间距 |
|---:|---:|---:|
| 1 | 0.00982 | 0.00491 |
| 2 | 0.02536 | 0.01268 |
| 4 | 0.07583 | 0.03790 |
| 8 | 0.24925 | 0.12442 |
| 12 | 0.49686 | 0.24800 |
| 24 | 1.36002 | 0.67817 |

一步全动作版本的平均 logit 范围只有约 `0.05`，短预筛没有出现成功；四步宏节点把正式训练中的 logit 范围逐步提高到约 `7`，使动作效果具有可学习的数值分离度。

## 4. 预先固定的正式协议

- 单一源 Acrobot 动力学；
- `60` 轮训练；
- 每轮 `128 × 96` 个环境步；
- PPO epoch `2`，minibatch `384`；
- 动作点 `5`，Bellman 深度 `2`，宏步长度 `4`；
- 每 `5` 轮用 `16` 个反馈相位 episode 选择检查点；
- 最终使用 `3` 个独立评估种子，每种子 `32` 个随机初态，共 `96` 次；
- 源成功率门槛：至少 `95%`；
- 正确认知排序门槛：正确认知至少高于错误认知 `2` 个百分点。

错误认知对照是在真实源环境执行时，把 Actor 内部的认知模型替换为重惯性 Oracle 模型；环境、参考走廊、Actor 参数和随机初态保持不变。

## 5. 正式结果

最佳检查点为第 `35` 轮。

| 内部认知 | 成功数 | 成功率 |
|---|---:|---:|
| 正确源 Oracle | 95/96 | **98.96%** |
| 错误重惯性 Oracle | 2/96 | **2.08%** |
| 正确减错误 | 93/96 | **+96.88 pp** |

正确认知的三个评估种子分别为：

\[
31/32,\quad 32/32,\quad 32/32.
\]

错误认知分别为：

\[
0/32,\quad 0/32,\quad 2/32.
\]

认知替换导致平均绝对动作变化 `0.65918`，最大变化 `2.0`。源成功率门槛和正确认知排序门槛均通过。

训练中的 16 条小评估从第 `10` 轮开始达到 `100%`，第 `40/45/60` 轮存在 `87.5%/93.75%/93.75%` 的波动，因此正式结果使用预先规定的独立最终种子复测最佳检查点，而不是使用训练中小评估作为最终数字。

## 6. 零训练结构基线

使用相同结构、相同随机初始化，但完全不进行 PPO 更新时，独立 `48` 次预筛得到：

- 正确认知 `20/48 = 41.67%`；
- 错误认知 `0/48 = 0%`。

六轮小规模训练后，同一批初态的正确认知提高到 `29/48 = 60.42%`。这说明正确认知排序主要由宏步 Bellman 结构建立，决策学习提供了额外增益；不能把全部性能都归因于学到的势函数。该零训练结果是结构诊断，不替代正式 96 次训练后结果。

## 7. 能够成立的结论

本轮首次在同时满足下列约束的结构中通过 Oracle 源门控：

1. 动作前向传播必须经过认知动力学；
2. 没有独立动作旁路；
3. 认知参数不接受策略损失；
4. 正确认知高成功，错误认知几乎完全失败；
5. 决策不依赖零动作点的一阶梯度；
6. 当前一个真实动作只执行一步，未来动作由下一状态重新决策。

结果支持的核心机制是：

> 认知信息需要先在一个物理上可辨认、但仍可闭环重规划的时间尺度上形成动作后果，再进入 Bellman 策略改进。单步局部差异太弱，超长开环滚动又会累积模型误差；短宏步闭环备份位于两者之间。

## 8. 尚不能成立的结论

本轮仍有重要限制：

- 只有一个训练种子；
- 认知模型仍是 Oracle，不是在线 ProtoKAN；
- 仍依赖 Oracle-CEM 生成的外部状态走廊；
- 只有 Acrobot 和一维动作；
- 尚未验证物理参数切换后的零样本表现或在线恢复；
- 动作网格是结构门控工具，不是最终连续动作网络。

因此当前结果证明的是“认知算子能够被正确利用”，不是完整泛化论文已经完成。

## 9. 下一检查点

在接入 ProtoKAN 前，下一步应保持 Actor 参数不变，切换真实物理环境，并比较：

1. 正确目标 Oracle 认知；
2. 冻结源 Oracle 认知；
3. 错误 Oracle 认知；
4. 必要时目标环境中的决策在线恢复曲线。

该实验将回答当前结构是否只是源路线跟踪器，还是认知动力学变化确实能够让同一个决策网络产生有利于新物理环境的动作变化。
