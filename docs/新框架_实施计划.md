# 新框架实施计划

## 总原则

每个阶段只验证一个核心假设：先验证动力学表示，再验证决策网络接收能力，最后进行联合训练和在线适应。物理 token 的数量表示模型容量，不等于真实物理参数数量。

## 阶段

1. 自适应动力学 token 与公式无关的数据接口；
2. 认知网络多步预测、轨迹一致性和有效 token 数验证；
3. oracle 动力学表示下的决策网络物理接收能力；
4. token/动力学函数到决策参数的传递算子；
5. 用认知表示替换 oracle，并进行分阶段联合训练；
6. 在线适应、未见动力学组合和跨环境验证。

## 阶段 1 通过标准

- 不使用物理参数标签也能完成下一状态预测；
- 未见重力上的预测误差优于无物理表示基线；
- 同一动力学的不同轨迹产生稳定的 pooled 表示；
- token 不全部塌缩为零或全部无差别激活；
- 有效 token 数可随动力学复杂度变化。
