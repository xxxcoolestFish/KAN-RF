# Stage 55：锚点相对公式图与规范化残差

## 1. 目的

Stage 54 直接编码当前公式图，认知网络在线更新后 token 坐标发生漂移，导致决策解码器无法稳定解释新的公式图。

Stage 55 保存源环境认知函数作为锚点 `f_0`，当前公式图只通过相对函数残差传递：

\[
\Delta f_t(u)=
\frac{f_t(u)-f_0(u)}{\sigma_0(u)+\epsilon}
\]

公式 token 由两部分组成：

\[
z_t=T_0(f_0)+T_\Delta(\Delta f_t)
\]

认知网络仍然只使用预测损失，决策损失不反向更新认知网络。

## 2. 结构改动

- 对每个 ProtoKAN 层的全部边函数在解析基点上求值；
- 对边函数集合计算均值、标准差、绝对均值、最大值和最小值；
- 通过固定源函数统计量进行规范化；
- 缓存冻结阶段的函数统计量，认知更新后刷新；
- 决策网络同时读取源规律 token 和物理变化残差 token；
- 公式图 token 不依赖策略生成的动作 query。

初始锚点 token 漂移为 0；人为修改 ProtoKAN 参数后，漂移指标能够检测到函数变化。

## 3. seed=0 完整协议结果

| 方法 | 源环境 | 参数组 B 零样本 | 在线适应后 |
|---|---:|---:|---:|
| 绝对公式 token（Stage 54） | 76.56% | 14.06% | 9.38% |
| 锚点相对公式 token（Stage 55） | **85.94%** | 7.81% | **25.00%** |
| 历史上下文 FiLM（Stage 51） | 89.06% | 10.94% | 31.25% |

Stage 55 的认知预测损失最终为 `2.67e-4`，在线适应曲线不再出现 Stage 54 那样的快速崩溃，说明锚点残差确实减轻了公式表示漂移。

## 4. 结论

锚点相对表示是有效的第一步：它把“认知网络参数更新造成的表示漂移”转化成了“相对于源物理规律的函数变化”。但单个 seed 下仍未超过历史上下文方法，说明还需要：

1. 对认知更新加入函数空间信赖域；
2. 对公式编码器加入函数等价变换一致性；
3. 使用双时间尺度更新，避免认知 token 和决策解码器同时快速变化。
