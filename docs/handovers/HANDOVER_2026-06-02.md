## 当前进度：我们在做什么

### 根本问题

KAN-RF 框架有三步：学习规律 → 用规律决策 → 根据偏差更新规律。第一步（训练 KAN 世界模型）基本成功，第二步（决策）是所有问题的根源。

### 第二步的演进

| 方法 | 核心操作 | 结果 | 问题 |
|------|------|:---:|------|
| 逆优化 | min_a \|\|f(s,a)-s*\|^2 | 7/10 | 根因三：单步 Jacobian 太小，放大因子 25× |
| 多尺度 + 决策网络 (Plan A) | KAN([6,12,2]): (s,s*) → (a,k) | 9/10 | 引入了 k-选择问题 |

| **decision_v2**（当前） | **KAN 特征 → MLP → (a,k)** | 探索中 | 见下文 |

## 最新方向（6月2日讨论）：KAN 作为"可微裁判"

### 问题诊断

当前 decision_v2 的核心问题是：**将 KAN 学到的丰富知识（48 条 1D 边函数）压缩成 5 个标量特征后喂给 MLP**——信息大量丢失，本质上是"用错了 KAN"。

### 新思路

KAN 的知识不应该作为输入特征，而应该作为**训练时的可微裁判**：

```
训练时:                          部署时:
s → [π_θ] → a                   s → [π_θ] → a
      │                               (纯前向，KAN 不参与)
      ▼
f_KAN(s, a) → s'_pred
      │
      ▼
loss = ||s' - s*||²
      │
      ▼
θ ← θ - α · ∂loss/∂θ            ← 梯度经过 KAN 的可信导数
```

**关键区别**：
- KAN 不出现在决策网络的输入中
- KAN 出现在训练损失的计算中——它评价"这个动作好不好"
- 梯度通过 KAN 反向传播到 π_θ——KAN 用可信的导数告诉网络"动作应该往哪调"
- 部署时只有 π_θ 前向传播，KAN 不需要

| | 原始逆优化 | 旧 decision_v2 | 新方向 |
|------|:---:|:---:|:---:|
| KAN 角色 | 每步求逆（部署时用） | 特征计算机（硬压缩） | **训练时裁判（梯度路径）** |
| 部署开销 | 高（30 步 Adam） | 低（一次前向） | **低（一次前向）** |
| 信息利用 | 点值 | 5 个标量 | **完整梯度** |
| 根因三影响 | 致命 | 间接触发（a_init 爆炸） | **缓解**（不求精确逆，梯度方向对就行） |

## 容易理解偏差的内容

### 1. 三步框架中，第二步是瓶颈（不是第一步）

第一步（KAN 拟合动力学）已经做得很好：Forward MSE=0.0002, Hybrid cos_sim=0.92。
问题不在"学不会物理"，而在"不知道怎么用学到的物理做决策"。
单点逆优化是用错了工具——不是工具不好。

### 2. 特征质量 vs 性能天花板

decision_v2 的实验表明：把 KAN 知识压缩成标量特征再输入 MLP，性能有**天花板 7/10**。
这不是特征质量不够好（ctrl 从 0.03 提到 0.80 结果一样），而是"压缩→MLP 重新推导"这个范式本身的局限。

### 3. Hybrid 模型的"反直觉"表现

Hybrid 模型（cos_sim=0.92, MSE=0.0002）的 a_init 特征反而比 baseline（cos_sim=0.099）更差。
这不是 bug——越精确的模型，\|J\| 越准确（也更小），单步求逆的放大因子就越大。
**根因三是结构性的：更精确的模型 → 更大的放大因子 → 更不稳定的求逆。**

### 4. "KAN 作为裁判" vs "KAN 作为输入特征"

- 输入特征方式：信息硬压缩（48条边函数→5个标量），本质是用错了 KAN 的能力
- 裁判方式：KAN 通过梯度路径注入知识，信息密度高（每个参数都收到梯度信号），
  且天然规避了根因三（不求逆，只求梯度方向）

### 5. 动作探索器（10/10）是绕过问题，不是解决问题

动作探索器直接在真实环境中试动作——完全不依赖 KAN 的决策能力。
它证明了一个控制器可以达到 10/10，但没有证明 KAN 在决策中的价值。
本项目的学术贡献在于展示 KAN 如何帮助决策，而不只是帮助预测。

### 7. 已确认的死路

- **世界模型自评选 k**：循环推理，模型高估长 horizon 预测能力
- **CKS 认证 k-选择**：理论正确，基础误差太高导致上界太松
- **单点逆优化**：根因三是结构性约束，提高模型精度无法解决
- **将 KAN 知识硬压缩成标量特征**：信息丢失，性能天花板 7/10
