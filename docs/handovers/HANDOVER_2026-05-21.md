## 当前进度

### 我们在做什么

**核心任务**：用 KAN 作为可微世界模型完成 Pendulum-v1 摆起任务（从底部摆到顶部并保持）。

**核心结论（2026-05-21 最新）**：

```
完美模型实验证明：
  多步 shooting (H=30, Open-Loop) + 完美物理公式 = 5/5 成功 ✓
  单步 strategy v2          + 完美物理公式 = 0/5 失败 ✗
  多步 KAN-MPC             + KAN v4       = 0/1 失败 ✗

结论：多步 shooting 在模型准确时完美工作。
      瓶颈是 KAN 模型精度，不是 strategy 设计。
      不需要找"介于单步和多步之间"的新策略。
      需要把 KAN 精度提高到能支撑多步 shooting 的程度。
```

### 探索过的三条路径

| 路径 | 代码 | 核心方法 | 结论 |
|------|------|---------|------|
| **1. 单步 Strategy** | `strategy.py` → `strategy_v2.py` | s_mid / velocity-field + GN + 可控loss | 安全但太近视，无法共振摆起。完美模型下也失败。 |
| **2. 多步 Shooting** | `shoot.py` → `shoot_v2.py` | H=30 开环 / H=10 MPC + B样条不确定性 | 模型不准时被 exploitation。模型准确时完美成功。 |
| **3. 在线学习** | `online_learning.py` → `online_learning_v2.py` | FA / SGD / 三因子动态LR | 模型误差从 0.25 降到 0.09-0.17，但仍不足以支撑多步 shooting |

### 在线学习实验结果

| 方法 | 最佳 Model Err | 成功率 |
|------|---------------|--------|
| 无在线学习 | 0.25-0.35 | 1/3 |
| Feedback Alignment (lr=1e-4) | 0.20-0.35 | 0/3 |
| Full SGD (lr=1e-5) | 0.115 | 0/3 |
| Full SGD (lr=5e-5) | 0.167 | 0/3 |
| B-spline-local SGD (lr=1e-4) | 0.24-0.31 | 0/3 |
| **Three-factor (lr=1e-3)** | **0.094** | 0/3 |

在线学习**有效**改善模型精度（0.25→0.09），但单步 strategy 仍然全部失败。

## 完美模型实验（最新关键发现）

**代码**：`perfect_model_test.py`（单步）和 `perfect_shoot_test.py`（多步）

用物理公式 `θ̈ = 15sin(θ) + 3u, dt=0.05` 替代 KAN 作为 world model。

| 实验 | 结果 | 说明 |
|------|------|------|
| Strategy v2 + 完美模型 | 0/5 | 单步策略即使在完美模型下也无法摆起 |
| Open-Loop H=30 + 完美模型 | **5/5 ✓** | 多步 shooting 完美成功 |
| MPC H=10 + 完美模型 | 0/5 | 可能是优化不足（1 restart, 200 iters 不够） |

**这决定了后续方向**：提高 KAN 模型精度，不是重新设计 strategy。

## 容易理解偏差的内容

1. **"单步 strategy 失败"不是因为代码 bug，是因为物理上不可能。**
   Pendulum 摆起需要多周期共振 pumping。单步 strategy 每步独立做"离目标更近"的贪心决策，物理上无法积累能量。这和模型精度无关——完美模型下也失败。

2. **"多步 shooting 被 model exploitation 打败"不是因为 shooting 不对。**
   完美模型下 shooting 5/5 成功。问题是 KAN model 不够准。提高模型精度就能解决。

3. **"B-样条不确定性惩罚太弱"是因为它只检测 OOD，不检测 in-distribution 模型误差。**
   Shooting optimizer 找到的轨迹可能仍在训练分布内（B-样条激活正常），但模型在这些区域有系统性偏差。不确定性惩罚检测不到这种偏差。

4. **在线学习的 B-样条局部性是 KAN 独有优势。**
   B-样条严格局部支撑意味着：在顶部区域学习不会影响底部区域的知识。这是 MLP 做不到的天然抗灾难性遗忘。

5. **KAN 网络结构**：`[4 → 12 → 3]`, 756 params, grid_size=5, spline_order=3。
   输入：`[cosθ, sinθ, θ̇/8, torque/2]`，输出：`[cosθ', sinθ', θ̇'/8]`。
   每个边是一个 1D B-样条函数 φ(x) = w·SiLU(x) + Σc_k·B_k(x)。

6. **模型版本**：
   - `kan_pendulum_model.pt` (v1)：15k 随机数据
   - `kan_pendulum_model_v4.pt` (v4)：35k (15k 随机 + 20k expert, 1.3:1)
   - `pendulum_data_v4.pt`：v4 的训练数据

7. **代码备份**：`~/kan-rf-safe/` 有旧版代码。最新代码在 `~/Desktop/KAN/KAN-RF/`（git 仓库，已提交）。

8. **GIF 可视化**：`trial_v4_success.gif` 是 strategy v2 + v4 KAN 的成功 trial。
