## 项目概述

用 KAN 构建可微分世界模型 f(s, a) → s'，通过冻结模型 + 梯度优化（或 MPC）反推动作。目标是展示 KAN 的 B-样条局部支撑带来的独特优势：拟合深度训练（MOPS）、天然抗遗忘的在线学习、以及 B-样条结构对模型不确定性的分析性诊断。

### 已完成：k-选择问题的研究

这是过去几个 session 的核心探索。k 是 MPC 的预测 horizon（看多远的未来）。

**k 的困境**（FORWARD_INVERSE_GAP_CN.md 根因三）：
- k 太小：动作对系统状态的影响微弱（Jacobian ‖J‖ 太小），前向误差被放大数十倍
- k 太大：世界模型预测误差累积（混沌系统指数增长）
- 需要状态相关的 k：Pendulum 底部用 k=16，顶部用 k=1

**我们试过的方法**：

1. **世界模型自评**（失败）：问世界模型"哪个 k 预测的结果最好"→ 世界模型在大 k 时预测更乐观（预测更大的状态变化）但更不准，导致偏向大 k。Acrobot 因此选了 k=8（0% 成功率），而 k=1 是 92%。

2. **CKS（可认证 k-选择）**（理论正确，工程失败）：用 B-样条导数上界分析性地计算预测误差上限，选"安全"的 k。理论基于 FITTING_DEPTH 的 B-样条导数公式。问题：多尺度世界模型在 k=1 的预测误差已经太高（L2≈0.38），导致认证上界对所有 k 都太松，无法区分。

3. **不确定性加权 MPC**（部分成功但区分力不够）：用 B-样条激活密度 ρ(s) 作为不确定性代理，加权 MPC 评分 `score = task_loss + λ·U(s)/‖J‖²`。问题：U(s) 跨状态变化太小（训练数据密度均匀），加上混沌系统的 Jacobian 补偿使惩罚归零。

4. **Q-KAN + 乐观初始化**（理论上最正确，待实现）：把 k-选择做成 RL 问题——KAN 做 Q(s,k) 的逼近器，乐观初始化偏向 k=1，用环境反馈更新 Q 值。有收敛保证和后悔界。

### 当前方向：世界模型 + 价值网络（WM+V），去掉 k

**核心思路**：不再选 k。世界模型永远只做单步预测（k=1，最准）。用一个微型 MLP 价值网络 V(s) 来估计"从 s 出发的累积未来奖励"。V(s) 通过 TD 学习隐式编码长 horizon 效果。

**连接**：和 AlphaGo 的 MCTS + value network 同构。世界模型替代 MCTS 的 rollout，V(s) 替代 value network。

**架构**（见 `wm_v/DESIGN.md`）：
```
每步：
  1. 对每个候选动作 a：
     世界模型预测 s' = f(s, a, k=1)
     score(a) = 即时奖励 + γ·V(s')
  2. 执行 score 最高的动作
  3. 观察真实 s'_real 和奖励 r_real
  4. TD 更新: V(s) ← V(s) + α[r_real + γ·V(s'_real) - V(s)]
```

**当前实验状态**（2026-05-28）：
- 在 Pendulum 上初测：22/30 OK（73%）
- 瓶颈：新鲜 V(s) 是平的（所有状态 V≈0.03），控制退化为贪婪策略
- 底部状态需要 V 提供远见，但 V 需要好轨迹学习→鸡-蛋死锁
- ε-greedy 探索打破死锁但效率低（从底部随机到顶部几乎不可能）
- 和决策网络+动作探索（10/10）的差距：决策网络方案中，动作探索器直接在底部试候选动作，不需要 V 来间接编码

## 容易理解偏差的内容

1. **"前向 MSE 好"≠"反推动作准"**
   这是整个 FORWARD_INVERSE_GAP 文档的核心。根因三（欠驱动放大效应）是结构性的物理约束。即使模型完美，J 的范数小仍然会导致逆误差。这是在 [FORWARD_INVERSE_GAP_CN.md §5](FORWARD_INVERSE_GAP_CN.md) 详细分析的。

2. **多尺度世界模型 ≠ 解决所有问题**
   Pendulum 上用多尺度（k=16）解决了根因三，因为 k=16 的 Jacobian 比 k=1 大 16 倍。但 Acrobot 上 k=8 会失败——因为双摆是混沌系统，大 k 的预测误差指数爆炸，Jacboian 增益赶不上。

3. **"世界模型自我评估"是死路**
   让世界模型判断"哪个 k 最好"是循环推理——模型高估自己在长 horizon 的预测能力。这是 CKS 理论试图用数学上界替代自我评估的原因。

4. **B-样条局部支撑是 KAN 的核心优势**
   这是这个项目和其他 MBRL 项目的本质区别：MLP 没有局部支撑，没有控制点，没有导数上界。FITTING_DEPTH 的全部理论都建立在这个基础上。

5. **动作探索器 vs 价值网络的本质区别**
   动作探索器（给 10/10 的那个）直接在真实环境中尝试候选动作——它不依赖于任何模型来预测"未来会怎样"。价值网络（当前 WM+V 方案）让模型来估计未来——这是中介了一层间接推理，收敛更慢。

6. **当前代码组织结构**
   - `KAN-RF/` 根目录：核心组件和四个环境的实验脚本
   - `KAN-RF/cks/`：CKS 理论实现和测试
   - `KAN-RF/wm_v/`：当前方向——世界模型 + 价值网络
   - `KAN-RF/acrobot/`、`KAN-RF/mountaincar/`：子环境实验

7. **CKS 理论为什么放弃了但仍有价值**
   CKS 的 B-样条导数上界数学是正确的，但多尺度世界模型的基础误差太高，导致上界太松。如果需要紧的认证——比如安全关键系统——需要额外训练一个高精度的 k=1 专用模型来做认证。这个方向本身没有问题，只是不适合当前的模型精度水平。
