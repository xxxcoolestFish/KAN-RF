# 路径2：参数变化作为语义编码 —— 完整数学框架

## 一、核心思想

当环境物理参数变化时，WM 的参数会以某种规律变化：
$$\theta_{\text{WM}} \xrightarrow{\text{微调}} \theta_{\text{WM}}' = \theta_{\text{WM}} + \Delta\theta$$

这个 $\Delta\theta$ 编码了"物理参数变化了多少、变了什么"。但 $\Delta\theta \in \mathbb{R}^{6898}$ 维度过高、噪声大。我们需要一个**信息瓶颈**，从中提取低维语义 $z$：

$$z = \mathcal{E}(\Delta\theta) \in \mathbb{R}^k, \quad k \ll 6898$$

然后把 $z$ 作为 $\pi$ 的额外输入：

$$\pi(s, z) \to a$$

当物理参数变化时，$\Delta\theta$ 变了，$z$ 变了，$\pi$ 的决策自动跟着调整——**$\pi$ 本身的参数不用动。**

## 二、关键问题：$\mathcal{E}$ 怎么设计？

### 方案 A：参数空间直接降维（不太优雅）

$$\Delta\theta = \theta_{\text{WM}}' - \theta_{\text{WM}} \in \mathbb{R}^{6898}$$
$$z = W \cdot \Delta\theta,\quad W \in \mathbb{R}^{k \times 6898}$$

**问题**：6898 维参数空间中，不同重力变化产生的 $\Delta\theta$ 只有几个样本（g=10, 12, 14.7...）。数据量太小，训练 $W$ 必定过拟合。

### 方案 B：通过 WM 输出空间间接编码（优雅，推荐）

不直接从参数空间编码。而是用 WM 在一组**固定探针点**上的输出变化来编码：

定义探针集 $\mathcal{P} = \{(s_1, a_1), (s_2, a_2), \dots, (s_N, a_N)\}$，$N$ 个固定的(s,a)点。

基线输出：$y_i^{(0)} = \text{WM}_0(s_i, a_i) \in \mathbb{R}^6$
新输出：$y_i^{(1)} = \text{WM}_1(s_i, a_i) \in \mathbb{R}^6$
输出变化：$\Delta y_i = y_i^{(1)} - y_i^{(0)}$

定义探测向量：
$$\mathbf{d} = [\Delta y_1, \Delta y_2, \dots, \Delta y_N] \in \mathbb{R}^{6N}$$

信息瓶颈：
$$z = \mathcal{E}(\mathbf{d}) \in \mathbb{R}^k, \quad k \ll 6N$$

$\mathcal{E}$ 可以是一个小 MLP 或者 PCA。

### 为什么方案 B 更优雅

1. **探针输出空间比参数空间平滑得多**——探针输出的变化 $\mathbf{d}$ 对重力的依赖是近似线性的（因为动力学本身在参数变化下是连续的）
2. **语义明确**——$\mathbf{d}$ 的每个分量是"在这个探针点，新环境比旧环境的预测多了多少"
3. **与参数解耦**——不需要访问 WM 的内部参数，只需要 WM 的前向推理
4. **信息可控**——通过 $k$ 控制信息瓶颈，迫使 $z$ 提取最本质的变化模式

## 三、训练流程

### 阶段0：生成训练数据

在多个重力值下微调 WM，收集探针输出变化：

| 重力 $g$ | $\mathbf{d}_g = \text{WM}_g(\mathcal{P}) - \text{WM}_0(\mathcal{P})$ |
|:-------:|:----------------------------------------------------------------:|
| 9.8 | $\mathbf{0}$（基线） |
| 10.0 | $\mathbf{d}_{10}$ |
| 12.0 | $\mathbf{d}_{12}$ |
| 14.7 | $\mathbf{d}_{14.7}$ |
| 17.0 | $\mathbf{d}_{17}$ |
| 19.6 | $\mathbf{d}_{19.6}$ |

总共 5 个微调 WM，$N$ 个探针点，$6N$ 维探测向量。

### 阶段1：训练编码器 $\mathcal{E}$

两种训练方式：

**方式1：无监督（自编码器）**
$$\min_{\mathcal{E}, \mathcal{D}} \|\mathbf{d} - \mathcal{D}(\mathcal{E}(\mathbf{d}))\|^2$$

$z$ 被强制学习到 $\mathbf{d}$ 中最重要的变化模式。如果 $k=2$，$z$ 会自然学到"重力变化量"这个主导模式。

**方式2：弱监督（重力回归 + 对比学习）**
$$\mathcal{L} = \|z - t(g)\|^2 + \text{contrastive}(z)$$

其中 $t(g)$ 是一个目标编码（如 $g$ 的归一化值）。对比项确保不同 $g$ 的 $z$ 有区分度。

### 阶段2：训练 $\pi(s, z)$

$$\min_\theta \mathbb{E}_{g, s_0}\left[ \sum_{t} \gamma^t \| \text{WM}_g(s_t, \pi_\theta(s_t, z_g)) - s_{\text{goal}} \|^2 \right]$$

其中 $z_g = \mathcal{E}(\mathbf{d}_g)$。

关键：$\pi$ 在所有重力值下同时训练。它学到"当 $z$ 指示重力的值时，动作应该如何调整"。

### 阶段3：部署适应

1. 新环境 g' 下，微调 WM₀ → WM₁（500步 Adam）
2. 计算探针预测 $\mathbf{d}' = \text{WM}_1(\mathcal{P}) - \text{WM}_0(\mathcal{P})$
3. 编码 $z' = \mathcal{E}(\mathbf{d}')$
4. **$\pi$ 不做任何更新**，直接用 $\pi(s, z')$ 做决策

## 四、为什么这解决了编码偏移问题

回顾之前的问题：把 WM 参数植入 π 会导致"编码偏移"——WM 的参数变了，π 看不懂了。

在路径 2 中，π 从来**不看** WM 的参数。它只看 $z$：

$$\pi: (s, z) \to a$$

$z$ 编码的是"环境物理条件"（如重力大小），而不是"WM 的某个隐藏特征"。所以 $z$ 的"语言"是固定的、语义化的——当重力变大时，$z$ 的某个分量单调增大。π 学的是在这个固定的语义空间里做决策。

**编码偏移的根源是"WM 的隐藏特征 h 没有固定语义"**。而 $z$ 通过信息瓶颈被强制提取了有固定语义的信息（重力变化），所以不存在偏移问题。

## 五、需要实验验证的关键问题

1. **数据量**：5 个微调 WM 够不够训练 $\mathcal{E}$？可能不够。替代方案：用随机参数扰动模拟重力变化来扩充数据。

2. **探针点选择**：$N$ 个探针点应该选哪些？直觉上应该选对 $g$ 敏感的状态-动作对（如大角度 + 大力矩 = 对重力最敏感的区域）。

3. **信息瓶颈维度 $k$**：$k=2$ 是否足够？一个维度编码重力大小，另一个维度可能编码重力对惯性耦合的影响。

4. **$\pi$ 对 $z$ 的泛化**：$\pi$ 只在离散的几个 $g$ 值下训练。当遇到一个全新的 $g$ 值时，能否插值出正确行为？
