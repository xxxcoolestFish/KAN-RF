# Stage 37：训练期 TD 价值估计实验

## 实验目的

Stage 36 表明单纯增加反向传播 horizon 不能提高成功率。本实验加入一个只用于训练的 Q critic，通过 TD 目标向直接策略提供长期信用信号。部署时动作仍由决策网络直接输出，critic 不进入运行时动作路径。

## 设置

- 使用精确源环境动力学作为诊断上界；
- 8 步轨迹收集和 replay buffer；
- TD 折扣因子 0.98，target policy/target critic 软更新；
- reward 包含目标势函数进展、平滑高度、成功奖励和动作代价；
- actor/critic 训练 800 步，batch size 64；
- 比较全参数认知耦合网络和普通 state-goal MLP；
- 3 个随机种子，每个种子 100 个固定初始状态。

## 结果

| 网络 | source 成功率 | 平均最大高度 | 平均最终目标势 |
|---|---:|---:|---:|
| 全参数耦合 + TD critic | 65.0% | 1.192 | 1.099 |
| 普通 MLP + TD critic | 65.7% | 1.190 | 1.093 |

critic 的 TD 损失从约 0.2～1.1 降至约 0.04～0.10，说明价值拟合本身在收敛，但该收敛没有转化为成功率提升。

## 结论

1. 长时域直接反向传播不足以解决问题；
2. 简单的 TD critic 也没有带来明显收益；
3. 全参数认知耦合网络仍与普通 MLP 基本相当，认知参数干扰不是主要瓶颈；
4. 当前更可能是 reward 设计、轨迹分布和策略更新之间失配：随机初始状态 replay 提供的长期价值信号不足以学习 swing-up 所需的能量积累时序；
5. 下一步应先做轨迹级奖励/成功标签审计，并用真实完整轨迹进行 n-step/return 学习，而不是继续单独扩大 critic。
