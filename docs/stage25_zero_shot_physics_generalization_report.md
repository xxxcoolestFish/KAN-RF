# Stage 25：单一物理环境训练后的零样本参数泛化

## 1. 实验目的

本实验暂时不优化最高成功率，而是验证系统是否具备物理参数泛化能力。

认知网络、能量决策网络和 cost-to-go 网络全部只使用源物理环境训练。训练完成后冻结所有参数，在多个不同物理参数下进行实时动作决策。所有物理参数变化只发生在真实环境 `step` 中，测试初始状态和测试随机种子保持一致。

## 2. 源环境与目标环境

源环境：

```text
(mass_1=7.35, damping=0.00, length_1=0.80, length_2=0.80)
```

测试环境包括 4 个未参与训练的 FACTORS 参数和 2 个 HELDOUT 参数，共 7 个环境（含源环境）。测试期间没有在线更新，即这是严格的 zero-shot 泛化测试。

## 3. 训练流程

1. 只在源环境上训练多步 ProtoKAN 认知网络；
2. 只在源环境上训练能量网络和 Bellman cost-to-go 网络；
3. 冻结三个网络；
4. 使用相同的 20 个初始状态，在不同真实物理参数下滚动 64 步；
5. 记录认知网络单步预测误差和决策成功率。

## 4. 结果

| 环境 | 与源环境距离 | 单步认知 MSE | 决策成功率 | 平均最大高度 |
|---|---:|---:|---:|---:|
| source | 0.000 | 0.00445 | 15/20 = 75% | 1.421 |
| factor_1 | 3.250 | 0.00424 | 16/20 = 80% | 1.447 |
| factor_2 | 2.993 | 0.00404 | 15/20 = 75% | 1.296 |
| factor_3 | 1.876 | 0.00411 | 14/20 = 70% | 1.215 |
| factor_4 | 2.191 | 0.00452 | 12/20 = 60% | 1.174 |
| heldout_1 | 1.839 | 0.00430 | 14/20 = 70% | 1.354 |
| heldout_2 | 2.333 | 0.00394 | 12/20 = 60% | 1.209 |

## 5. 关键结论

### 5.1 认知网络具有一定的动力学插值能力

虽然认知网络只在源环境训练，但所有目标参数上的单步 MSE 都保持在约 `0.004`，没有出现灾难性预测崩溃。这说明 ProtoKAN 学到了一部分跨参数共享的运动规律。

### 5.2 预测泛化不等于决策泛化

不同环境上的预测误差非常接近，但成功率从 80% 下降到 60%。因此当前泛化瓶颈不主要是认知网络的单步预测，而是：

- 决策网络如何将预测结果转换为对新动力学有效的动作；
- 能量函数的局部梯度是否仍然指向真实环境中的有效方向；
- 多步控制中小的动力学偏差是否会改变动作序列的相位和时机。

### 5.3 当前结果已经能验证研究方向，但还不能证明在线适应

本实验是严格 zero-shot 测试，没有使用目标环境转移更新网络。下一步应在同一组目标环境上增加在线认知更新，并记录：

```text
第 1 个 episode → 第 2 个 episode → ... → 第 N 个 episode
```

观察认知更新后决策成功率是否恢复。这将直接验证“认知网络持续学习并实时影响决策网络”的核心假设。
