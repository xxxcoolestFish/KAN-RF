# Stage 17–18：决策网络能力与任务可达性诊断

## 1. 目的

在继续修改在线损失之前，先回答两个更基础的问题：

1. 当前 20 个测试初始状态是否在环境动作约束和 64 步时限内可达？
2. 如果给决策网络更大的参数更新自由度和可靠动作监督，它能否达到 20/20？

因此本组实验使用固定的 20 个初始状态（`test_seed=20260718`），避免学习前后由于随机初始状态不同而产生误判。

## 2. 固定状态上的策略诊断

环境为预训练环境 `(7.35, 0, 0.8, 0.8)`，成功判据仍为 64 步内尖端高度达到 `1.0`。

| 策略 | 成功率 |
|---|---:|
| 当前一次性映射初始化 | 14/20 = 70% |
| 真实动力学 5 步 MPC 参考策略 | 14/20 = 70% |
| 全参数可训练、直接模仿该 MPC 的决策网络 | 14/20 = 70% |

全参数模仿训练的动作损失从 `0.0494` 降至约 `0.0021`，但闭环成功率没有超过教师。这说明当前 6 个失败状态并不是简单的“runtime residual 没有学够”；因为教师自身在这些状态上也失败，而且决策网络已经能够较好地模仿教师。

需要强调：5 步 MPC 不是严格的最优控制上界，只是一个可靠参考策略。因此该结果不能证明 20/20 不可能，但它证明“继续模仿当前教师”不会解决问题。

## 3. 动作序列可达性检查

使用真实 simulator 对每个固定初始状态直接优化 64 步有界动作序列。这不是部署控制器，而是可达性下界诊断。

- 100 步优化、2 次重启：找到 16/20 个状态的成功动作序列。
- 200 步优化、3 次重启：仍找到 16/20 个状态的成功动作序列。

这说明至少有 16 个状态在当前动作范围和时限下存在成功轨迹；另外 4 个状态在当前直接优化预算下仍未找到成功轨迹。由于这是非凸优化结果，它是“已找到可行解”的下界，不是对不可达性的严格证明。

## 4. 当前问题的定位

诊断结果把问题分成两层：

### 第一层：任务/教师层

当前 5 步 MPC 教师本身只能达到 14/20，且成功判据是“曾经达到最大高度”，教师代价却是整条轨迹的累计状态代价。教师目标与最终 20/20 指标并不完全一致。

### 第二层：决策学习层

在 Stage16 中，决策网络使用的是自身探索动作的回报加权回放；即使放开全参数并直接模仿 MPC，也只能复现教师表现。这表明当前损失没有提供超越教师的任务级信息，不能从失败轨迹推导出成功动作序列。

## 5. 结论与下一步

目前不能把 50% 或 70% 的结果简单归因于认知网络或 residual 学习率。更准确的结论是：

> 当前任务教师和在线损失都没有建立“从任意测试初始状态到成功轨迹”的可靠监督；而且 20/20 的可达性还需要用更强的轨迹规划进一步确认。

下一步应按以下顺序进行：

1. 先建立真正的长时域轨迹教师（CEM/MPPI 或更长预测时域 MPC），并单独验证教师在固定测试集上的成功率。
2. 让训练目标与成功判据一致，使用终端成功、最大高度或成功轨迹级别的目标，而不是仅模仿逐步带噪动作。
3. 在确认教师可以覆盖测试集后，再比较 residual-only、全决策参数和受约束参数更新，定位在线持续学习的瓶颈。
