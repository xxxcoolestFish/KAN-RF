## 一、研究目标

单一源物理环境训练 RL 策略 + 认知世界模型。部署到未知目标物理后，仅利用真实 transition (s,a,s') 在线识别动力学变化，不使用目标环境任务 reward 更新策略，尽可能恢复闭环控制性能。

当前主要实验环境：Hopper-v5, friction_070 (摩擦系数从 1.0 降至 0.7)。

### 2.3 可微 MPC 诊断 (Phase C：已完成)

| 实验 | 结果 | 结论 |
|:---|:---|:---|
| Phase 0: KAN action Jacobian | cos=0.95, sign=97.3% | 单步 ∂F/∂a 可信 |
| Phase 1: True-dynamics MPC | 随机 shooting 无法超 Transport | 采样搜索在 3H 维空间低效 |
| Phase 2: KAN gradient MPC | 梯度优化 0% 改善 | 根因：cos(g_KAN, g_true) = -0.81 |

**核心发现**：KAN 单步 action Jacobian B_t = ∂F/∂a 可靠 (cos=0.95)，但多步 return 梯度 ∂R/∂U 方向翻转 (cos=-0.81)。state Jacobian A_t = ∂F/∂s 的累积误差在 H=4 步链式相乘后方向完全错误。

## 三、当前架构

```
源环境训练:
  PPO → π_source(s)
  KAN → F_source(s,a) = b_source(s) + G_source(s)·a

目标环境部署:
  (s,a,s') → 在线拟合 KAN → F_target(s,a)
  F_target → Transport action (保守补偿)
           → B_t = ∂F_target/∂a (局部动作敏感度，已验证可靠)
```

**Transport 锚定**：friction_070 上 reward 572，保守但稳定。
**B_t 可用**：单步动作梯度可信，cos=0.95。
**多步 return 梯度不可用**：A_t 累积翻转方向，cos=-0.81。

## 四、当前困难

### 4.1 已排除的路线

- **z → a 直接学习**：单源训练不可辨识
- **Transport imitation**：残差变化仅 0.09，信号太弱
- **DAgger / curriculum**：不解决 physics gap
- **CEM / random shooting planner**：3H 维采样低效
- **多步 KAN backprop MPC**：state Jacobian 链方向翻转
- **换优化器 / 增加 horizon / trust region 调参**：不解决梯度方向为负的问题

### 4.2 理论边界

如果同时满足以下所有条件，长期任务优化原则上是欠约束的：
1. 不使用目标环境 reward
2. 不知道任务 reward 计算方式
3. 不使用目标示范
4. 多步动力学模型的 state Jacobian 不可信

必须在以下至少一项中选择：
- 已知任务目标/任务特征 (如 Hopper reward 公式)
- 目标环境 reward feedback (如 PPO fine-tune)
- 目标演示或参考轨迹
- 足够准确的长期动力学模型 (如 Jacobian-aware 重训)

## 五、下一步方向

### 核心原则

> 保留 KAN 可靠的局部动作微分能力 (B_t)，通过真实 transition 学习长期价值 (critic/successor feature/周期反馈)，不再让 KAN 承担多步 state Jacobian 链。

### 方案 1（最推荐）：B_t + Target Critic

```
真实 transition → TD 学习 target Q(s,a)
KAN B_t → 一步动作梯度
a* = a_transport + η · B_t^T · ∇_s Q(s, a_transport)
```

- KAN 只提供已验证可靠的单步 B_t
- Target critic 通过真实 transition 学习长期价值
- 定义为 "target-reward-feedback-free"，已知任务 reward 公式

### 方案 2：周期级 ILC + B_t

```
高层选择参考步态
→ Transport 初始化周期动作
→ 执行一个完整步态周期
→ 比较周期误差
→ KAN B_t 辅助计算学习增益
→ 修正下一周期
```

- 长期信息来自真实完成的周期
- KAN 只用于局部增益设计
- 特别适合 Hopper 周期运动

### 方案 3：Jacobian-aware KAN 重训

加入导数监督重新训练 KAN，使其 state Jacobian A_t 也保真。设严格停止条件：
- H=1 cos > 0.9
- H=2 cos > 0.8
- H=4 cos > 0.5 且不为负
否则停止。

### 方案 4：Successor Features

```python
φ(s,a,s') = [forward_displacement, healthy, ctrl_cost, safety]
# 在真实 transition 上学习 successor features ψ
Q(s,a) = w^T ψ(s,a)
# 一步改进
a* = a_transport + η · B_t^T · w^T · ∇_s ψ(s,a)
```

## 六、关键约束与设计原则

1. **单源训练**：策略只在源物理中使用 reward 训练
2. **目标环境只给 (s,a,s')**：无 reward 反馈
3. **认知参与执行**：KAN 提供的信息进入控制回路
4. **Transport 作为安全底座**：最差情况下退回 572
5. **B_t 可靠，A_t 不可靠**：设计决策以此为前提
