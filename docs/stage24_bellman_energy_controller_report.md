# Stage 24：Bellman Cost-to-Go 能量控制验证

## 1. 目的

Stage 23 中，终端价值带来了小幅提升，但能量网络的长时域训练仍不稳定。本实验进一步采用：

- 非负的任务条件化 cost-to-go 网络；
- 慢速更新的目标价值网络；
- 真实转移上的 Bellman TD 更新；
- 价值更新与能量更新交替进行；
- 对动作梯度使用平滑 trust-region 式限制。

动作依然必须通过认知 ProtoKAN 生成，未使用动作教师或 MPC 标签。

## 2. 实验设置

- 认知网络：1、2、4、8 步 horizon curriculum 的 ProtoKAN。
- 能量网络：先进行 100 步一步任务代价拟合。
- Cost-to-go：100 步 TD warm-up，之后与能量网络交替更新 150 步。
- Bellman 折扣因子：`γ=0.95`。
- 决策模型滚动长度：4 步。
- 测试：固定种子 `20260718`，20 个初始状态，真实 Acrobot 环境滚动 64 步。

## 3. 结果

| 阶段 | 成功率 | 平均最大高度 |
|---|---:|---:|
| 初始一步能量 | 14/20 = 70% | 1.4307 |
| Cost-to-go TD warm-up 后 | 15/20 = 75% | 1.4313 |
| Bellman 与能量交替训练后 | 15/20 = 75% | 1.4303 |

训练损失：

- value warm-up：`1.7055 → 1.1936`；
- 交替阶段 value：首步 `1.3086`，末步 `1.5825`；
- 交替阶段 energy：首步 `7.6027`，末步 `11.5412`，最后 20 步均值 `14.1992`。

## 4. 结论

Bellman cost-to-go 和目标网络使价值估计比 Stage 23 更明确，并再次带来 70% 到 75% 的提升。但交替训练没有进一步提高成功率，能量损失仍然上升。

这说明目前的主瓶颈不是单纯的多步模型误差，也不是价值网络缺少 TD 目标，而是：

1. 当前能量函数关于动作的局部梯度不一定指向有效的长时域动作；
2. 认知模型输出空间中的小变化，未必对应真实环境中的有效控制方向；
3. 直接用能量梯度迭代动作，容易陷入局部解或产生低幅度动作。

下一步应固定认知网络和价值网络，单独比较动作求解器：平滑梯度下降、多初始点梯度下降、CEM/MPPI 式采样优化。这样可以判断问题究竟来自能量函数本身，还是来自动作优化器。
