# 认知拉回 Bellman 网络：数学架构与当前问题

## 1. 设计约束

项目不是普通的“世界模型加策略网络”。最终方法必须同时满足：

1. 认知网络 `Fθ` 是单纯的动力学预测器，只由 `(s,a,s')` 训练；
2. 决策网络拥有自己的任务参数 `φ`，认知和决策损失不混合；
3. 决策前向传播无法绕过 `Fθ`；
4. 新环境中只要预测网络持续更新，决策规律就随之改变；
5. 不预设物理参数的数量和语义。

## 2. 从动力学到决策的拉回

认知网络定义状态空间上的受控映射：

\[
F_\theta:\mathcal S\times\mathcal A\rightarrow\mathcal S.
\]

决策价值 `Vφ(s,g)` 本来定义在未来状态上。利用 `Fθ` 的复合，可以把未来价值完整拉回当前动作空间：

\[
Q_{\theta,\phi}(s,a;g)
=r(s,a,F_\theta(s,a);g)
+\gamma V_\phi(F_\theta(s,a),g).
\]

这不是对认知网络进行若干点查询后再拼接特征，而是使用整个函数及其关于动作的导数。若动作在内部最优点，动作由隐式方程

\[
G(\theta,\phi,s,g,a)
=\nabla_a Q_{\theta,\phi}(s,a;g)=0
\]

定义。当 Hessian 可逆时，隐函数定理给出

\[
\frac{\partial a^*}{\partial\theta}
=-\left(\nabla^2_{aa}Q\right)^{-1}
\nabla^2_{a\theta}Q.
\]

所以认知参数变化如何改变动作不是额外学习的映射，而是由动力学、价值几何和二阶导数组成的确定算子。这是当前架构相对“动作探针”更深的融合点。

## 3. 两种损失的严格隔离

认知阶段：

\[
L_{\mathrm{cog}}(\theta)
=\mathbb E\,d(F_\theta(s_t,a_t),s_{t+1}),
\]

只更新 `θ`。

决策阶段固定 `θ`，只更新 `φ`：

\[
L_{\mathrm{dec}}(\phi;\operatorname{stopgrad}(\theta)).
\]

在线阶段每获得真实转移，就先用 `L_cog` 更新认知模型。动作层在下一次前向传播时自然读取新的 `Fθ`。是否以及怎样继续更新 `φ` 是独立的决策学习问题。

## 4. Oracle 实验排除掉了什么

Stage78 用真实动力学替代 `Fθ`。隐式层在 129 点动作网格审计下近似无 regret，KKT 满足率为 100%，但控制成功率为 0/16。

因此本检查点尚未暴露“ProtoKAN 预测不准”或“认知信息传递不充分”；即使信息是完全正确的，当前决策学习仍失败。问题位于价值/可达性的长时域传播。

## 5. 为什么一步 Bellman 冷启动会停在零动作

令初始目标价值 `V0≈0`，则第一次动作目标近似为

\[
Q_0(s,a)\approx r(s,a,F(s,a)).
\]

在 Acrobot 下垂状态附近，一个很短时间步内的高度收益对动作很弱，而动作代价包含 `-0.005a²`。此时

\[
\frac{\partial^2Q_0}{\partial a^2}\approx-0.01,
\qquad a^*\approx0.
\]

如果价值拟合的状态分布主要是均匀随机状态，而不是从成功边界向下垂初态反向扩展的可达分布，后续迭代会不断强化这个低动作自洽解。这里缺失的不是局部最优化精度，而是“多步摆动之后能够成功”的边界条件及其传播机制。

## 6. 下一步必须先回答的问题

下一版算法应先在 Oracle 动力学下验证一个最小命题：不使用动作教师，能否让成功集合的价值沿真实可达轨迹传播到下垂初态，并使隐式动作层达到高成功率。

在这个命题成立之前，不应重新加入在线 ProtoKAN、参数迁移、因果图或更多环境。否则认知误差、传递误差和决策误差会再次混在一起，无法判断失败来源。
