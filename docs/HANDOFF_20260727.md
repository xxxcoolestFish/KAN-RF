## 一、研究目标

单一源物理环境训练 RL 策略 + 认知世界模型。部署到未知目标物理后，仅利用真实 transition (s,a,s') 在线识别动力学变化，不使用目标环境任务 reward 更新策略，尽可能恢复闭环控制性能。

当前主要实验环境：Hopper-v5, friction_070 (摩擦系数从 1.0 降至 0.7)。

## 二、已完成工作总览

### 2.1 Phase 0-2：KAN 微分 MPC 审计（已完成）

| 实验 | 结果 | 结论 |
|:---|:---|:---|
| Phase 0: KAN action Jacobian | cos=0.95, sign=97.3% | 单步 ∂F/∂a 可信 |
| Phase 0A: Bᵀ∇V_source 方向 | cos=0.53, 88.9% positive | 一步改进方向有用 |
| Phase 0B: Oracle target critic | source cos=0.63 >> target cos=-0.06 | 价值预测 ≠ 梯度准确 |
| Phase 1: 固定 α 梯度修正 | 所有 α ≤ Transport | 闭环分布偏移导致失败 |
| Phase 1.5: 相位门控修正 | sparse=neutral, dense=harmful | — |
| Phase 2: KAN gradient MPC | cos(g_KAN, g_true) = -0.81 | state Jacobian A_t 链式崩塌 |

**核心发现**：KAN 单步 action Jacobian B_t = ∂F/∂a 可靠 (cos=0.95)，但多步 return 梯度 ∂R/∂U 方向翻转 (cos=-0.81)。state Jacobian A_t = ∂F/∂s 的累积误差在 H=4 步链式相乘后方向完全错误。

### 2.2 ILC-1：周期级迭代学习控制（已完成）

| 实验 | 结果 | 结论 |
|:---|:---|:---|
| ILC-0: 周期重复性 | CV=0.019 | 步态周期检测可靠 |
| ILC-1: KAN-B_t ILC | 578.6 vs Transport 571.1 | **首次闭环超越 Transport** |
| ILC-1 消融：B_t 变体 | KAN > Shuffled ≈ Proportional > Negative | **因果链确认** |
| Online KAN + ILC | v1-v5 全失败 | 相位偏移破坏 u(φ) 对齐 |
| CartPole Online KAN | 367→499 | 非周期环境验证通过 |

**核心发现**：KAN-B_t ILC 是第一个 reward-free 闭环超越 Transport 的方法。因果消融确认 KAN B_t 的贡献。Online KAN 与相位 ILC 不兼容，但在非周期系统（CartPole）有效。

### 2.3 Planner-Router：行为空间参考生成（已完成）

| 实验 | 结果 | 结论 |
|:---|:---|:---|
| R0: Oracle reference | Oracle_ref=496 vs Transport=579 | Oracle 步态与 Transport 结构性不兼容 |
| R1: Controllability scan | vx 主导，vx=+0.10→660 最佳 | 一维行为指令足矣 |
| R1.5: Achievement audit | 固定 c=0.10 最优 | Router 退化，无切换优势 |

**核心发现**：vx 是主导行为轴，Router 退化为常量 c=0.10。Hopper+friction 场景无需复杂指令规划。

### 2.4 E0-E6：657 vs 3000 差距故障定位（当前阶段）

**统一评估框架**：5 方法 × 50 episodes，完全相同环境配置（Hopper-v5, max_episode_steps=1000, terminate_when_unhealthy=True）。

#### E0+E1：统一评估 + 回报分解

| Method | Return | Length | R/step | F100 | Fell% |
|:---|---:|---:|---:|---:|---:|
| Source→Source | 3545.0 | 1000.0 | 3.545 | 242.3 | 0% |
| Source→Friction | 664.8 | 198.4 | 3.350 | 242.8 | 100% |
| Transport | 571.4 | 183.3 | 3.117 | 242.6 | 100% |
| KAN-ILC (c=0.10) | 576.1 | 185.6 | 3.104 | 242.9 | 100% |
| Oracle (PPO on target) | 1282.2 | 413.9 | 3.096 | 219.8 | 100% |

**判定：Case A**——每步控制质量正常（94% of Source），F100 完全一致（242-243）。差距几乎 100% 来自早期终止（T=186 vs 1000）。**连 Oracle PPO 也 100% 摔倒。**

#### E2：终止前轨迹对齐

失败模式：**z_first**（躯干高度逐渐下降，非突然摔倒）

```
tau=-50: z=1.143  m_z=0.443  vx=3.04
tau=-25: z=1.158  m_z=0.458  vx=3.28
tau=-10: z=0.966  m_z=0.266  vx=3.27
tau=-1:  z=0.718  m_z=0.018  vx=3.01
```

- 高度逐渐下降（约 25 步预警窗口），角度始终在健康范围内
- vx 始终很高（~3.0-3.3 m/s）——Hopper 以高速奔跑但逐渐失去高度
- KAN 预测误差不升反降——摔倒态已在训练分布中
- ILC residual ≈ 0，Transport vs KAN-ILC 差异可忽略

#### E3：Oracle Rescue

| Condition | Return | Length | Fell% | RescueDur | Recovered |
|:---|---:|---:|---:|---:|:---|
| No rescue | 576.4 | 185.7 | 100% | 0 | 0 |
| Oracle at m_z<0.10 | 576.1 | 185.8 | 100% | 3.0 | **0** |
| Oracle at m_z<0.15 | 575.7 | 185.8 | 100% | 4.6 | **0** |
| Oracle at T-40 | 641.5 | 195.8 | 100% | 49.8 | **0** |

**z 崩溃不可逆**：连 reward-trained Oracle PPO 也无法阻止摔倒。Oracle 提前 40 步介入仅 +66 点、+10 步。0/20 episode 恢复。

|:---|---:|:---|

PCA dim 4 是唯一有效参考——它沿 obs[6]=vz 方向（ILC task_dims 追踪的维度）。

- |a_ILC - a_transport| = **0.015** → ILC ≈ Transport

## 三、架构与关键组件

```
源环境训练:
  PPO → π_source(s)
  KAN → F_source(s,a) = b_source(s) + G_source(s)·a

目标环境部署:
  Frozen Source PPO (π_source)
  + KAN Transport (control-equivalent action compensation)
  + Phase-based ILC feedforward u(φ) with KAN-B_t learning gain
  + Reference command c (behavior modification)
```

### Hopper-v5 观测结构（从 Gymnasium 源码确认）

```
obs[0]=z  obs[1]=angle(rad)  obs[2]=thigh  obs[3]=leg  obs[4]=foot
obs[5]=vx  obs[6]=vz  obs[7]=vang  obs[8-10]=joint_vels
```

⚠️ **VX_IDX=5，非 6**。早期 R1/R1.5 部分实验使用了错误的 VX_IDX=6（实际修改 obs[6]=vz）。

### ILC task_dims

追踪维度：[0(z), 2(thigh), 6(vz), 3(leg), 4(foot)]，权重 [2, 1, 1, 0.5, 0.5]

⚠️ task_dims 包含 obs[6]=vz 但不包含 obs[5]=vx。

## 四、核心发现与约束

### 已验证的可靠组件

| 组件 | 证据 | 置信度 |
|:---|:---|:---|
| KAN B_t = ∂F/∂a | cos=0.95 | ★★★★★ |
| Transport 保守补偿 | R=571, 100% 存活率 (前100步) | ★★★★★ |
| 周期检测 (foot_z local minima) | CV=0.019, 可靠检测 | ★★★★ |

### 已确认的瓶颈

| 瓶颈 | 证据 | 严重程度 |
|:---|:---|:---|
| ILC 学习信号弱 | \|u\|=0.017, ILC≈Transport | 高 — 参考修改方向与追踪维度不匹配 |
| z 崩溃不可逆 | E2+E3: 0/20 Oracle rescue 恢复 | **致命** — 物理结构性限制 |
| Transport 锚定限制 | PCA dim 4 仅达 656 | 中 — E4 将给出上界 |

### 三个根本瓶颈（从下到上）

```
3545 (Source→Source)     ← 目标上界
  ↓
1282 (Oracle PPO)        ← Reward-trained on target
  ↓  z 崩溃不可逆
 656 (PCA dim 4 ILC)     ← ILC 学习信号对齐后最优
  ↓  Transport 锚定限制
 576 (KAN-ILC c=0.10)   ← 当前 reward-free 实际水平
  ↓  ILC 学习信号弱
 571 (Transport)          ← 保守底座
```

### 设计约束

1. **单源训练**：策略只在源物理中使用 reward 训练
2. **目标环境只给 (s,a,s')**：无 reward 反馈
3. **Transport 作为安全底座**：最差情况退回 571
4. **B_t 可靠，A_t 不可靠**：设计决策以此为前提
5. **z 崩溃是低摩擦物理的结构性限制**：连 Oracle 也无法避免
