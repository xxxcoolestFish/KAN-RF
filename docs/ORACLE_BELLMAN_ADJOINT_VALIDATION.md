# Oracle 一步 Bellman 伴随策略验证与失败诊断

## 1. 为什么不是重复旧拉回算子

旧 `CognitivePullbackActor` 让网络自由产生四维协变量，再通过

\[
\mu=-\alpha B^{\mathsf T}\lambda
\]

生成动作。它在源环境只有 `51/320 = 15.94%`。旧认知逆算子进一步让当前一个动作拟合未来 12 步效果，固定时钟训练仍为 `0/320`。

本轮改成严格的一步 Bellman 时间结构。决策网络学习标量任务势函数

\[
U_\phi(s,\mathcal C),
\]

当前动作只通过认知模型的一步转移影响下一状态：

\[
\hat s'=F_\theta(s,a).
\]

协变量不再是自由四维向量，而必须来自标量势函数的状态梯度。动作均值为

\[
\mu(s,\mathcal C)
=
\alpha
\frac{
\left.\dfrac{\partial U_\phi(F_\theta(s,a),\mathcal C)}{\partial a}\right|_{a=0}
}{
B_\theta(s,0)^{\mathsf T}B_\theta(s,0)+\rho
},
\qquad
B_\theta=\frac{\partial F_\theta}{\partial a}.
\]

未来动作的作用由 (U_\phi) 表示，不再让当前动作承担整段未来效果。分母使用局部控制 Gramian 修复原始 (B^{\mathsf T}\lambda) 的尺度病态。

## 2. 训练约束

- 认知模型使用 Oracle 源动力学，完全不接受 PPO 梯度；
- 动作没有状态直达旁路；若 (B=0)，动作均值严格为零；
- 势函数同时接受 PPO 策略梯度和回报回归辅助损失；
- Critic 独立训练，避免把优势基线与动作势函数完全绑定；
- 固定时钟收集 PPO 数据，最终使用反馈最近相位评估；
- 路线只提供状态走廊，Actor 不读取 CEM 动作。

结构测试还验证：在其他条件相同时，控制作用变弱会通过正则化逆产生更大的补偿动作；组合损失能够到达全部势函数参数。

## 3. 源环境门控结果

预先规定的门槛为最终反馈相位成功率至少 `90%`。

| 训练上限 | 最佳轮次 | 正确认知 | 错误重惯性认知用于源环境 | 平均动作变化 | 门控 |
|---:|---:|---:|---:|---:|---:|
| 45 | 45 | `84/96 = 87.50%` | `80/96 = 83.33%` | `0.06335` | 未通过 |
| 60 | 60 | `80/96 = 83.33%` | `87/96 = 90.63%` | `0.06944` | 未通过 |

45 轮实验在最后阶段仍持续改善，因此只把相同协议延长到 60 轮，没有更改结构、损失或其他超参数。60 轮的小规模保存点评估达到 `15/16 = 93.75%`，但独立 96 次复测只有 `83.33%`，说明检查点评估方差仍然较大。

与旧拉回和逆算子相比，新结构已经把源环境性能从 `15.94%/约 0%` 提高到 `83%--88%`，证明“一步转移 + 标量势函数”显著改善了时间结构和优化条件。但它没有达到严格源门槛，因此不进入目标物理切换和 ProtoKAN。

## 4. 最关键的新问题：数值价值正确不保证梯度语义正确

势函数辅助损失约束的是采样状态上的函数值：

\[
U_\phi(s_i,\mathcal C_i)\approx G_i.
\]

动作使用的却是复合函数对动作的导数：

\[
\frac{\partial U_\phi(F_\theta(s,a),\mathcal C)}{\partial a}.
\]

有限采样点上的值回归不能唯一确定邻域梯度。许多函数可以在所有 (s_i) 上具有近似相同的值，却在这些点附近具有完全不同的导数。因此势函数可以获得尚可的回报拟合，同时产生不稳定或物理语义错误的控制梯度。

这一点也解释了为什么 60 轮时错误重惯性认知反而优于正确认知：网络确实经过认知模型，替换认知使动作平均变化 `0.06944`；但当前梯度没有被约束成“正确动力学下的 Bellman 改善方向”。错误认知改变了 (B) 的尺度和复合梯度，偶然形成了更有利的动作重标定。

因此：

> 强制认知进入前向传播解决了计算图旁路，却仍未解决导数语义旁路。

## 5. 其他限制

1. **势函数目标非平稳。** 45 轮末势函数损失为 `0.4475`，60 轮末升至 `0.7428`；随着策略和回报分布变化，PPO 梯度与回报回归可能互相牵制。
2. **仍在线性化于零动作。** 摆起任务经常使用接近饱和的动作，零动作处的一步导数不能完整描述非线性控制效果。
3. **检查点选择方差较大。** 16 个 episode 的第 60 轮评估为 `93.75%`，96 次独立复测只有 `83.33%`。
4. **正确性敏感性没有通过。** 认知变化会改变动作，但正确认知并不稳定优于错误认知，不能宣称物理规律已被正确利用。

## 6. 下一步应修复什么

下一步不应继续调整伴随增益或训练轮数，而应直接约束产生动作的梯度。一个更严格的候选是反事实 Bellman/Sobolev 训练：

\[
Q_{\theta,\psi}(s,a)
=
r(s,a,F_\theta(s,a))
+
\gamma U_{\bar\phi}(F_\theta(s,a)),
\]

在同一状态附近对多个动作扰动计算认知转移，用 Bellman 目标同时约束值与动作方向，再让策略使用

\[
\nabla_a Q_{\theta,\psi}(s,a).
\]

这样训练信号直接约束“改变动作会怎样改变长期价值”，而不是只希望状态值回归间接产生正确导数。该方案仍应先做 Oracle 源环境与正确/错误认知门控；在正确认知不能稳定优于错误认知前，不接入 ProtoKAN。
