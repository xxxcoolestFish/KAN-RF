# Oracle 反事实 Bellman/Sobolev 伴随策略验证

## 1. 验证目的

一步 Bellman 伴随策略把旧认知拉回的源环境成功率从 `15.94%` 提高到 `83%--88%`，但错误认知有时优于正确认知。诊断表明，状态价值回归约束了势函数的数值，却没有唯一约束用于动作的价值梯度。

本轮尝试在训练时直接约束动作价值斜率。反事实动作只在训练中使用，执行时仍通过一次认知伴随前向直接输出动作，不增加运行时动作查询。

## 2. 反事实目标

对 rollout 中的同一个状态，构造

\[
a^-=-\delta,
\qquad
a^+=+\delta,
\qquad
\delta=0.5.
\]

Oracle 认知模型产生两个下一状态：

\[
s'^\pm=F_\theta(s,a^\pm).
\]

Actor 势函数定义的动作价值为

\[
\widehat Q^\pm
=
r_{\mathrm{local}}(s,a^\pm,s'^\pm)
+
\gamma U_\phi(s'^\pm),
\]

冻结的当前 Critic 提供目标：

\[
Y^\pm
=
r_{\mathrm{local}}(s,a^\pm,s'^\pm)
+
\gamma V_{\bar\psi}(s'^\pm).
\]

训练同时最小化反事实值误差和中心有限差分斜率误差：

\[
L_{\mathrm{cf}}
=
\ell(\widehat Q^+,Y^+)
+
\ell(\widehat Q^-,Y^-),
\]

\[
L_{\mathrm{Sob}}
=
\ell\left(
\frac{\widehat Q^+-\widehat Q^-}{2\delta},
\frac{Y^+-Y^-}{2\delta}
\right).
\]

动作前向还加入到走廊下一状态的可微局部距离效用，并继续使用控制 Gramian 正则化伴随梯度。

## 3. 正式结果

正式协议为 60 轮、128 个并行环境、96 步 rollout、固定时钟 PPO 训练，以及三个评估种子共 96 个反馈相位 episode。

| 指标 | 结果 |
|---|---:|
| 最佳检查点 | 第 35 轮 |
| 正确源认知 | `46/96 = 47.92%` |
| 错误重惯性认知用于源环境 | `62/96 = 64.58%` |
| 正确减错误认知 | `-16.67` 个百分点 |
| 认知替换平均动作变化 | `0.14162` |
| 第 60 轮反事实值损失 | `0.85882` |
| 第 60 轮 Sobolev 斜率损失 | `0.01389` |

Sobolev 损失从第 1 轮的 `1.32e-6` 增长到训练中期约 `0.02`，认知替换的动作变化也大于上一个版本，因此新约束确实进入了优化过程。失败不能解释为损失权重严格为零或网络完全忽略认知。

然而正确认知性能从上一个版本的 `83%--88%` 降到 `47.92%`，错误认知反而高出 `16.67` 个百分点。源环境门槛与正确认知排序门槛均失败，所以不进入 ProtoKAN。

## 4. 为什么“直接监督梯度”仍然错了

### 4.1 反事实教师不是反事实真值

Critic 只使用当前策略实际访问的状态训练。对于 (a=\pm0.5) 产生的反事实下一状态，(V_{\bar\psi}(s'^\pm)) 可能位于训练分布之外。本轮把两个 Critic 外推值的差当作动作价值斜率教师：

\[
\frac{Y^+-Y^-}{2\delta}.
\]

这个量数值明确，却不一定方向正确。Sobolev 损失越有效，Actor 就越严格地复制 Critic 的离分布梯度错误。因此“加入梯度监督”本身不够，还必须保证梯度教师来自真实或闭环验证的长期回报。

### 4.2 一步局部距离会产生短视控制

摆起任务需要先向看似错误的方向运动以积累能量。把到下一走廊状态的距离直接加入一步动作目标，会鼓励局部追踪，却可能破坏长程摆动节奏。它在训练早期快速把小规模评估提高到 `25%`，但没有形成稳定的长期策略。

### 4.3 Critic、策略与反事实目标共同非平稳

每轮 Critic 更新都会改变下一轮的反事实教师；Actor 势函数同时受 PPO、回报回归、反事实值和斜率四种损失约束。第 60 轮势函数损失和反事实值损失分别升至 `0.83958` 与 `0.85882`，说明目标之间没有稳定收敛。

### 4.4 错误认知仍可充当有利的动作重标定

错误惯性改变了局部 (B^\mathsf TB) 和反事实下一状态。由于长期斜率教师不可靠，这种改变可能偶然产生更合适的动作幅值。计算图强制使用认知，仍然不等于正确认知必须优于错误认知。

## 5. 下一步理论约束

如果继续反事实方向，教师必须来自闭环模型回报，而不是 Critic 对单步离分布状态的裸外推。更合理的目标是模型价值扩展：

\[
Y_H(s,a_0)
=
\sum_{k=0}^{H-1}\gamma^k r(s_k,a_k)
+
\gamma^H V_{\bar\psi}(s_H),
\]

其中第一个动作 (a_0) 是反事实动作，后续动作由当前策略根据每一步模型反馈重新生成：

\[
a_k=\pi(s_k),\qquad s_{k+1}=F_\theta(s_k,a_k).
\]

这与旧多步逆算子不同：未来状态偏差由未来反馈动作共同处理，当前动作不承担整段效果。短模型时域提供真实累计奖励，终端 Critic 只负责较近的 bootstrap，从而减少离分布梯度外推。

但该方法会重新引入认知滚动误差，因此仍必须先用 Oracle 检查正确/错误认知排序，再决定是否值得研究 ProtoKAN 的短时域闭环预测稳定性。
