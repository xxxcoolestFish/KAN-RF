# Hopper 闭环认知运输：方法、结果与评价修正

> 更新时间：2026-07-25
>
> 本文档记录 `HOPPER_IDENTIFIABILITY_STAGE_CN.md` 之后的新实验。它修正了此前依据一步反事实误差得出的过度悲观结论，并给出当前真正有效的高维认知运输协议。

## 1. 本阶段最重要的结论

当前高维 Hopper 方法已经出现明确的闭环正结果：

> 在不读取目标物理参数、不使用目标奖励训练策略、也不在目标评估时查询源模拟器的条件下，仅使用目标环境中的无奖励状态转移更新认知算子，就能使冻结的源策略在复合物理变化下快速恢复回报。

在 `combo_medium` 环境中：

- 不适应的源策略回报约为 340；
- 256 条认知转移后回报约为 360；
- 512 条认知转移后回报约为 380--394；
- 1024 条认知转移后回报约为 394；
- 2048 条认知转移后，10 回合平均回报为 \(405.8\pm1.0\)。

同样使用 2048 条目标反馈时：

- 直接继续训练 PPO：约 339.9；
- 动作残差 Actor-Critic：约 340.1；
- 只使用控制 Jacobian 的效果残差 Actor-Critic：约 340.0；
- 当前蒸馏认知运输：约 405.8。

因此，恢复并不是普通决策持续学习造成的。目标奖励甚至没有用于更新策略，性能提升来自目标转移对认知算子的更新以及认知算子对源动作的重新解释。

## 2. 为什么此前判断过于悲观

此前主要使用以下一步反事实指标评价运输：

\[
E_{\mathrm{effect}}(s,a)
=
\left\|
\frac{
f_t(s,a)-f_0(s,\pi_0(s))
}{\sigma_{\Delta s}}
\right\|_2.
\]

该指标要求目标环境中的修正动作在一步之后尽可能复现源环境的完整状态变化。Dense 源孪生和可组合 KAN 在这个指标上经常使误差恶化，因此我们曾判断高维可部署运输尚未成立。

新的闭环实验表明，这个判断把“机制诊断指标”错误地当成了“控制目标”。

### 2.1 一步完整状态等价不是长期任务等价

Hopper 的回报取决于：

- 身体前进速度；
- 健康姿态；
- 触地时序；
- 接触模式切换；
- 长期闭环稳定性。

一步误差对 11 个状态坐标按固定尺度求欧氏范数。它可能强烈惩罚一个对任务影响很小的坐标误差，却无法表达动作对未来接触相位和生存时间的有利影响。

因此可能同时出现：

\[
E_{\mathrm{effect}}(a_{\mathrm{transport}})
>
E_{\mathrm{effect}}(\pi_0),
\]

但

\[
J_t(a_{\mathrm{transport}})
>
J_t(\pi_0).
\]

### 2.2 固定状态集诊断不等于运输后的闭环分布

一步诊断在认知 warmup 产生的固定状态上比较动作。实际策略运输会改变后续状态访问分布：

\[
\rho_t^{\pi_{\mathrm{transport}}}
\ne
\rho_t^{\pi_0}.
\]

一个在固定状态上局部误差略大的动作，可能把系统带入更稳定、更高回报的状态流形。固定状态的一步平均误差无法评价这种分布改变。

### 2.3 控制等价不应被定义为完整动力学复制

真正需要保持的是任务相关的闭环行为，而不是所有状态坐标的一步变化完全相同。此前的源效果误差仍然有价值，但它只能用于检查动力学模型和局部运输机制，不能单独否决闭环方法。

## 3. 当前有效架构

当前方法由四个部分组成：

1. 冻结的源 Actor \(\pi_0\)；
2. 源 ProtoKAN 控制仿射上下文；
3. 源环境蒸馏数字孪生；
4. 目标环境在线更新的 ProtoKAN 控制算子。

### 3.1 源 Actor

源 Actor 只在源环境中训练：

\[
a_0=\pi_0(s).
\]

目标适应实验中 Actor 参数保持冻结。因此，当前正结果不是重新训练 Actor 得到的。

### 3.2 源 ProtoKAN 控制仿射表示

以源策略动作为中心，认知模型表示为：

\[
\hat f_0^{\mathrm{KAN}}(s,\delta a)
=
b_0^{\mathrm{KAN}}(s)
+
G_0^{\mathrm{KAN}}(s)\delta a,
\]

其中

\[
\delta a=a-\pi_0(s).
\]

固定 KAN 字典 \(\Phi(s)\) 表达状态相关规律，源系数由源环境转移和控制 Sobolev 探针训练得到。

### 3.3 源蒸馏数字孪生

当前效果最好的源反事实模块是控制仿射 Dense 网络：

\[
\hat f_0^{\mathrm{twin}}(s,\delta a)
=
b_0^{\mathrm{twin}}(s)
+
G_0^{\mathrm{twin}}(s)\delta a.
\]

它只使用源环境数据训练，包括：

- 源策略轨迹；
- 多种动作扰动；
- 源状态云增强；
- 动作 Jacobian 的 Sobolev 监督。

该模块的作用不是直接输出目标动作，而是在目标认知更新时提供源反事实基准。

### 3.4 在线目标 ProtoKAN 算子

目标环境只提供正常转移：

\[
(s_t,a_t,s_{t+1}).
\]

算法不读取质量、摩擦或执行器缩放。先计算源孪生预测：

\[
\Delta\hat s_{0,t}
=
\hat f_0^{\mathrm{twin}}
(s_t,a_t-\pi_0(s_t)),
\]

再构造目标相对残差：

\[
y_t
=
(s_{t+1}-s_t)-\Delta\hat s_{0,t}.
\]

动作扰动采用严格对称形式，使

\[
\mathbb E[\delta a_t\mid s_t]=0,
\]

从而将动作相关控制变化与状态漂移尽量分离。

目标控制变化用低维矩阵 \(T_t\) 表示：

\[
G_t(s)\approx G_0^{\mathrm{KAN}}(s)T_t.
\]

目标漂移变化在固定 KAN 字典中递归拟合：

\[
\Delta b_t(s)=\Phi(s)W_t.
\]

于是目标认知上下文为：

\[
\hat f_t^{\mathrm{KAN}}(s,\delta a)
=
b_0^{\mathrm{KAN}}(s)
+
\Phi(s)W_t
+
G_0^{\mathrm{KAN}}(s)T_t\delta a.
\]

### 3.5 动作运输

源认知上下文给出源策略意图对应的标准效果：

\[
e_0(s)
=
\hat f_0^{\mathrm{KAN}}(s,0).
\]

目标动作通过正则化反解获得：

\[
\delta a_t^\star
=
\arg\min_{\delta a}
\left\|
\hat f_t^{\mathrm{KAN}}(s,\delta a)-e_0(s)
\right\|_2^2
+
\lambda\|\delta a\|_2^2,
\]

\[
a_t
=
\operatorname{clip}
\left(
\pi_0(s)+\delta a_t^\star
\right).
\]

当前闭环正结果使用这一无门控运输。目标阶段没有用奖励更新 \(\pi_0\) 或额外残差 Actor。

## 4. 实验协议没有使用的信息

必须明确当前方法没有使用：

- 目标环境的真实质量；
- 目标摩擦系数；
- 目标执行器缩放；
- 人工指定的物理变化类别；
- 目标奖励对策略参数的梯度；
- 目标评估阶段的源模拟器查询；
- Oracle 目标动力学。

源模拟器只在源阶段用于生成训练和校准数据。部署到目标环境后，算法只读取状态、执行动作并观察下一状态。

目标 warmup 和目标评估使用不同的环境实例及随机种子。

## 5. 闭环恢复结果

### 5.1 `combo_medium` 恢复曲线

单个采样种子下：

| 目标认知转移数 | 源策略回报 | 认知运输回报 | 提升 |
|---:|---:|---:|---:|
| 0 | 约 340.0 | 约 340.0 | 0 |
| 256 | 340.0 | 360.3 | +20.2 |
| 512 | 340.0 | 379.9 | +39.9 |
| 1024 | 340.0 | 394.1 | +54.1 |
| 2048 | 341.5 | \(405.8\pm1.0\) | +64.2 |

认知更新产生近似单调的恢复曲线。尤其在 256 条转移时已经出现约 20 点提升，说明并非必须等待完整训练回合后才有效。

### 5.2 512 条反馈的三个采样种子

源模型和源策略固定，只改变目标 warmup 与评估采样种子：

| 种子 | 源策略 | 认知运输 |
|---:|---:|---:|
| 1811 | 340.0 | 379.9 |
| 1813 | 341.9 | 391.6 |
| 1817 | 341.5 | 394.3 |
| 平均 | \(341.2\pm0.8\) | \(388.6\pm6.2\) |

三个种子都得到明显提升。

### 5.3 完整三种子恢复曲线

采用完全一致的协议，在每个预算点均使用 3 个采样种子和 3 个独立评估回合：

| 目标认知转移数 | 平均回报 |
|---:|---:|
| 0 | \(341.2\pm0.8\) |
| 256 | \(367.8\pm7.4\) |
| 512 | \(388.6\pm6.2\) |
| 1024 | \(399.3\pm3.9\) |
| 2048 | \(407.0\pm1.9\) |

三个种子的曲线均严格单调上升。归一化恢复 AUC 为：

\[
0.767\pm0.043.
\]

在离散反馈预算上：

- 三个种子均在 256 条反馈时超过 360 回报；
- 达到 380 回报平均需要 683 条反馈；
- 达到 400 回报平均需要 1365 条反馈；
- 三个种子最终都超过 405 回报。

### 5.4 `combo_mild`

1024 条目标认知转移、3 个评估回合：

- 源策略：\(539.7\pm0.6\)；
- 认知运输：\(557.8\pm2.5\)。

源策略在该环境中本来已经较强，但认知运输仍带来正增益。

### 5.5 与决策持续学习的归因对照

在 `combo_medium`、2048 条目标反馈下：

| 方法 | 是否使用目标奖励训练策略 | 最终回报 |
|---|---:|---:|
| 继续训练 PPO | 是 | 339.9 |
| 动作残差 Actor-Critic | 是 | 340.1 |
| 只更新 \(G_t\) 的效果残差 | 是 | 340.0 |
| 当前认知运输 | 否 | 405.8 |

这组结果支持如下归因：

> 当前提升来自认知网络根据目标转移学习动力学变化，并通过控制算子修改动作，而不是来自决策网络在目标奖励上重新学习。

## 6. 联合支持置信度实验

### 6.1 它能预测源孪生误差

我们实现了联合状态支持校准器：

1. 用源状态协方差白化联合状态；
2. 在白化空间计算 k 近邻覆盖；
3. 用源留出反事实误差校准局部风险；
4. 全部置信度只依赖源数据和当前目标状态。

在四种物理变化中，不确定性与真实源反事实误差的秩相关为：

| 变化 | 联合支持不确定性 | 逐坐标最大范围 |
|---|---:|---:|
| `combo_mild` | 0.573 | 0.227 |
| `combo_medium` | 0.678 | 0.467 |
| `actuator_065` | 0.685 | 0.286 |
| `friction_070` | 0.435 | 0.149 |

因此，联合支持确实比逐坐标范围更能发现高维联合分布外组合。

### 6.2 它不能直接作为动作门控

我们进一步构造了具有数学意义的可辨识裕度：

\[
\gamma(s)
=
\mathbf 1[d_{\mathrm{support}}(s)\le q_{0.95}]
\left[
1-\frac{
\hat\epsilon_0(s)
}{
\|\widehat{\Delta f}(s)\|
}
\right]_+,
\]

其中：

- \(\hat\epsilon_0(s)\) 是源局部模型误差；
- \(\|\widehat{\Delta f}(s)\|\) 是预测到的物理变化信号；
- 只有变化信号超过模型误差时才允许认知修正。

该门控能改善一步反事实指标：

- `combo_mild`：基线 0.3768，无门控 0.3995，门控 0.3743；
- `combo_medium`：基线 0.4584，无门控 0.5236，门控 0.4477。

但是闭环中它几乎删除了全部长期收益：

- `combo_medium` 正式实验：
  - 源策略 341.5；
  - 无门控认知运输 405.8；
  - 可辨识门控 341.6。

结论是：

> 世界模型误差可信度不等价于策略修正价值。用预测误差直接限制动作，会把“一步模型保守性”错误地施加到“长期控制价值”上。

联合支持估计仍然有用，但更适合：

- 标记认知预测是否可信；
- 决定是否写入长期认知记忆；
- 调整认知学习率或模型 ensemble 权重；
- 触发额外探索；
- 为残差 Actor-Critic 提供不确定性特征。

它当前不应直接乘在最终动作修正上。

## 7. KAN 贡献的当前边界

当前最强方案是混合结构：

- 源反事实数字孪生：Dense 控制仿射网络；
- 源控制表示：ProtoKAN；
- 在线目标漂移和控制算子：固定 KAN 字典上的递归更新；
- 动作生成：目标 KAN 上下文的正则化反解。

将 Dense 源孪生替换为第一版稀疏可组合 KAN 后，在 512 条目标反馈的 `combo_medium` 上：

- 源策略：340.0；
- Dense 源孪生运输：379.9；
- 稀疏 KAN 源孪生运输：357.0。

稀疏 KAN 仍然产生约 17 点正恢复，但明显弱于 Dense 源孪生。因此目前不能声称性能主要来自源 KAN 表达能力。

当前可以合理声称的是：

1. 固定 KAN 字典提供了在线递归更新的目标物理算子；
2. 控制仿射 KAN 上下文进入动作生成必经路径；
3. KAN 目标算子结合蒸馏源孪生能够仅靠转移反馈恢复闭环回报；
4. 第一版成对交互 KAN 源孪生仍需提升高阶耦合表达。

## 8. 当前方法的学术意义

这一阶段把论文故事从“高维源反事实预测必须逐点准确”调整为：

> 学习一个足以支持闭环策略运输的认知算子，不要求它在固定状态集上完整复制所有源动力学坐标。

当前方法与普通上下文条件策略的区别在于：

- 没有把动力学 latent 简单拼接到 Actor；
- 没有在多环境分布上预训练条件策略；
- 只有一个源物理环境；
- 目标变化类别未知；
- 在线认知更新通过明确的控制算子改变动作；
- Actor 可以完全冻结，认知更新本身就产生恢复。

最有竞争力的指标是：

\[
\text{目标无奖励转移数}
\longrightarrow
\text{闭环回报恢复曲线}.
\]

这比只报告最终回报更直接对应项目最初追求的快速物理泛化。

## 9. 尚未解决的问题

### 9.1 仍需正式多种子恢复曲线

当前完成了：

- 单种子 0/256/512/1024/2048 恢复曲线；
- 512 条反馈的三个采样种子；
- 2048 条反馈的 10 回合正式评估。

仍需对每个反馈预算做多种子统计。

### 9.2 仍需更多独立物理变化

至少需要正式覆盖：

- 单一执行器变化；
- 单一摩擦变化；
- 单一负载变化；
- 复合轻度变化；
- 复合中度变化；
- 方法不能改善或发生退化的边界变化。

### 9.3 需要公平比较上下文世界模型

必须加入：

- MLP 在线目标上下文；
- 不使用 KAN 字典的线性/低秩上下文；
- 普通预测 latent 拼接 Actor；
- 仅目标动力学模型但不做控制运输；
- 同预算 PPO、TD3、动作残差。

这将决定论文贡献究竟来自 KAN、控制等价运输，还是一般的在线系统辨识。

### 9.4 决策网络持续学习尚未建立在新起点上

此前残差 Actor-Critic 从约 340 的弱策略开始，2048 条反馈几乎学不动。现在认知运输先把策略提高到 380--406，合理的下一步是：

\[
\text{认知快速恢复}
\rightarrow
\text{残差 Actor-Critic 长期精修}.
\]

需要检验：

- 残差 Actor 是否能在更好起点继续提升；
- 是否能保持认知带来的早期样本效率；
- 是否会破坏已经恢复的策略；
- 返回源环境后是否遗忘。

### 9.5 源孪生仍不是纯 ProtoKAN

Dense 源孪生当前更强。后续 KAN 改进必须针对 Hopper 的高阶接触耦合，而不是继续堆叠全部成对交互。可研究：

- 动力学结构分块；
- 接触模式条件模块；
- 低秩高阶张量 KAN；
- 可学习稀疏超图；
- 控制相关的闭环训练目标。

## 10. 下一步实验顺序

### Gate A：正式恢复曲线

已通过。`combo_medium` 的 0/256/512/1024/2048 条反馈均已完成三种子统计，所有曲线单调恢复，最终回报为 \(407.0\pm1.9\)。

### Gate B：多物理变化

单种子固定超参数筛查已完成。没有按变化类型选择模型或阈值，初步结果如下：

| 隐藏物理变化 | 0 条反馈 | 512 条反馈 | 2048 条反馈 | 初步结论 |
|---|---:|---:|---:|---|
| `payload_125` | 1854.7 | 1554.8 | 1691.1 | 源策略本来很强，运输负迁移 |
| `payload_150` | 834.7 | 864.1 | 877.9 | 小幅单调提升 |
| `friction_070` | 588.0 | 680.8 | 585.7 | 早期显著提升，后期回落 |
| `actuator_080` | 595.5 | 728.5 | 801.1 | 强单调恢复 |
| `actuator_065` | 420.5 | 475.6 | 503.0 | 明显单调恢复 |
| `combo_mild` | 539.3 | 557.0 | 564.0 | 小幅单调提升 |
| `combo_medium` | 340.0 | 379.9 | 405.5 | 明显单调恢复 |

512 条反馈时 7 个变化中有 6 个得到正增益；2048 条反馈时有 5 个保持正增益。除 `payload_125` 使用 3 个评估回合、`combo_medium` 已有正式三种子结果外，其余是单回合快速筛查，不能作为最终统计结论。

筛查揭示了两个必须解决或诚实界定的边界：

1. 当源策略在目标环境中本来就很强时，算法还不会判断“无需适应”，固定认知运输可能负迁移；
2. 摩擦变化中早期认知有效，但继续递归更新会失去收益，说明认知估计存在后期漂移或控制相关过拟合。

正式实验优先选择：

- `actuator_080`：稳定正恢复代表；
- `combo_medium`：已经通过完整三种子恢复曲线；
- `friction_070`：早期有效、后期退化的稳定性边界；
- `payload_125`：无需适应时的负迁移边界。

### Gate C：结构消融

严格比较：

1. Dense 源孪生 + ProtoKAN 目标算子；
2. Dense 源孪生 + MLP 目标算子；
3. KAN 源孪生 + ProtoKAN 目标算子；
4. 只更新全局控制矩阵；
5. 不做认知运输；
6. 普通目标 PPO。

### Gate D：决策持续精修

以认知运输后的策略为初始化，再允许残差 Actor-Critic 使用目标奖励更新，比较：

- 早期恢复 AUC；
- 最终回报；
- 稳定性；
- 返回历史环境后的遗忘。

## 11. 当前结论

高维 Hopper 的关键问题并不是“认知模型的一步预测必须在目标状态上完全准确”，而是认知更新是否能产生对闭环任务有价值的动作重解释。

当前实验已经证明：

1. 仅用一种源物理环境训练；
2. 目标物理参数完全隐藏；
3. Actor 冻结；
4. 不用目标奖励训练策略；
5. 只用 256--2048 条目标转移更新认知；
6. 认知运输使 `combo_medium` 回报从约 340 单调恢复到约 406；
7. 同预算普通决策学习没有出现相同恢复。

这是目前项目中第一个同时满足“高维环境、隐藏物理变化、认知持续学习、认知必经动作生成、有限反馈快速恢复”的正结果。

下一阶段不应继续用一步完整状态误差筛掉有效策略，而应以闭环恢复曲线为主评价，并通过目标上下文结构消融确定 ProtoKAN 与控制运输各自的真实贡献。
